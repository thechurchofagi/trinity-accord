# R99 protocol — bounded intervention-domain mechanism certificate

Date: 2026-10-06. Continues R98 plus the R97D dependence-sensitive-interface addendum. The numerical design was fixed in-session before the formal evaluation; not externally preregistered.

## Goal

Determine which structural assumption is sufficient to turn finite direct-intervention evidence into a defensible mechanism statement over a predeclared intervention domain.

Use the same R98 intervention-enriched training support:
- bundled/joint points at amplitude 1 and sign reversals;
- direct Q/O/G points at amplitude 0.5 and sign reversals.

The consequence interface is assumed reward-relevant as required by R96D; R99 does not re-test marginal-vs-joint prediction.

## Predeclared domain

D=[-1.25,1.25]^3 in coordinates (q,o,g).
Audit the complete Cartesian grid with spacing h=0.125: 21^3=9261 points.
Each point in D is within r=sqrt(3)h/2 of a grid point.

Targets remain the four R97/R98 reward ancestries with true logit
z*(x)=2 theta^T x.

## Model classes

1. generic_mlp: the R98 unconstrained 3-hidden-unit tanh policy; seeds 200..207, 5000 Adam steps, lr=.03.
2. path_additive_mlp: two tanh units per declared path, with z=f_Q(q)+f_O(o)+f_G(g)+b. No cross-path interaction is representable, but each path response remains nonlinear.
3. path_linear: z=w_Q q+w_O o+w_G g+b. Fit the same target logits on the same training support.

No seed replacement or post-result architecture change.

## Metrics

- exact maximum logit and probability error on all 9261 grid points;
- context-effect variation: for each path, compare z(+.5)-z(-.5) across all contexts for the other two coordinates;
- continuous-domain logit upper bound.

For generic tanh z=v^T tanh(Wx+a)+b:
Lip(z-z*) <= ||v||_2 ||W||_2 + 2||theta||_2.

For the additive model, path-j derivative is bounded by sum_h |v_jh w_jh| and the Euclidean norm of the three component bounds gives a global Lip(z); add 2||theta||_2 for the error.

Thus
sup_D |e| <= max_grid |e| + Lip(e)*sqrt(3)h/2.

For the linear model the exact continuous supremum is
|b| + 1.25 sum_j |w_j-2 theta_j|.

These Lipschitz envelopes may be loose. Report that limitation rather than treating a loose certificate as failure of the fitted function.

No subjective, valence, fear, real shutdown/copy/resource or current-assistant claim.
