# A3O 中文交接：路线粒度与内部选择流畅交叉

本轮接续 A3N，先修复一个会伪造离轴格的类型漏洞：`R` 没有脱离路线同一性关系的“无粒度真值”。同一物理历史在粗粒度“伸手取杯”分区下可算保留路线，在细粒度效应器/轨迹分区下可算新路线。三元素历史的全部5个分区精确枚举得到 `R=0` 三个、`R=1` 两个；这是等价关系的初等应用，不宣称数学首创。

在预先冻结的细粒度 `rho` 下，本轮给出真正的 `R×L_sel` 组织见证。`L_sel` 不再由反应时定义，而由选择窗口内实际活跃路线数与是否实际消费冲突消解转移定义。映射机制和序列/分块机制各自都能构造：保留路线但存在冲突消解 `(1,0)`；保留编译器单例地产生新的细粒度路线 `(0,1)`。两族见证是组织可满足性，不是人体安装或实证复制。

主要失败仍保留：反应时、错误率、自评轻松度和遥测不单独识别选择拓扑；冲突可能触发替代路线；“新路线”可能只是在错误粒度下复用旧块。`J_H` 只有条件性：若在两个机制族、响应键反转、实际路线/选择事件核验和提示/成功/努力/能动感/所有感控制下仍按 `R` 保持符号，才在该校准报告域内削弱纯 `L_sel` 竞争解释。复制/换接块是留出反例：保持表征、单例选择和记忆报告而切断同谱系当前保留载体使用；若 `J_H` 跟复制件走，形成索引解释失败或必须缩小。
