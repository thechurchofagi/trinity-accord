# R136：任务一样，什么时候真的存在统一翻译器？

本轮解决了 R135 的一个限定问题，并把时间顺序变成了明确的数学条件。

## 1. 先修正可能的过度结论

不能笼统说“任务能力相同也永远不能得到统一翻译器”。经典 Blackwell 定理说明：固定两套有限观察渠道，先观察后决策，如果一套在所有效用表定义的决策问题上都不差，那么确实存在一个统一随机后处理器，能从它模拟另一套观察。

本轮给出完整有限维证明。它要求固定观察渠道、覆盖所有决策问题，强于 R135 中只比较一个固定成功率族的加权成绩。它仍然不是实际组织同构。

## 2. 关键在于：信息来得及吗？

考虑两套系统：第一套在第一步给出隐藏比特，第二套到第二步才给。等两步都结束，二者都完整知道这个比特，可以离线重排记录。但如果第一步就必须回答，第二套只能猜。

严格结果：离线翻译误差可以为0，在线因果翻译的最小最坏误差却是1/2。

因此，论文 C 的“纤维常值”识别条件要在每一个输出截止时间成立，不能只在完整记录上成立。

## 3. 每个单项任务100%，换成后来揭晓的任务却只有75%

两个隐藏比特，只允许预先读取一个。如果提前告诉系统要问哪一个，它就读哪一个，每项任务都能100%成功。

如果先读完、再告诉它问哪个，它的最优最坏成功率只有75%：一半机会读中了，另一半只能公平猜测。

推广到 n 个比特、预读 k 个：

\[
V_{n,k}=\frac12+\frac{k}{2n}.
\]

正文证明了适应性读取也不能超过这个界，并构造了逐输入达到界的随机策略。这里限制的是读取次数，不是任意编码的内存大小。相对于全读系统，在统一延后查询协议中的能力保证损失精确为：

\[
\frac{n-k}{2n}.
\]

这表明“对每个提前指定的任务都能另选准备策略”，不能替代“先完成同一份准备，再应对后来揭晓的任务”。任务揭晓时间是组织能力定义的一部分。

## 4. 已补上的正面证书

对有限外生观察流，写出了一个线性可行性证书：同一随机翻译核、逐隐藏参数路径律匹配、每个输出前缀只能依赖已到达输入。这些条件成立，当且仅当存在一个可执行的因果观察翻译器；误差还能在多次翻译时相加。

这个证书当前只覆盖没有动作反馈的观察流。若行动会改变后续世界与观察，必须另建受控机制证书，不能套用被动路径匹配。

## 5. 下一篇论文的定位

可以围绕“能力等价、因果可替代与完整组织等价的层次”组织论文。现有结果把问题变得可证明、可反驳，也解释了为何任务分数和最终记录不足以确定机制对应。

经典 Blackwell、因果运输和查询理论均有先行工作，不把它们包装成新的意识公理。与意识的联系仍依赖四篇论文中实际支撑、完整签名及识别条件；75%或1/4不是体验量。

检查：13项精确数学检查通过，包括4096个组合、2080个混合核、10000次静态决策比较、650棵适应读取树、4088个保证坐标。一般证明是同一助手手工审查，非独立审稿或证明助手认证。下一步研究动作会反过来影响观测时的统一机制翻译。
