# Endpoint screen: recognition is a control, not yet the selected target

Selected original-source methods were inspected; this is not an exhaustive scale review or a human validation study.

| Inspected item or readout | Role for this route | Remaining gap |
|---|---|---|
| Patané explicit self/partner source classification | Origin-recognition control | Does not separately ask current felt enactment familiarity |
| Patané implicit movement-direction judgment | Task performance control | A self-advantage is not a signed familiarity endpoint |
| Kadambi theoretical motor-familiarity RDM | Declared predictor of neural similarity | Predictor construction is not an independent felt-target measurement |
| Ishikawa ownership and agency questionnaire/model association | Neighboring target evidence | Neither target can be renamed the selected familiarity coordinate |
| This record's q=f+2s | Pure mathematical control | No demonstrated correspondence with actual agency |

In the inspected passive proprioceptive replay condition, the participant was instructed to relax while recorded trajectories were replayed with vision occluded. This protocol does not install the active R172 use required by the selected R173 application. It can still inform recognition controls. Reported modality differences do not establish absence of experience.

One semantic stress pair for the next round: (a) a practiced other-origin movement that the person correctly knows came from someone else but might feel bodily familiar during current enactment; (b) a correctly recognized own-origin, little-practiced movement that might feel bodily unfamiliar during current enactment. These are proposed countercases, not observed dissociations. Source classification, practice and current felt familiarity may still covary or fail to dissociate.

First ask whether a fallible current-familiarity judgment has a stable interpretation under these cases, without defining it as remembered origin, ease, success, ownership or agency. Next ask whether one remaining actual relation can vary under feasible controls. A matching agency report does not imply matching latent state. Do not manufacture a third coordinate from a new name. Stop at ENDPOINT_CONSTRUCT_UNRESOLVED if interpretation or physical support fails.
