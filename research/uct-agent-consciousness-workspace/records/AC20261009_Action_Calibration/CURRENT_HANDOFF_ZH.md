# AC20261009：动作通路校准与任务相关自模型

**成果版本：AC-RESULT-v1.0.0；日期：2026-10-09。** 方法采用 MGTD v1.0.1。原完成地图仍为 UCT-MAP-v1.0.0，不覆盖；候选地图标识 UCT-MAP-v1.0.1-AC20261009-candidate.1。

## 本轮问题与成果

从体验—智能—我感主线接续：知道一般动作规律，不等于知道自身指令端口连接哪个结果端口。固定一个无噪声、未知但稳定的双射接线模型，推导校准后的全部剩余接线，以及它们如何限制不同任务。

1. 相同命令历史的端口形成一组；实际观测仍允许组内任意对应。剩余接线数是各组大小阶乘的乘积。
2. 若一组含m个结果，目标要求其中指定r个改变，该组的最佳精确成功率为1/组合数(m,r)。独立组相乘。均匀单目标平均成功率为可区分组数/n；所有一起动则始终能做对。
3. 四端口例子：无校准或反复1111，单目标最佳1/4；重复0011为1/2；0011然后0101达到1。后两种同为两轮、四次端口激活，但组织的可区分性不同。
4. 并行二值校准精确识别全部n条接线至少ceil(log2 n)轮；每轮只能动一个端口则至少n-1轮。编码识别原理有明确前人工作，不算首次发现。
5. 控制器必须保留的接线区别随任务改变。对于固定目标族，最少区别状态数M=n!/各目标不可分端口组阶乘之积。四端口：只要求全动/全停需1种，固定一个指定目标需4种，任意指定一个需24种（至少5位固定长度二进制信息）。两轮观察多个通道，不等于只有两位记忆。
6. 控制器可以用编译后的接线关系，无需用语言表达“我”。但关系也可对应外部工具，不证明解剖归属感、熟悉我感、一个独占主体或体验强弱。

## 原理论与原创性

C1、U1、P3不变。整体形成不取消持续局部体验；控制失败不等于局部或整体无体验。实际过程、完整签名、安装的调用机制及同一真实J独立成立后，才能用原C:P1推出完整体验结构类型差异。不同校准预算不能偷换成同一J；两系统若均可自由优化校准，单次执行差异不证明最大能力差异。

R146已有自相关目标充分性，R147已有同步掩盖接线及控制不决定身体归属的限制。Bongard2006、Hu2025、Chen等2026已有机器人自模型与身体对应研究；置换恢复已有二值编码界。本轮的窄增量是把残余歧义、目标成功率和任务相关状态下界在同一动作组织中精确连接，配合UСT的实际性/我感边界。具体组合的历史优先权尚未完全查清，不宣称重大意识定律已被证实。
