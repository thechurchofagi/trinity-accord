# R166 中文审查：从总体效应到同一实例中的实际安装

本轮把主线从统计设计拉回了实际组织。核心结论不是“总体实验显著，所以某个人体内有身体框架关系”，而是相反：总体剖面、有限观察、同一实例中的实际安装、C1 下的体验结构对应、熟悉的“我身感”解释，必须分成五层。

两个精确反例封住了两条捷径。第一，相同总体多重集可以把命名个体的 0/1 状态交换，所以群体统计不识别命名 token。第二，一个真正经由 `k` 到消费者的路径和一个绕过 `k` 的旁路，在自然输入和上游 `do(r)` 下可以给出完全相同的 `r,k,u`；只有事先规定的 `do(k)` 或局部切断才能区分本候选。这说明“看见这个变量跟着变化”还不是“它被实际使用”。

正面推进是 W1–W6 同一实例安装见证合同：同一实际 `P/I/K/D` 与实现映射、独立物理锚定、内生绑定和实际使用、局部传播、对旁路有区分力的中介/切断干预、严格状态边界。合同全部成立时，只支持这个被选关系在该实例该时段内实际安装；缺项默认 `UNRESOLVED`，不能默认无我感、无体验或无意识。

在完全同一实例上，既有 R159/C1 运输才把实际关系带入体验结构内部；但 R157 的语义剩余继续成立，叫它熟悉的“身体我感”仍需独立 `B_min` 和目标证据。这里没有增加额外主人，也没有把身体框架、报告、自我模型、语言、整合、递归、预测或控制变成基础体验门槛。

失败和开放项已保留：合同只是充分而非必要；无实际装置或参与者；干预保真、排除性、局部性、冗余补偿和完整实现都未验证；R161 尚未被改造成保持 token 身份的锚点—中介—消费者联合试验；`B_min/F_O` 仍开放。下一题应设计一个伦理可行、保持同一实例身份并显式处理冗余/补偿的 W2–W5 架构，而不是继续增加总体统计层。
