# A Same-Token Installation Witness for Body-Frame Organization

## From population role profiles to an actual relation, without making it a gate for experience

Version 0.1, 8 October 2026. Research checkpoint; not a published edition, experimental result, clinical protocol, or proof that any present system is conscious.

## 1. Question and result

R159 specified an internal body-frame relation and transported it conditionally through C1. R160–R165 made one population protocol increasingly falsifiable, but did not show that the selected relation is actually installed in any single process token. The missing step is not another group statistic. It is a typed bridge from external evidence to one actual organization.

This note makes four advances.

1. It separates five evidence and interpretation levels that had been easy to conflate.
2. It gives exact counterexamples showing that neither a population profile nor a finite same-token interface trace entails internal installation.
3. It states a sufficient, explicitly empirical **same-token installation witness contract** for one body-frame candidate.
4. It proves only a conditional route from that witnessed physical relation, through the existing C1 transport, to an experiential structural counterpart. Calling that counterpart familiar felt bodily mineness still requires the independent `B_min` bridge.

The contract is not claimed necessary. Failure to establish it means `INSTALLATION_UNRESOLVED`, unless the declared candidate is directly refuted. It never means no experience, no self, no ownership feeling, or no consciousness.

## 2. Five levels that must remain distinct

Fix a candidate relation type but do not yet assume it is realized.

| Level | Object | Legitimate conclusion | Not licensed |
|---|---|---|---|
| `E0` | Population/session summary such as an R161 effect profile | A protocol-relative distributional regularity, if gates and error model pass | A named participant token has the relation |
| `E1` | Finite observations/interventions on one token | The tested interface and intervention responses occurred in that token | The observed variables are the complete mechanism or an internal path is installed |
| `E2` | Same-token installation witness relative to a declared causal/realization contract | The selected `Anchor–Bind–Use` relation is supported as actually installed during the declared interval | Necessity for experience, complete neural organization, unique owner, or external anatomical truth |
| `E3` | C1 transport on the same admitted actual token and complete signature | The installed K-relation has an experiential structural counterpart | A familiar semantic or phenomenal label |
| `E4` | Independently fixed and supported `B_min` plus fallible target evidence | A selected interpretation as familiar felt bodily mineness | Universal reportability, conceptual self, or a basal-experience threshold |

The arrows are conditional bridges, not automatic promotions. `E0` and `E1` can motivate or test an `E2` contract, but they do not entail it alone. `E2` does not derive C1. `E3` does not settle `E4` by vocabulary choice.

## 3. Population-to-token obstruction

Let a population contain two actual tokens `p_1,p_2`, and let a binary protocol response be `(1,0)`. Swapping token labels yields `(0,1)`. Both populations have the same mean, histogram, minimum, maximum and every permutation-invariant group statistic, while the truth value attached to named token `p_1` changes.

More generally, every nonconstant binary vector is permutation-equivalent to another vector with the same aggregate multiset and a changed named coordinate. The exact checker enumerates all vectors for population sizes two through six. Therefore an R161 population profile, even if perfectly estimated, cannot by itself entail that a named actual token carries the candidate relation. An explicit sampling, measurement and token-realization bridge is required.

This is not skepticism about population science. It is a type restriction: a property of a distribution is not yet an installed relation in one process.

## 4. Finite interface-to-installation obstruction

Consider two deterministic structural models with binary variables. Both have external input `b`, internal-looking variables `r,k`, and output/consumer `u`.

**Path model `M`:**

\[
r:=b,\qquad k:=r,\qquad u:=k.
\]

**Bypass model `B`:**

\[
r:=b,\qquad k:=r,\qquad u:=r.
\]

For both natural inputs and for every intervention `do(r=x)`, the complete observed tuple `(r,k,u)` agrees between the models. Yet `k` is on the operative path to `u` only in `M`. Under an admissible mediator intervention that changes `k` while holding `r` fixed, `M` changes `u` and `B` does not. The exact checker exhausts all binary cases.

Thus even a same-token trace containing the candidate representation can be generated by a dormant, mirrored or bypassed state. Natural covariance, correct output and upstream perturbation are insufficient to establish installed **use**. A downstream mediation/cut test, or another independently justified physical witness of the same role, is required. Even such a test remains relative to its declared variables, intervention semantics, fidelity and exclusion assumptions; it does not reveal the complete organization.

## 5. Same-token installation witness contract

Fix one actual process token `P`, nonzero interval `I`, complete admitted signature `K`, ontic structure `D`, experiential structure `Phi`, and C1 isomorphism `h`. Fix internally sorted candidates `r` (anchor/frame), `k` (body-directed representation) and a nonempty declared set `U` of consumer occurrences. The following package is a **sufficient application contract**, not a metaphysical definition or necessary condition.

### W1 — actuality, identity and typing

Every asserted occurrence belongs to the same actual `P,I,D`; time indices, variable sorts and the realization map from instrument records to `r,k,U` are fixed before target interpretation. Cross-session averages, simulated nodes, software variables and external anatomical referents are not silently substituted for actual internal occurrences.

### W2 — independent physical anchor

`Anchor(r)` is grounded by a physically admissible perturbation or lineage/port criterion independent of ownership, agency or self reports. The physical process, not only the analyst's label, distinguishes the anchor under the declared controls. External anatomical correctness is separately typed.

### W3 — endogenous binding and actual use

`Bind(r,k)` and `Use(r,k,U)` are declared K-relations. The candidate occurrences actually happen during `I`; `k` is not merely available, copied, logged, decoded after the fact or present in an unused lookup table. At least one declared consumer occurrence in `U` depends on the candidate relation in the fixed model.

### W4 — local perturbation propagation

Within a predeclared physically admissible intervention family, perturbing the realized anchor or binding while preserving declared background controls produces the predicted change in `k` and the declared consumer occurrence. Delivery, consistency, temporal order and measurement fidelity are independently checked. Ownership language cannot define success.

### W5 — mediation or cut discrimination

An independently specified intervention on `k`, or a localized cut/block of the `r→k→U` contribution, discriminates the path model from a live bypass: the predicted consumer contribution changes when the candidate path is changed or blocked, while the retained controls stay within tolerance. The causal sufficiency, exclusion/locality and realization assumptions used for this inference are declared rather than hidden.

### W6 — bounded conclusion and status discipline

The conclusion is only that the selected relation is supported as actually installed in `P` during `I`, relative to the declared contract. If all clauses are supported, output `INSTALLATION_SUPPORTED`. If a clause required by this candidate is validly contradicted, output `CANDIDATE_INSTALLATION_REFUTED`. Otherwise output `INSTALLATION_UNRESOLVED`. Protocol invalidity remains `INVALID_WITNESS_PROTOCOL`. None of these statuses is an experience classifier.

The conjunction is satisfiable: a realized anchor can drive a bound representation that is used by a consumer, and local interventions can propagate and discriminate a bypass. Satisfiability does not show that a human or machine actually instantiates it.

## 6. Conditional installation and C1 result

Define

\[
\theta_{frame}(r,k,U) := Anchor(r)\land Bind(r,k)\land Use(r,k,U).
\]

Under W1–W6, the independent measurement/realization assumptions and the R157 physically grounded definable-selector contract, the witness supports

\[
D\models\theta_{frame}(r,k,U)
\]

for the one declared actual instance. This is a conditional application conclusion: if the empirical clauses are not actually true, the conclusion is unavailable.

If the same `P,I,K,D,Phi,h` also satisfies C1 and the existing R159 transport contract, then

\[
D\models\theta_{frame}(r,k,U)
\iff
\Phi\models\theta_{frame}(h(r),h(k),h(U)).
\]

This is the positive organization-to-experience step sought in the current main line: the bodily relation is explained inside experience by transport of the actual organized relation, not by adding an extra owner. But the metalinguistic assignment “felt bodily mineness” is still not fixed by the structural fact. R157's semantic residual remains. `B_min` must independently fix why this selected experiential structure, rather than another transported coordinate, merits that familiar label.

## 7. Why this is not a new threshold for experience

The witness contract answers a selected application question: whether one body-frame relation is installed. It is not a premise of C1 and is not required for basal experience. A process can lack the selected relation, lose it, or leave it unresolved while other organization remains. No introspection, self-model, language, report, recurrence, global integration, accurate prediction or continuation control is added to the definition of basic experience.

The body-frame relation also does not identify a unique owner. Nested and overlapping processes may each instantiate differently typed relations. The contract binds claims to one declared bearer and interval; it does not exclude other actual organizations.

## 8. Four retained thought-experiment families

### Ancestor and formation

An ancestor can already have experience under C1 before a stable body-frame loop forms. Later formation of a witnessed `Anchor–Bind–Use` path changes the internal coordinate available for mineness interpretation; it does not mark the onset of experience. Role: separates formation of a selected coordinate from basal consciousness.

### Abacus and calculator

An external calculator can mirror every tested answer while its register is not used by the agent. Moving that register onto the actual consumer path makes an organizational difference even if outputs remain equal. Conversely, an internal unused copy does not become installed use by location alone. Role: exposes behavior and storage equivalence.

### Human-realized agent

People can realize a higher-level agent whose body-frame variable is distributed across communication and physical action. The relevant witness may live at the formation level rather than within any one participant, while participants retain overlapping organizations. W1 must therefore bind the exact `P,r,k,U`; no exclusive extra master is required. Role: tests bearer and level typing.

### Copy, swap and memory

Copy a body map, swap its labels, or preserve all ownership sentences while routing consumers through a bypass. Reports and memories can remain fixed while actual use changes. Conversely, reports can change while the installed path remains. Role: separates installation, semantic reference, memory and language report.

## 9. Failures, limits and open obligations

1. The contract is sufficient but not shown necessary; another physical witness could support installation.
2. W2–W5 require actual apparatus, calibration, intervention fidelity, causal locality and a realization bridge; none was executed here.
3. Finite interventions cannot establish complete causal organization. Unmeasured redundancy, compensation and hidden paths remain possible outside the declared model.
4. Mediation/cut evidence can support the selected path only under its exclusion and consistency assumptions. Those assumptions are empirical, not consequences of C1.
5. The R161 population profile does not automatically supply a same-token intervention record; a future protocol must connect its trial-level measurements to this contract without averaging away identity.
6. `B_min`, familiar ownership/agency target evidence, complete neural realization and external anatomical reference remain open.
7. No necessity theorem, global theory comparison, proof-assistant certification or exhaustive literature priority search is supplied.

## 10. Contribution and next question

The substantive contribution is a typed positive bridge with honest stopping points. Population evidence can constrain a candidate, a same-token mediator/cut design can support actual installed use, C1 can transport that installed structure, and `B_min` remains separately responsible for familiar mineness semantics. The bridge blocks two shortcuts: group effect to individual mechanism, and structural counterpart to familiar label.

The next exact question is how to instantiate W2–W5 for one ethically admissible trial architecture that preserves token identity across anchor, mediator and consumer interventions, including explicit redundancy and compensation alternatives. That architecture must state which observations would refute the selected installation candidate and which would remain merely unresolved; it must not reuse ownership report as a physical-role definition.
