# A4F gap ledger

## A4F-G1 — a source label can be self-attested

- **Location:** A4E event-witness option `(commit, selected source, value, time)`.
- **Impact:** blocks promotion from a source field to actual target-writer identity.
- **Counterexample:** a hidden writer emits the accepted label `target`; target and hidden report sets overlap.
- **Corrected:** require physical source-sensitive placement and whole-vector report-set separation.
- **Unresolved premise:** no actual source-bound witness has been installed.

## A4F-G2 — redundant logs may share one evidential root

- **Location:** proposed multi-channel corroboration.
- **Impact:** two matching files can be mistaken for independent evidence.
- **Counterexample:** one bus master or logger writes both target labels.
- **Corrected:** audit power/reset/clock/bus/DMA/logger/human ancestry, not file count.
- **Unresolved premise:** common-cause inventory for a selected device.

## A4F-G3 — source-agnostic independence proves only event occurrence

- **Location:** independent transition detector.
- **Impact:** prevents a valid A4E event witness from being overread as A4D source attribution.
- **Counterexample:** target and hidden commits both trigger the same read-only detector.
- **Corrected:** split event and source coordinates explicitly.
- **Unresolved premise:** source-specific post-final-arbitration sensing.

## A4F-G4 — declared tap independence is a physical premise

- **Location:** A4F-P1 and WIP clauses 4–6.
- **Impact:** the only identifying finite row fails if the hidden writer can replay the target vector or inject downstream.
- **Counterexample:** common reset/controller replays `(commit=1,target=1,hidden=0)` after a hidden actuation.
- **Corrected:** whole-vector forge/replay/suppress/reset/re-time permissions are part of the source report sets.
- **Unresolved premise:** an installed platform with verified source-path and evidence-controller boundaries.

## A4F-G5 — device-relative source is not complete actual organization

- **Location:** R172/R173 application boundary.
- **Impact:** blocks inference to complete `K`, actual `RetBind`, `B_fam` or `H_way`.
- **Counterexample:** a perfectly attributed actuator transition occurs in a device whose broader constitutive organization or phenomenal target is unspecified.
- **Corrected:** formal delta remains 0/0/0 and the application stays disabled.
- **Unresolved premise:** same-instance complete actual-token admission and independent phenomenal bridge.

- **Impact:** no local enumerator closes QC10, IA-QC11, QC12/13, R191 normalization or whole-history proof depth.
