# Bearer-centred route contract

## 1. Fixed domain

Fix one admitted actual process token `P`, interval `I`, complete signature `K`, event grain `e`, external task coordinate `x`, live bearer-anchor state `a`, route occurrence `r`, and named consumer `c`. External target, bearer convention, interface and allowed interventions are fixed before comparison. A counterfactual installation is not the numerically same token with contradictory states.

`x`, `a`, `r` and `c` must be physically grounded, correctly sorted objects or occurrences in the declared actual organization. A body label, analyst coordinate, stored value, output, report or finite trace does not install them.

## 2. Candidate relation

`BearerCentredRoute(P,I,K,e;x,a,r,c)` (`BCR`) requires all of:

1. **BIND:** all terms and interventions concern the same `P/I/K/e` binding and one named route/consumer interface.
2. **ANCHOR:** `a` is a current bearer-state anchor used during `e`, not a prerecorded or observer-supplied label.
3. **ENCODE:** one actual event in the declared route forms `r` from the target and anchor relation.
4. **USE:** the named current consumer actually reads the route occurrence and live anchor in producing its declared downstream coordinate; a parallel recorder is insufficient.
5. **A-CONTRAST:** for at least one admissible matched anchor intervention holding the external target fixed, the route occurrence changes in the declared representation space.
6. **R-CONTRAST:** for at least one admissible matched route intervention holding the anchor fixed, the named consumer's downstream coordinate changes.
7. **JOINT:** a predeclared matched co-transformation of anchor and route preserves the downstream coordinate while each single intervention supplies its nontrivial contrast.
8. **ORDER:** anchor availability, encoding, route arrival and consumer use occur in the declared current-event order before the downstream coordinate is fixed.

`all_of=[BIND,ANCHOR,ENCODE,USE,A-CONTRAST,R-CONTRAST,JOINT,ORDER]` is conjunctive. The one-bit checker illustrates this relation but does not establish it in a physical token.

Accuracy, task success, low effort, learning history, report, self-model, language, anatomical membership and exclusive causal sufficiency are not conjuncts. They may be held fixed, studied separately or added for another target. A route can be bearer-centred and wrong; a bypass may coexist. Conversely, a successful route may use world coordinates and fail `BCR`.

## 3. Exact one-bit witness

Let `x,a,r,y` be bits, with actual encoder `r=f(x,a)` and current consumer `y=g(r,a)`. Impose only perfect task recovery `y=x` for every `(x,a)` in the matched finite comparison.

For each anchor value `a`, perfect recovery forces the section `f_a` to be a bijection on one bit. Hence there is one bit `c_a` such that

`f_a(x)=x XOR c_a` and `g_a(r)=r XOR c_a`.

There are exactly four perfect pairs, indexed by `(c_0,c_1)`:

- if `c_0=c_1`, the route is anchor-insensitive (world-coordinate identity/complement);
- if `c_0!=c_1`, the route is bearer-centred (XOR/XNOR with the live anchor).

Thus two perfect pairs are bearer-centred and two are not. All four use `r` and give identical output `y=x`. Flipping `a` at fixed `x` changes `r` only in the bearer-centred class. Co-flipping `(r,a)` preserves `g` only in that class.

This is an elementary Boolean normal-form result, not a new group-action theorem. Its use here is to isolate a bodily/action organizational contrast at fixed output.

## 4. Required counterexamples

- **Vacuous symmetry:** constant `f=0,g=0` is invariant under a joint flip in a trivial sense but fails route use and target recovery. `JOINT` without both nontrivial contrasts is insufficient.
- **Direct bypass:** `y=x` can be generated while `r` is ignored. Output equality and even a logged route value do not establish `USE`.
- **Copied or stale anchor:** a copied `a'` can reproduce values in a restricted history while failing the current live-anchor binding and intervention order.
- **Body-label/world-route:** an anatomical label can coexist with `f(x,a)=x`; membership and wording do not establish bearer centring.
- **Reflex twin:** a reflex controller can satisfy `BCR`; deliberation, conceptual self and report are not entailed.
- **Overlap:** one larger actual process may contain multiple concurrent, partly overlapping centred routes. `BCR` does not select one exclusive owner.
