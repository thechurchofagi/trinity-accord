# R122 B2 protocol frozen before biological outcome inspection

Date: 2026-10-06. This protocol is an independent, deliberately conservative reanalysis of cumulative-evidence decoding. It is not an exact reproduction of Figure 2C. Neural outcomes were not inspected to select its settings.

## Scope and fixed analysis

- One model per recording session and anatomical region. No pseudo-population made by joining neurons from different recordings. Units are the simultaneously recorded FOF and ADS populations; map DMS to ADS and M2/FOF to FOF only as justified by the original region metadata.
- Eligible behavior rows: non-violation accumulation trials with an observed left/right choice, valid stimulus time, and auditable click arrays. Keep errors and exact evidence ties. Preserve original row identities and all exclusions.
- Target: externally specified cumulative right-minus-left click count at successive 50 ms endpoints. This is a stimulus statistic, not a measured phenomenal state and not the choice-conditioned posterior accumulator used in the paper's tuning-curve analysis.
- Neural observation window: each target bin is matched to the 50 ms neural window delayed by exactly 100 ms. Rate smoothing is a causal half-Gaussian with sigma 75 ms, truncated at four sigma, evaluated separately for each trial. Smoothing includes only the current and preceding spike bins, with explicit prestimulus padding; it never mixes trials.
- Main analysis includes only neural bins ending during the stimulus (and before center-poke exit if a valid exit time is available). This removes the delayed tail after the decision stimulus. The supported time domain is explicitly narrower than the author's delayed-offset mask. No claims about sub-50-ms latency or the final unobserved evidence state.
- A recorded/unrecorded indicator, when available, is honored. No artifact or absent unit observation is silently interpreted as zero spikes. Record availability exclusions and missing availability metadata.
- Schema-only amendment before decoding outcomes: some actual files have no `recorded` variable and contain NaN runs in spike vectors. Preserve the NaN-run brackets from adjacent finite spike timestamps. Exclude any trial whose causal-filter/readout support or stimulus firing-rate support overlaps any FOF/ADS candidate unit's bracket. This is a deliberately conservative inferred exclusion; the exact artifact cause or unavailable interval is not observed. Preserve all excluded trial and unit identities. Explicit `source_laser_isOn` must be zero when present. Missing center-poke exit timestamps are reported; the stimulus-offset cutoff still applies.
- Fixed nested validation: five outer contiguous blocks of whole trials and three inner contiguous blocks of whole training trials. The outer and inner trial identities are disjoint by construction. If fewer than five trials exist, fail clearly; with fewer than 50 eligible trials report insufficient data rather than a population conclusion. Identical trial folds are used for both regions.
- Within each training split, retain units with stimulus firing rate greater than 1 Hz, match region counts by a deterministic outcome-blind random subset, and fit feature means/scales on that training split only. This differs intentionally from author code that computes full-session side-selectivity and normalization before cross-validation.
- Lasso regularization candidates, fixed in advance: `[0.01, 0.03, 0.1, 0.3, 1, 3, 10]`; choose lowest validation mean squared error, with a tie preferring greater regularization. Max iterations 20,000; tolerance 1e-4. Save warnings and iteration counts. No hyperparameter search based on final decoding outcomes.
- Seed 122. Preserve selected unit identities, train/validation trial identities, chosen alpha, means/scales and final outer-fold coefficients.
- Outputs: out-of-fold predictions, Pearson correlation, R-squared and RMSE, both pooled and by elapsed target time. Also show left-choice and right-choice strata separately. A predeclared low-dimensional eventual-choice/time/duration baseline is fitted on training rows only, as a descriptive anti-triviality reference. Neither conditional decoding nor this baseline establishes causal use.
- Fit each session separately. Aggregate region contrasts first within rat and then across the five rats; retain session values. Trial bins and individual neurons are not independent biological replicates. Five-rat uncertainty is limited. Do not infer equivalence from a non-significant difference.

## Source discrepancies recorded before analysis

The final Neuron paper (PDF pages 17–19, especially e2) specifies 50 ms bins, a 100 ms neural encoding lag, Gaussian sigma 75 ms, matched population counts, L1 regression, and nested 10-fold validation. The pinned source `figure2/fig2_helpers/evidencedecoding.py` instead executes shuffled folds on flattened time-bin rows. Its helper normalizes using the full session. A `Tshift=100` parameter and delayed onset column are created, but the executed neural alignment remains `clicks_on`; only the offset mask is delayed. The figure assembly also computes time without adding the shift. These observations concern the inspected executable path at commit `39d056fb12f688034b543d9ac8b7406a58ad0f77`; they are not claims that all unpublished analysis paths behaved identically.

## Inference ceiling

B1 provides a behavioral temporal weighting estimate; B2 provides selected stimulus decodability and timing diagnostics. Neither reconstructs a complete biological transition law, identifies the neurally used causal state, or provides a matched internal intervention. Under the R119 certificate, C2 and C3 therefore remain open after B1/B2 alone. FOF→ADS silencing, whole-region silencing, an external evidence pulse and an instantaneous accumulator reset are different ports. Matching their labels as early/late does not transport the intervention. T2 cannot be marked closed, and T3, ordinary phenomenal labels, fear and valence are not measured here.
