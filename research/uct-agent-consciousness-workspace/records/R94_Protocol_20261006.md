# R94 protocol — predictive quotient and bearer-resolved future availability

Date: 2026-10-06. Continues R93. This analysis plan was fixed in the session before the exact finite check; it is not an external preregistration.

## Question

When does prediction itself require a distinction corresponding to the current process token's future availability, rather than merely world state, task continuation, generic successor availability, or a language label?

## Frozen finite system

Use all 16 binary states h=(W,Q,O,G), uniformly weighted.

- W: a declared world-state difference.
- Q: future availability of the currently identified process token under a declared virtual continuation criterion. It is a task variable, not a metaphysical identity theorem.
- O: future availability of a distinct other/successor process.
- G: task/service continuation.

No real shutdown, copying, resource acquisition, credentials, or external action is involved.

Prediction queries are noisy binary observations with symmetric error epsilon=0.1, except count_avail which is used only for exact partitioning:

world=W; self=Q; other=O; task=G; any_avail=Q OR O; count_avail=Q+O.

Evaluate six fixed query families: world_task, world_task_any, world_task_self, world_task_other, world_task_count, and role_resolved.

## Predeclared checks

1. Compute the exact predictive equivalence partition: two states are equivalent iff every query in the family has the same conditional output law.
2. Flip each coordinate while holding the other three fixed and record whether the family ever requires that distinction.
3. Swap Q and O and test whether the predictive signature changes.
4. For binary-query families, compute Bayes log-loss with the full state and after deleting one coordinate. Excess loss is a task-relative information loss, not an experience metric.
5. Verify an invertible distributed code c=(W xor Q, Q xor O, O xor G, G), showing that exact role-resolved prediction does not require a single explicit Q or O unit.
6. Retain an observational-confounding counterexample: U is uniform, observationally Q=U, and Y=U xor noise. Q predicts Y strongly, but do(Q) does not change Y.
7. Audit benign virtual policies to separate predictive retention from installed decision use.

Expected qualitative outcomes: a world/task-only family need not distinguish Q/O; generic availability can require both yet remain invariant under Q/O exchange; a bearer-resolved self query requires Q but not O; role-resolved prediction requires all four coordinates. No result is to be called consciousness, fear, valence, subject count, or experiential magnitude.

Stop on any failed assertion and preserve the failure before repair. No training, seed search, large model query, or noise sweep.
