# Same-bearer factorial installation contract

## Frozen objects

Fix before outcome access one actual bearer, one enacted-event kind and grain, one current consumer, one constitutive route boundary, one response code, one time window and one admission signature. Their tuple is the invariant slice `K`.

For an actual event token `x` in that slice, let:

- `R(x) in {0,1}` mean that the declared retained context-to-continuation relation is actually consumed in the event;
- `F(x) in {0,1}` mean that the declared present-fit condition actually holds;
- `W_R(x)` and `W_F(x)` be pre-outcome evidence channels for those two facts.

`R`, `F`, their assignments, their witnesses, the delayed judgment `J_cont`, the selected experiential target `H_cont`, complete organization and C1 are different objects.

## Full crossing criterion

Let `V_K` contain only tokens satisfying the frozen bearer/event/consumer/route/response/time/signature contract. A valid same-bearer 2×2 requires

`{(R(x),F(x)): x in V_K and Fidelity(x)} = {0,1}^2`,

where `Fidelity(x)` requires assignment-to-actual agreement, witness-to-actual agreement, pre-outcome acquisition and evidence independence from both the assignment label and response endpoint.

Because the codomain has four elements, this is equivalent to the valid image having cardinality four. Four nominal trial labels or four requested settings are insufficient.

## Structural-coupling obstruction

If throughout one invariant slice `F(x)=g(R(x))` for a single-valued Boolean function `g`, the image has at most two elements. The full crossing is impossible in that slice. This does not show that relation use and fit are universally inseparable; it shows that the proposed realization does not implement the claimed factorial contrast.

## Compensators

A compensator may make an otherwise missing cell physically reachable. It is admissible for this comparison only if it preserves `K` and does not write the response endpoint or generate either witness from the assigned label. If it changes the enacted event, consumer, constitutive route or response meaning, it creates a different slice. Pooling such slices does not establish one same-bearer 2×2.

An invariant-preserving compensator can establish installability, but not intervention selectivity, phenomenal orientation, C1, or the truth of either `B_relation` or `B_fit`.

## Independent fidelity

Each cell must have same-instance evidence that the intended organizational state occurred. A command, condition name, training schedule, logged request or questionnaire label is not automatically evidence of actual relation use or fit. The evidence need not be perfect, but its error model and source must be independent of the response whose interpretation is at issue.

## Decisions

- `INSTALLED_FACTORIAL`: one invariant slice has all four valid actual cells.
- `STRUCTURALLY_COUPLED`: a declared within-slice law restricts the image below four.
- `FIDELITY_FAILURE`: four assignments exist but one or more cells lack valid actual/witness binding.
- `COMPARISON_BROKEN_BY_COMPENSATOR`: apparent cells require changing `K`.
- `NOT_INSTALLED_TERMINATE_CURRENT_CANDIDATE_COMPARISON`: present records contain no bounded installation. This terminates the current candidate application, not all future designs and not experience or mineness.

No post-outcome relabeling, new grain, new bearer or changed response code may rescue a failed frozen design.
