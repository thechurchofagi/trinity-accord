## Four qualifications that must stay open

### EIP-NQ1 — distinguish the two C4 identifiers

Ledger `EIP-C4` is a source-bounded empirical assessment. Map node `EIP:C4` is a conditional UCT interpretation. No explicit claim-to-node mapping connects or distinguishes these meanings. They must not be treated as synonymous simply because the suffix matches. A subsequent normalization should supply an explicit mapping and preserve the empirical assessment separately from the guarded UCT application. Neither claim is thereby refuted; the problem concerns identity and downstream coverage. The map audit's sentence “C4 has no actual witness” is consequently ambiguous about which C4 is intended. [Ledger `/claims/3`; map `/nodes/5`; map audit.]

### EIP-NQ2 — global nonidentification is not ambiguity in every fiber

The map's “All rows” quantifier must mean that the displayed observation map fails to identify `G` over its full domain. It cannot mean that each possible observation fails to identify `G`:

| Observation `(S,arrival,U,Y)` | Possible `G` | Qualification |
|---|---|---|
| `(0,0,0,0)` | 0, 1 | Gate configuration ambiguous; see NQ3 |
| `(0,0,1,1)` | 0, 1 | Gate configuration ambiguous; see NQ3 |
| `(1,1,0,0)` | 0 | This fiber identifies `G=0` in the stipulated model |
| `(1,1,1,1)` | 0, 1 | Delivered-carrier read/gate twin preserves the core result |

The correct global statement is that there exist two admitted rows with identical observations and different `G`; no single function of ordinary observations recovers `G` for every row. The exclusive probe is a sufficient method under its declared premises. This finite argument does not prove that sole-writer exclusion is necessary for every possible identification method or every individual observation. [Map `EIP:C1`; EIP exact results; independent check.]

### EIP-NQ3 — gate configuration and actual intake require separate types

The files label `G` as actual gating/reading of the selected carrier but include `S=0,G=1`. If `S=0` means that the selected event is not delivered and no retained-token route is admitted, such a row can encode an enabled gate, not occurrence-level intake of that event. One conservative normalization is to interpret `G` as the configuration and introduce the **model-defined** intake indicator `I=S∧G`; another is to restrict actual-intake assertions to `S=1` and specify any retained-token interpretation separately.

Under the first normalization, the three ambiguous gate-configuration fibers become one ambiguous intake-indicator fiber. Both absent-delivery fibers fix `I=0`. The delivered-carrier counterexample and exclusive-probe calculation remain valid. This is a proposed semantic qualification, not a new observed read, hardware result or adopted EIP replacement. DVC's warm-buffer examples also prevent silently assuming that absent current delivery means no old token can be consumed in an unspecified physical implementation. [EIP variable definitions and eight rows; DVC EVENT_BUFFER_CONTRACT and C1.]

### EIP-NQ4 — narrative guards are not discharged typed premises

`EIP:R1` lists only the episode and evidence-partition nodes in `all_of`; the Boolean interface is carried in narrative text. `EIP:R2` lists C1 and the episode, while the delivered carrier, exclusion of alternative writers, faithful readout, intervention selectivity and timing requirements remain partly in the conclusion or prose. `EIP:R3` lists C3 and A:C1 while actual-bearer admission, complete signature, constitutive relation and target-semantic admission remain narrative guards.

If these edges mean availability of the entire guarded theorem, their conclusions must remain the guarded statements. They cannot discharge an actual instance. Before any rule is used to infer actual identification or an experiential counterpart, the independent guards need explicit typed premises, simultaneous binding and actual evidence for the same installation and episode. The structural audit's PASS does not establish that work. `EIP:C2` and `EIP:C4` correctly retain much of this caution in their statements; this review preserves it instead of activating the edges. [Map R1–R3; instrument contract; research note §§3,7; map audit.]
