# Reusable shadow-consumer protocol

**Purpose:** validate one digital consumer's supplied inputs and timing before interpreting its nominal gate factorial. This is a finite-model/engineering protocol, not an intervention on a person's neural consumer.

## Frozen contract

Fix the actual candidate device, two source ports, trial/episode interpretation, source-token identities, gates, buffer reset and writer law, capture windows, snapshot mechanism, consumer executable, read instrument and clock relation. Keep the plant and tactile stimulus path independent of the proposed shadow branch. The physical application of every item remains OPEN in this checkpoint.

## First trial: reject a false gate factorial

Preload both buffers with a previous trial's payload-one tokens. Request each availability mask 00,01,10,11, permitting new capture only on enabled lanes. An eager AND consumer that reads uncleared buffers returns one in every cell. This is a failed consumer-input factorial even if every gate command was acknowledged.

Repeat with explicit invalidation before the current captures. Enabled sources supply their identified current tokens; disabled cells remain absent. For marker payloads one, the AND outputs become 0,0,0,1. Check origin IDs and actual reads, not only those output values. Changing an enabled payload to zero keeps the source supplied; it does not change the availability cell.

## Second trial: separate arrival, capture and consumption

Use one delayed channel with the same numeric value as its cached predecessor. Issue the current token but let it arrive after the capture and consumption. An issue receipt and a correct output coexist with the wrong actual source epoch. An actual-port arrival/capture record must reject this trial.

For the reproducible model, enumerate the six once-only arrival/capture/commit/consume operations. Report the full denominator 720 and its mutually exclusive partition: 6 fresh pairs, 360 precommit-consume rejections and 354 matched-value but wrong-token executions. Do not interpret this enumeration as a frequency distribution of physical devices.

## Third trial: preserve a valid asynchronous pair

When the two actual robust capture windows do not overlap, capture each separately, preserve both, and commit only after their same-episode identity has been established. A shared label is insufficient. Verify no buffer overwrite, wrong source, clock ambiguity or missed deadline. A later state sample changes the predictive time target; it cannot be called a prediction of the already produced consequence.

## Countermodel controls

Retain the nine witnesses in EXACT_RESULTS.json. They cover warm caches, closure after capture, delayed arrival, postcommit overwrite, mixed epochs, source swaps, false epoch metadata, gate-label reflexes, bypass intakes, and nonoverlapping capture windows. The eager/short-circuit distinction is inherited from MPC; readiness of both inputs does not prove that the particular algorithm reads both.

## Human endpoint boundary

Select tactile-comparison PSE prospectively if that is the intended perceptual target; keep independently fitted sigma and source-labelled JND separate without assuming that they are numerically identical. This is a future design choice, not retrospective preregistration. A read-only shadow gate does not intervene on the participant. Any proposed use of digital gate effects to explain human PSE requires a separate actual causal or measurement bridge. Agency, ownership and H remain unmeasured. The eligibility rule for a digital trial is not an experience-existence criterion.
