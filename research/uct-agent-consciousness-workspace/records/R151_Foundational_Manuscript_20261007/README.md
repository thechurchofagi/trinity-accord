# Research package - version 0.2

Read `Experience_Intelligence_and_Self_v0_2.md` or `output/pdf/UCT_Experience_Intelligence_Self_v0_2.pdf` first. The 14-page manuscript integrates definitions, the UCT identity commitment, three scoped results, four thought-experiment families, AI applications, objections and the source/meaning/purpose audit method.

`PROOF_AND_SOURCE_LEDGER.md` maps manuscript claims to the existing formal graph. `MANUSCRIPT_CLAIMS.json` and `CROSS_CONSISTENCY_REVIEW.json` provide 13 manuscript units and 24 scoped relation reviews. `NODE_REVIEW_INDEX.json` and `RULE_REVIEW_INDEX.json` cover the whole graph structurally; they do not certify every semantic relation. `AUDIT_SUMMARY.json` records explicit coverage gaps.

Run `python verify_manuscript.py` within a checkout containing the pinned sources to repeat the focused finite and structural checks. `EXACT_AND_STRUCTURAL_CHECKS.json` records this run. `render_pdf.py` uses installed Pandoc and XeLaTeX; `PDF_QA.json` records the rendered inspection. Published source bytes are preserved.

Before subsequent research, read `../../RESEARCH_MASTER_GUIDE.md`. The mathematical graph remains R149-v1.0 (391 nodes, 188 rules); R151 adds a manuscript and audit layer, not new mathematical nodes. T1-T3 are manuscript-local labels; T2 is not the separate biological-AI correspondence certificate.

This is a versioned research manuscript and review package. It makes no claim of a new DOI, independent peer review, exhaustive historical priority, or globally certified semantic consistency.
