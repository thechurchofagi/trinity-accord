# Same-event anchor-route intervention contract

Version: A4P-ARIC-v0.1.0
Status: disabled prospective application; no human or embodied-device token is installed.

## 1. Target and frozen grain

The target is the organizational proposition `RouteReadsAnchor(P,I,r,a)`: during one declared event of bearer `P` in interval `I`, the already learned route `r` consumes the current bearer pose/proprioceptive anchor `a` to produce a predeclared coordinate-transform signature. It is not endpoint success, a body/tool label, ownership, agency, report or `H_cf`.

Before outcomes, freeze the bearer boundary, event grain, route grain, anchor port, target/tool geometry, plant, response semantics, clock order, writer/controller inventory and transform readout. A route trained in one task is not silently treated as the same route in another.

## 2. Three comparison strata

Run the intervention package separately in:

1. a limb route;
2. an independently grounded frame-incorporated tool route;
3. a matched tool route for which frame incorporation is independently absent.

The first two may test frame invariance; the third may test body/action-frame specificity. These labels do not establish `EnactedFrameBind`. If actual route equivalence or incorporation classification is unavailable, report only the successfully grounded stratum.

## 3. Four event conditions per stratum

| Condition | Anchor perturbation | Route anchor input | Required interpretation |
|---|---|---|---|
| no-anchor baseline | absent | native | reference transform |
| anchor/native | present | native | perturbation-dependent transform may appear |
| anchor/block | present | faithfully cut before route consumption | target transform must disappear if the route is necessary |
| anchor/rescue | present | native input remains cut; calibrated value enters the same consumer interface | target transform must return if interface-specific consumption is sufficient |

External target and tool geometry/state remain measured and fixed across the three anchor-present conditions. The anchor intervention must be independently oriented and must not be defined by the endpoint or report.

## 4. Predeclared response signature

The primary response is an event-level coordinate-transform signature `T`, not generic success. In the finite binary abstraction the target pattern is:

```text
no-anchor, anchor/native, anchor/block, anchor/rescue = 0,1,0,1.
```

For continuous data, direction, latency window, coordinate frame, tolerance and equivalence margins must be frozen before unblinding. Endpoint and report are secondary evidence and cannot substitute for `T`.

## 5. Joint identification premises

The pattern identifies declared route contribution only if all premises hold on the same token package:

- `P_same`: same bearer, event grain, learned route, anchor port, plant and response semantics;
- `P_ext`: external target/tool state fixed or exactly counterbalanced independently of the response;
- `P_anchor`: intervention changes the intended bearer anchor with independently verified sign and timing;
- `P_block`: cut is local, timely and faithful at the declared route input;
- `P_rescue`: rescue enters the same interface with the declared value and does not directly write output;
- `P_closed`: ordinary compensators and intervention-aware alternate controllers cannot generate the accepted transform vector;
- `P_event`: current commit, source and chronology satisfy the A4D–A4G writer/event/witness requirements;
- `P_readout`: `T` has frozen coordinate semantics and is not inferred from the desired conclusion.

These are simultaneous `all_of` premises. A failed premise invalidates the route inference; it does not count as evidence that the bearer has no experience.

## 6. Bounded finite result

The exact checker enumerates 32 worlds over route use, an ordinary compensator, an intervention-aware hidden controller, block fidelity and rescue fidelity. The `0,1,0,1` observation fibre has seven worlds and contains both route-use values. Under `P_closed` plus faithful block and rescue, the declared submodel has two worlds and the target fibre is the unique route-use world.

Thus the signature has conditional identifying force inside a closed declared model. It is not self-authenticating evidence that the model is closed. An intervention-aware hidden controller reproduces the entire pattern with the target route idle.

## 7. Stop and return rules

Stop with a typed non-result if controller closure, intervention fidelity, same-interface rescue, current-event source, incorporation classification or route equivalence is not independently grounded. Do not repair a failed design by changing the route grain, endpoint or frame label after outcomes.

Return to the UCT main line only with an actual same-instance organizational token. C1 and R157 would then conditionally transport its grounded internal relation. `B_cf`, `H_cf` identity/orientation and report reliability remain separate open obligations.
