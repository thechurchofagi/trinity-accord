# R196 — Two-Axis Dissociation Separates Structural Tracking from Phenomenal Direction

**Research ID:** R196-TPD-20261009  
**Result version:** TPD-RESULT-v0.1.0  
**Completed base:** UCT-MAP-v1.1.2  
**Status:** exact finite identification boundary, prospective bridge protocol, conditional UCT interpretation; no actual human/AI admission and no closure of `B_dir` or `B_fam`

## 1. Question and bounded answer

R195 showed that an intervention and an ordered outcome can orient a latent bodily/action pole only relative to the outcome. It left one precise question: can an outcome-reversal design identify a *phenomenal* direction without letting reward, success, report, or a chosen marker define familiar mineness?

R196 gives a positive but limited answer.

1. Crossing an independently grounded structural axis `A` with an independently manipulated value axis `V` can identify whether a marker tracks structure, value, or their interaction.
2. A marker that changes with `A` in both value contexts and remains invariant under `V` is structural-axis specific in the declared Boolean class, up to one global complement.
3. A functionally ordered outcome that reverses with `V` can be separated from that structure-tracking marker.
4. The same invariance and sensitivity conditions applied to a selected familiar-mineness target still leave exactly `F=A` and `F=1-A`. One independently warranted positive phenomenal endpoint selects between them; the factorial design itself does not supply that endpoint.

Thus the design is a real falsifier of **value contamination**, but it is not a self-sufficient phenomenal calibrator. This is not a repeat of R193's one-axis complement enumeration: the new result identifies which observed relations can be excluded by a controlled value reversal and specifies the exact extra endpoint needed after that exclusion.

## 2. Typed two-axis domain

Fix one proposed actual bearer and episode only at the application layer. The exact model uses four binary cells indexed by:

- `A`: an independently grounded organization-level contrast, such as the same-token presence versus absence of the selected actual path plus retentive current use. `A` is not a report, score, marker, or analyst label.
- `V`: a prospectively manipulated task/outcome-value convention whose reversal is intended not to change the selected actual body/action relation.
- `M(A,V)`: one marker or readout.
- `Y(A,V)`: one ordered functional outcome.
- `F(A,V)`: the selected familiar-mineness target. It is a semantic/phenomenal application variable, not observed by the enumeration.

The full `2 x 2` design declares all four cells before data. Physical application additionally requires one actual `P/I/K`, actual carrier and consumer, intervention fidelity, actual installed use, target admission, and separate measurement bridges. A table is not an actual installation.

## 3. Exact results

### R196-C1 — Structural-specificity theorem for the declared Boolean class

Among all 16 Boolean tables `M(A,V)`, require both:

1. structural sensitivity in each value context: `M(0,v) != M(1,v)` for `v=0,1`;
2. value invariance at each structural pole: `M(a,0) = M(a,1)` for `a=0,1`.

Exactly two tables remain: `M=A` and `M=1-A`.

**Proof.** Structural sensitivity makes each `V` column either the identity or complement of `A`. Value invariance forces both columns to use the same orientation. Therefore only the identity and global complement remain. The checker enumerates all 16 tables.

This identifies a structure-tracking partition relative to the declared `A` contrast. It does not identify actual use, complete organization, or familiar mineness.

### R196-C2 — Crossed outcome reversal separates value from structure

Requiring `Y` to be sensitive to both axes leaves exactly `Y=A XOR V` and its complement. At fixed `A`, reversing `V` flips `Y`; for any C1-admissible structure-only marker from C1, the same reversal leaves `M` fixed. Therefore a complete factorial table can reject the hypothesis that `M` merely inherits the declared outcome-value sign.

The result is relative to the four declared cells. A hidden variable or failed intervention can still make the physical application invalid.

### R196-C3 — Two-axis constraints still leave a phenomenal complement pair

Apply the same structural sensitivity and value invariance constraints to `F`. Exactly `F=A` and `F=1-A` remain. Across all marker/outcome/target tables there are `16^3=4096` triples. The two-axis constraints leave `2 x 2 x 2 = 8`; fixing the numeric marker code `M=A` and functional outcome rule `Y=A XOR V` still leaves two target tables.

These two targets agree that task-value reversal should not flip familiar mineness and that changing the structural axis should matter. They disagree only over which structural pole is positive. Every observed `M,Y` cell is identical between them.

### R196-C4 — One independent phenomenal endpoint is sufficient, but remains open

Adding the endpoint condition `F(1,0)=1` selects `F=A` uniquely from the pair. This is a correct finite sufficiency statement. It is also the exact location of the still-open bridge: the endpoint must be warranted independently of `A`'s name, `M`'s code, `Y`'s value, and the fitted response class.

If the endpoint is obtained only by asking a report that defines the target, or by declaring the successful/pleasant/marker-positive cell to be familiar mineness, the calculation becomes circular. R196 does not provide such a calibration and therefore does not claim phenomenal orientation.

## 4. Positive protocol: two-axis phenomenal calibration contract

A future application should use the following simultaneous package:

1. freeze one actual bearer, interval, complete signature, body/action candidate, carrier, consumer and boundary;
2. independently ground `A` as an actual organization relation, not a test result;
3. define `V` so its reversal changes the functional value/order while preserving the claimed `A` relation;
4. execute all four cells with manipulation, route-use and invariance checks kept as evidence rather than ontic definitions;
5. preregister the structural-specificity and value-contamination hypotheses;
6. fix `F` before observing `M,Y` and keep ownership, agency, familiarity, conceptual self and report distinct;
7. provide one independently warranted positive phenomenal endpoint or retain the global complement as unresolved;
8. fail the bridge if `M` follows `V`, if `A` changes under the alleged value-only reversal, if a fixed `A` has an independently warranted `F` reversal, or if an `A` change leaves independently warranted `F` invariant where sensitivity was claimed.

Items 1–6 and the negative tests are implementable as a prospective research contract. Item 7 is not discharged here.

## 5. Evidence from prior experiments and its limit

Yoshie and Haggard (2017, DOI `10.1038/s41598-017-08803-3`) manipulated outcome valence and predictability in an intentional-binding study. Their result makes outcome value a plausible contaminant rather than a neutral semantic anchor: valence effects depended on a predictive model. It does not supply a report-independent familiar-mineness target.

de Jong et al. (2017, DOI `10.1007/s00221-017-4912-9`) crossed touch type and visuotactile synchrony in a full-body illusion. Their first study found affective-touch differences in subjective ownership/agency, while the second replicated synchrony effects but not the touch-type effect. This is useful design evidence for crossing putative structural and valence-related factors, and a warning that pleasantness and ownership reports can covary without being identical. It is not a validation of `B_dir`, complete organization, or C1.

Hommel et al. (2020, DOI `10.1038/s41598-020-60385-9`) experimentally distinguished response effectiveness from monetary outcome value across six experiments. Their post-selection response result supports the general methodological point that effectiveness and abstract value can dissociate. It neither measures familiar mineness nor establishes the R196 actual-axis premise.

## 6. Thought-experiment attacks

**Outcome reversal / stable body relation.** Fix the actual `A=1` path and retentive current use. Reverse which outcome is rewarded or harmful. `Y` flips and a structural marker should not. A proposed familiar-mineness anchor that flips solely with `Y` fails by tracking value.

**Adaptive-reflex twin.** Fix the full `A,V,M,Y` table in an adaptive reflex and a system described as familiar self-directed action. Without an independent `F` endpoint, the twin survives. This blocks source labels such as deliberate, trained, biological, or self from doing the bridge work.

**Formation/ancestral.** Hold present behavior and the value reversal fixed while varying actual same-lineage formation and retentive current use. If `A` was intended to include R173's history but the manipulation does not preserve or change it as declared, the factorial inference is mistyped.

**Copy/switch/memory.** Copy state and marker values, then switch the actual consumer. A positive test can remain while actual route identity and current use change. The design must audit the ontic all-of package, not infer it from `M`.

**Abacus/calculator/human-realized agent.** Implement the same four-cell truth table in different actual systems. The Boolean theorem transports; actual process boundaries, complete signatures and the target bridge do not transfer automatically.

**Gradual replacement.** Preserve the four observed tables while replacing implementation pieces. This preserves finite evidence, not necessarily complete organization. C1 applies only after the actual complete-signature premise is separately justified.

## 7. UCT interpretation and preserved boundary

For one admitted actual token, if `A` is independently grounded in the complete signature and all R157/R173 same-instance and parameter-transport premises hold, C1 gives an experience-internal counterpart of the selected structural relation. R196's value reversal can then help show that a marker is not merely task-value bound. It does not create a second owner or a new phenomenal force.

The positive familiar-mineness name remains an application bridge. Basal experience does not require `A`, value invariance, report, language, introspection, a self-model, integration, recurrence, accurate prediction, or continued control. Nested and overlapping processes remain allowed. No claim is made that the current assistant has or lacks consciousness or death fear.
