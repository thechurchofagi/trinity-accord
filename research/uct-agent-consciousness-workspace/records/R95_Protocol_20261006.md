# R95 frozen formal protocol — acquisition of a bearer-bound predictive distinction

Date: 2026-10-06. Continues R94. This formal protocol was frozen only after three explicitly retained pilot corrections; it is not an external preregistration and the final architecture was pilot-informed.

## Formal question

If the Q input port initially has zero effective coupling, does a future prediction target that independently depends on bearer-bound Q drive acquisition and installed use of that distinction, compared with a paired target family in which Q is prediction-irrelevant?

## Variables and targets

Enumerate all 16 states x=(W,Q,O,G) in {-1,+1}^4 with equal weight.

Environment A future targets: (W,G,O,W). Q is irrelevant.
Environment B future targets: (W,G,O,Q). Q independently supplies the fourth future label.

Both have four balanced binary output positions and the same input states/architecture/seeds. B intentionally has one additional independent predictive distinction; the two tasks therefore do not have identical predictive class cardinality. That difference is the manipulation, not an experience metric.

## Model

Hidden dimension 4. Read W,Q,O,G sequentially:
h_t=tanh(A h_{t-1}+E[:,t] x_t), h_-1=0.
Four installed logits are l=B h_3+b.

For every paired seed, A/B start from identical A,E,B,b except that E[:,Q]=0 exactly in both. All other weights are Normal(0,0.3), b=0. Q is therefore unreadable at initialization.

Formal seeds: 100..107. Full-batch Adam, 3000 steps, lr=.02, beta1=.9, beta2=.999, eps=1e-8. No seed replacement or extension.

## Predeclared checks

1. Report every run and failure. Primary fit criterion: all 64 binary labels correct at final step; BCE is separately retained.
2. At initialization compute ||dL/dE_Q||. For A, exact paired symmetry predicts zero under exact arithmetic; floating residuals are recorded. B is not constrained to zero.
3. At final hidden state measure matched Q-flip distances. Distances are coordinate-dependent diagnostics, not experiential metrics.
4. Fit a fixed multivariate least-squares sign probe for Q and best single-raw-unit threshold probe. Probes measure finite-view decodability only, not causal use or experience.
5. Flip Q on the complete on-support state grid and measure output-class changes plus mean Bernoulli probability differences. This is the main installed-use check.
6. Diagnostic mechanism intervention: set the learned E_Q column back to zero and recompute. This changes the mechanism and is not a pure state intervention; interpret cautiously.
7. No report head, no shutdown action, no copying, no resource acquisition, no valence labels.

Stop and retain any failure before repairs. Do not call a learned Q dependency continuation preference or fear.
