# A4B — Formation Effect and Actual Route Are Two Keys

## 1. Question and result

R173 requires an actual earlier occurrence to continue into, and be used by, a current consumer. A4A showed that randomized formation can identify a total effect without conditioning on post-formation descendants. The remaining issue is whether a formation effect by itself establishes the retained route.

It does not. The exact result of this round is:

> **A randomized formation effect and actual use of the retained formation trace are logically independent.**

Therefore a positive body/action-related account needs two distinct evidential keys:

1. **Formation key:** a pre-formation randomized contrast changes a declared later endpoint, estimated without matching or adjusting for post-formation descendants.
2. **Route key:** at a particular later event, the named consumer actually reads/uses the same-lineage retained trace, and a faithful trace-specific block changes that event as predeclared.

The conjunction is stronger than either key alone, but it remains an organizational result. It does not by itself identify familiar mineness, phenomenal ownership, a complete UCT signature, or C1's empirical truth.

## 2. Typed setup

Let:

- \(F\in\{0,1\}\) be a randomized pre-formation assignment;
- \(T_F\) be the retained trace formed under \(F\);
- \(D\in\{0,1\}\) be a later trace-read intervention, where \(D=1\) blocks the exact read;
- \(C_t\) be the named current consumer;
- \(J\) be a predeclared organizational endpoint at the test event.

For a declared intact test regime, define the randomized formation effect

\[
\tau_0=\mathbb E[J(1,0)-J(0,0)].
\]

This is total with respect to formation descendants: no descendant of \(F\) is conditioned on or adjusted away. It is explicitly conditional on the declared test regime \(D=0\), not a claim about every later environment.

For the independently randomized route probe, define

\[
I_{F\times D}=
\{\mathbb E[J(1,0)]-\mathbb E[J(1,1)]\}
-
\{\mathbb E[J(0,0)]-\mathbb E[J(0,1)]\}.
\]

A nonzero interaction is not route evidence by algebra alone. It supports the route claim only when the physical/software audit also establishes: the same bearer, an actual preceding occurrence, retained trace continuation, a named current consumer, an actual current read/use, and a faithful block with no direct route-independent action on \(J\).

## 3. Exact independence construction

The four finite models below realize every truth-value combination. In each row, \(M=F\) when the retained route is open and \(M=0\) when it is blocked.

| Model | Endpoint law | \(\tau_0\neq0\) | Route structurally used | Diagnostic role |
|---|---|---:|---:|---|
| A | \(J=F\), direct path only | yes | no | Formation without retained-route use |
| B | \(J=M\oplus F\) | no | yes | Route use cancelled at the endpoint |
| C | \(J=M\) | yes | yes | Both keys |
| D | \(J=0\) | no | no | Neither key |

Because all four combinations are satisfiable, neither key entails the other. Model B is especially important: an actual route can be used even when endpoint-level formation effects cancel. Model A blocks the converse error: a formation effect can travel by a direct path without the retained trace required by R173.

## 5. Thought-experiment battery

### 5.1 Ancestor / formation

Hold the mature task and test fixed. Randomize an early training environment. One lineage later uses a retained formation trace; another gains the same score through a direct mature shortcut. A formation effect distinguishes the lineages but does not decide which current route was used. The route key varies the exact retained trace at the current event.

### 5.2 Abacus / calculator

Hold the numeric answer fixed. An abacus-trained system reads a persisting bead configuration; a calculator emits the answer from a direct lookup. Equal output does not establish equal route. Blocking bead access changes only the abacus-route event when the block is faithful and no alternate display is available.

### 5.3 Human-implemented agent

Hold the software transition rule fixed while a human writes and later reads the retained bit. The software audit can establish the declared read and endpoint dependence, but the complete physical bearer includes human activity not exhausted by the JSON trace. This is the counterexample to upgrading a software route certificate into a complete physical UCT application.

### 5.4 Copy / switch / memory

Hold the retained value fixed while replacing its bearer and lineage. The foreign copy computes equally well but fails the declared same-bearer trace contract. Conversely, a same-lineage trace may be read even when cancellation hides its endpoint effect. Value equality, causal contribution and actual lineage are three different claims.
