Comparator-only zero difference across all probes diagnoses equal pure-route roots uniformly over unknown pairs iff the columns are pairwise distinct. The minimum is `ceil(log2(n))`, even allowing adaptive probes in the worst-case exact decision problem: follow the all-zero comparator branch and apply the same column-collision argument. If one actuator root is independently known, one complement probe suffices for `n>=2`.

On the all-zero branch, missing unit probe `e_i` leaves full set `N` and `N\{i}` indistinguishable. Unit probes attain the bound. This class change is a concrete caution against silently applying the logarithmic protocol to redundancy.
