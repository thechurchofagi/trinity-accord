# Thought-experiment matrix

| Family | Fixed | Varied | Role / counterexample |
|---|---|---|---|
| Matched-output exoskeleton | endpoint trajectory, contact and declared force envelope | natural torque, selected carrier delivery/read, intervention lineage | Shows output equality is partial and cannot identify actual consumption. |
| Redundant-writer twin | peripheral spike, central arrival, aggregate update and output | declared consumer gate `G` | Exact countermodel to arrival-plus-output identification. |
| Abacus / calculator | arithmetic answer and public report | implementing organization and carrier–consumer route | Prevents result identity from becoming organization identity. |
| Human-implemented agent | public policy/output trace | actual human/computational realization and consumer binding | Forces actual installation and bearer boundaries to remain explicit. |
| Copy / switch / memory | copied state and later report | causal ancestry, active instance and read window | Defeats inference from stored content or report to present consumer use. |
| Ancestor / formation | basic experience admission assumptions | later sensorimotor instrumentation and learned model | Prevents EIP measurements from becoming a new basal-experience threshold. |

The first pair drives the proof. The remaining four are compatibility checks against the standing UCT thought-experiment families.
