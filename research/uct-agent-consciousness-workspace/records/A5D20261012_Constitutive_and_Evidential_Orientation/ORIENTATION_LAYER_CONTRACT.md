# Constitutive, semantic and evidential orientation contract

## Fixed binding

Fix one actual-token candidate binding

`b = (P, I, K, e, tau, c, t)`,

where `P` is the bearer process, `I` the episode interval, `K` the complete relevant signature, `e` the event, `tau` the selected action target, `c` a bearer-state/route port and `t` a target/consumer port. The actual directed relation `R_b(c,t)` is specified before any phenomenal response is examined. For the present application it means that a bearer-anchored route is actually consumed in selecting, sustaining or correcting `tau`; its complement is absence or a declared alternative at the same grain. Direction and port sorts are part of `K`.

This is an organizational predicate. It is not defined as feeling mine, agency, ownership, voluntariness, report, success or consciousness.

## Three layers

1. **Constitutive coordinate.** Under actual grounding, complete relevant `K` and C1, the isomorphism `h_P` transports `R_b` to the experience-internal relation `R_b^Phi`. Define `X_R(b)=1` exactly when this transported relation is present. A change in an external 0/1 code does not complement `X_R`; port reversal is a different relation unless declared as a symmetry of `K`.
2. **Named phenomenal interpretation.** `B_pc` is the application claim that the selected named contrast `H_pc` is positively aligned with `X_R`, rather than complemented, independent or only partially related. C1 does not supply `B_pc`.
3. **Evidence.** `E_pc` is a fallible observation intended to concern `H_pc`. Its signed reliability `P(E_pc=1|H_pc=1)>P(E_pc=1|H_pc=0)` is independent of both `R_b` grounding and `B_pc`.

## A5D-C1 — conditional constitutive-orientation preservation

**Type:** conditional application of typed isomorphism preservation.

**Statement:** If all of `ACTUAL_R`, `COMPLETE_RELEVANT_K`, `C1_SAME_BINDING`, `TYPED_DIRECTION_PRESERVED` and `NO_ADMITTED_ROLE_REVERSAL_SYMMETRY` hold, then the truth and direction of `R_b(c,t)` are preserved in `R_b^Phi(h(c),h(t))`. The constitutive coordinate has one declared orientation relative to `R_b`.

**Proof:** An isomorphism in the declared relational signature preserves the interpretation of each relation symbol and the sorts/order of its arguments. Complementing the relation or reversing its argument order is not an external label permutation. It is either a different model or an admitted symmetry that must be declared. This is standard model-theoretic preservation plus A:C1, not a new theorem.

**Counterlimits:** a finite view mistaken for complete `K`; a predicate selected after seeing reports; an analyst-invented relation without a physical witness; an actual automorphism that exchanges the declared roles; or no admitted actual token.

## A5D-C2 — two-bridge alias

Let `H_pc = X_R xor s_B`, where `s_B` represents the unresolved semantic orientation, and let evidence be high for `H_pc xor s_E = 1`. With rates `4/5` and `1/5`, the sign of the observed `E_pc`--`R` contrast depends only on `s_B xor s_E`.

Therefore a positive observed association is compatible with both `(s_B,s_E)=(0,0)` and `(1,1)`, while a negative association is compatible with `(0,1)` and `(1,0)`. Actual relation grounding cannot decide whether the phenomenal interpretation and the evidence channel are both correct or both inverted.

## A5D-C3 — bounded gain from grounding

If the constitutive coordinate is also left as a free label, there are eight orientation triples `(s_X,s_B,s_E)`, four producing each observable sign. Grounding the directed actual relation and using C1 fixes `s_X=0`, leaving four pairs, two per observable sign. Thus grounding removes one convention freedom but does not identify `H_pc` or calibrate `E_pc`.

## Refuters and stop rule

- **Role reversal:** exchange `c` and `t` while holding an external code fixed. If the allegedly constitutive coordinate does not change when the typed relation changes, it was not tracking this relation.
- **Response-key inversion:** invert the learned output key while retaining the same target comparison. A genuine evidence analysis must recode the key; raw key identity is not the sign.
- **Copy/switch:** copy report, memory and endpoint state, then switch the current route so `R_b` changes. Preserved `E_pc` with changed `R_b` defeats constitution-by-endpoint.
- **Route replacement:** preserve success while replacing the bearer-anchored route with a world-coordinate or imposed route. Success is not `R_b`.

Passing these refuters can support the selected organizational relation and reject some evidence packages. It cannot by itself establish `B_pc`. If no independent `B_pc` or independently signed `E_pc` warrant appears, retain the positive result only as an experience-internal structural relation under C1 and leave the named mineness bridge open.
