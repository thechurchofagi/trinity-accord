# R183 当前交接：体验结构何时对智能“有关系”

本轮没有重做并行完成的计算器、晚询问或最小保留集合。新结果把“体验是否帮助智能”改写成严格的同实例问题：固定实际对象、时间、完整签名、任务、边界、允许补偿和干预协议后，问某个实际构成关系是否出现在每一种成功实现中。

定义 `TRER(r|P,I,K,M,pi,T)`：只有当实际桥接、固定成功族、`r` 的个体不可避免性和 C1 同时成立时，才称 `r` 的体验对应关系对目标 `T` 具有目标相对的构成性相关。这不是“体验作为第二股力量推动物理计算”，而是同一个不可缺构成关系的物理描述和内在体验描述。

最重要修正是冗余：共享路线需要 H，旁路需要 Q，冗余系统中 H、Q 都不单独必需，但 `{H,Q}` 至少一个必需。因此要区分个体不可避免集合与析取式最小击中集。否则会把冗余误判为体验结构无关，或错误寻找唯一意识核心。

精确检查遍历四关系上的65,535个非空成功族和262,140个关系—成功族实例；167个非空单调成功族都在完整支持上成功，但不可避免核心大小分布为0:114、1:36、2:12、3:4、4:1。完整行为相同不能识别依赖剖面。报告关系可以改变而固定算术目标不变，所以体验结构改变也不必改变所选能力。

四类反事实已经分开：完整组织不变但关闭体验在UCT内不合法；构成关系干预是组织变化；证据/报告干预首先改变可知性；加入外部操作员、记忆或重训练改变边界/资源合同。任何一类都不能偷偷替代另一类。
