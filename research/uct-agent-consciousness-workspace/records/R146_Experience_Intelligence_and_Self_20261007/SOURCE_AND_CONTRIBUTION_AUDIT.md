## 3. Objections and corrections applied

**A definition can hide the hard question.** The attachment record is explicitly a grounding premise. Mathematical designation alone is not intrinsic reference or an actual installed mechanism. The manuscript does not claim that this open physical/semantic task has been derived from the tuple.

**Wrong self-models would be excluded by an accuracy threshold.** They are retained with their error profile. Accuracy is an attribute, not the admission definition of representation. A uniformly wrong branch is not described as lacking all self organization.

**Self-localization can be mistaken for arbitrary name recovery.** The duplicate theorem states two different tasks and their protocols. The external-label chance result requires full-history independence, while local prediction uses a physically attached channel. No contradiction is inferred.

**A center might be smuggled into an uncentered theorem.** The identity family takes a center as argument and is not a singleton selector from W. The draft makes this change of domain explicit; it proves compatibility, not spontaneous construction of a self-model from an unmarked structure.

**A function might exist but be unavailable.** Proposition 2 optimizes over arbitrary decoder rows. It is not a resource-feasible or physically installed implementation certificate. The profile separately includes installed realization.

**Half the diameter might be overclaimed.** Only a lower bound is stated. The three-point-mass example has exact minimax radius 2/3 despite diameter one; the complete expression uses fiber radii.

**Continuous organization formation might be treated as proof of universal experience.** The existing smooth-onset counterexample remains. Thought-experiment motivation, A:E1 and A:E3 have different premises.

**Several local selves might imply one exclusive whole subject.** No such edge is admitted. Local referents, an actual coordinated token and a subject-selection convention remain distinct.

**A new name might claim priority for old mathematics.** Both propositions are explicitly attributed to antecedent principles. A/C already contain much of the material; R145 is supporting technical work, not the core of this definition-first paper.
