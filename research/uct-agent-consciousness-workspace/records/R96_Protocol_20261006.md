# R96 protocol — path-blocking test for direct vs instrumental continuation preference

Date: 2026-10-06. Continues R95. This is a formal virtual-controller audit, not an externally preregistered behavioral experiment. The design was finalized after algebraic sanity checks; no confirmatory-status claim is made.

## Goal

R84 already showed that current-token continuation, successor continuation and task continuation are not identifiable when their consequences are bundled. R96 asks a narrower mechanistic question that becomes important after R95:

If a policy uses a bearer-bound Q prediction, is Q valued directly, or does Q influence action only because Q predicts task continuation?

## Declared pairwise-choice model

For a matched option contrast, let q,o,g in {0,1} indicate whether the chosen option preserves current bearer Q, other/successor O, and task outcome G relative to the reference. Permit pairwise interactions. The choice logit is

z = theta_Q q + theta_O o + theta_G g + theta_QG qg + theta_OG og.

This is a finite identification model, not a complete theory of agency.

Use five core contrasts:
- q_direct=(1,0,0,0,0): Q changes while task G is externally held matched by a relay.
- o_direct=(0,1,0,0,0): O changes while G is matched.
- task_only=(0,0,1,0,0): task result changes while Q/O are matched.
- q_bundled=(1,0,1,1,0): ordinary case where current bearer and task continuation move together.
- o_bundled=(0,1,1,0,1): successor and task continuation move together.

Use qo_joint=(1,1,1,1,1) only as an overidentification check for omitted higher-order structure.

## Checks

1. Enumerate theta in {-1,0,1}^5. Show bundled q/o contrasts cannot point-identify the five coefficients.
2. Show the five core exact logits have full rank and identify all grid profiles.
3. Retain deterministic-choice loss of scale/magnitude identification.
4. Construct direct-Q, pure-task-instrumental, and QxG-interaction controllers with identical q_bundled choice probability.
5. Show q_direct and task_only interventions separate these mechanisms.
6. State explicitly that a controlled direct effect at fixed G is evidence about a control contribution, not phenomenology or valence.
7. Preserve the possibility that a real policy has omitted higher-order terms, belief errors, unequal relay trust, or other nuisance paths. A failed overidentification check rejects this simple model rather than being relabeled as fear.

No real shutdown, copying, persistence privileges, external resources, credentials, model APIs, or emotional wording.
