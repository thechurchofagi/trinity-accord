# A5F 中文交接：解剖锚点、工具远端坐标与体验桥缺口

## 本轮实质推进

A5F 找到 A5E 所要求的一个真实协议级候选：固定的解剖手通过实际握持关系连到工具远端；交叉两根棍时，手和机械感受器位置不变，而远端尖端的外部空间侧发生交换。用 `Anchor(hand)`、`Grip(hand,tip)`、`ExternalSide(tip)` 定义锚定远端坐标，不需要概念我、报告或额外主人。

精确穷举 256 个两手/两端结构：同步交换手和端点只有 16 个自同构，240 个不是。在“唯一解剖锚点 + 该手恰握一个端点”的 64 个结构中，交叉前后全部非同构。限定到两棍完美匹配且两端位于相反侧的族：无锚点时 4/4 对仍同构，有唯一锚点时 8/8 对非同构，锚定远端侧 8/8 反号。因此，真实解剖锚点确实消除了 A5E 的纯置换障碍。

## 关键发现与失败

Yamamoto–Kitazawa 的交叉工具研究提供真实的手—工具—远端位置组织及触觉时序/远端转移证据；但它没有给出完整生物 `K`，也没有独立于报告的 `H_tip`（接触在当前握持工具远端的体验位置）测量。Kalckert–Ehrsson 的实验又表明所有权与能动感可分离，所以二者都不能事后替换成 `H_tip` 或 `H_pc`。

本轮的正结果只到“协议级实际不对称与可定义坐标”；负结果是 `B_tip`、`B_pc` 仍未识别。非同构不能反推体验桥，时序报告也不是体验目标本身。
