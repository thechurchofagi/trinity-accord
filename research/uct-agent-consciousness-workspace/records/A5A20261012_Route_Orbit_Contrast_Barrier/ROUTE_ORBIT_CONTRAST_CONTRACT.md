# Route-orbit contrast contract

Version A5A-ROCB-v0.1.0. Negative boundary result plus corrected comparison contract. This is not a basal-experience condition and not an installed phenomenal bridge.

## 1. Typed domain

Fix one admitted actual process token P, interval I, complete signature K, event e, two named targets T={t0,t1}, and two actual same-event bearer-centred routes R={r0,r1}. A4Z's relation Pi is a covered subset of R x T. A route-label permutation acts on Pi by replacing every route name while leaving target identities fixed.

Define:

- joint_count(Pi) = the number of targets served by both routes;
- any_joint(Pi) iff joint_count(Pi)>0;
- all_joint(Pi) iff joint_count(Pi)=2;
- strict_distributed(Pi) iff both targets have exactly one route and their routes differ;
- global_single_owner(Pi) iff both targets have exactly one route and that route is the same.

These are structural predicates of Pi, not phenomenal measurements.

## 2. A5A-T1 — orbit-invariance theorem

For every route permutation g and every covered relation Pi, joint_count(g.Pi)=joint_count(Pi) and strict_distributed(g.Pi)=strict_distributed(Pi). The same holds for any_joint, all_joint, local uniqueness and global-single-owner status.

Proof: a route permutation is a bijection on each target's incident route set. It preserves each set's cardinality and preserves equality or disjointness between the two singleton sets. Therefore every listed predicate is constant on a route-label orbit. This is elementary group-action reasoning, not a new mathematical theorem.

## 3. A5A-T2 — finite contrast barrier

In the two-route/two-target covered family there are nine relations and five route-swap orbits. Exact enumeration finds no pair within one orbit for which any_joint, all_joint or strict_distributed differs.

Therefore “same route-label orbit” and “different joint/distributed status defined only from Pi” are jointly unsatisfiable. Report matching, conceptual-self matching or endpoint calibration cannot make that structural pair exist.

## 4. Corrected fallible comparison

A valid A4Z follow-up has two options:

1. **Pi-only contrast.** Hold P/I/K/e typing, target identities, coverage, conceptual-self organization, report code and selected measurement protocol fixed, but deliberately vary the route-label orbit. The comparison may then test a predeclared phenomenal bridge. It must not claim that complete organizations are otherwise identical.
2. **Augmented-structure contrast.** Keep Pi's orbit fixed but add an independently typed feature W such as contribution weights, temporal coordination, consumer topology or formative lineage. Then the claimed difference is a predicate of (Pi,W), not Pi alone. W must be actual, same-instance, independently grounded and part of complete K; it cannot be inferred from the desired report.

The first option tests A4Z's relation-family semantics. The second tests a new bridge and must not be advertised as evidence already contained in A4Z.

## 6. Inference firewall

Permitted direction:

    complete actual Pi (and W if used)
      -- C1 + R157, conditional --> experience-internal organization
      -- independently predeclared bridge, open --> selected joint/distributed mineness content
      -- fallible measurement bridge, open --> judgment/report evidence

No arrow reverses. A report cannot install Pi or W. Orbit difference is not itself a named phenomenal difference. Same output, conceptual self or memory does not make complete K equal. A finite checker proves the stated combinatorics, not physical actuality, C1, bridge truth, subject count or current-assistant phenomenology.
