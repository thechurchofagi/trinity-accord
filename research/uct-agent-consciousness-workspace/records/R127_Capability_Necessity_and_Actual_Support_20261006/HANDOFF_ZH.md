# R127 交接：从能力要求推到实际组织支持

2026-10-06。承接 R126：1126bd1ebc5de784013a3b55c9747a4bf2350298。遵照用户“先做好理论，再考虑实验”的要求。本轮没有新数据拟合、仿真、体验测量或论文发布。

## 真正的增量

R126 讲清“摘要何时能保持动力学”，本轮进一步问“能力本身要求物理过程保留什么”。对象选为延迟后回答关于先前历史的问题，避免泛泛谈全部智能。

### 1. 任务决定不可合并的区别

设历史 x，后到查询 q，正确答案 f(x,q)。两个历史只有在所有允许查询下答案都相同时，才可在精确求解中合并。若同一内部编码把需要不同答案的历史合并，后续相同输入下不可能重新区分。

形式结论：精确编码 z 存在解码器，当且仅当 z 的等价类细于任务答案剖面的等价类；至少需要 |H/≡Q| 个编码状态。增加查询种类只会细化这项区别要求，但不一定严格增加。

例子是解析的：n 位历史只问奇偶，两个答案类足够；编码之后才任选一位查询，则需要 2^n 个精确状态类。若查询提前告诉编码者，就换了任务，不能用来反驳该下界。

还证明 R126 的稳定细化恰好是“所有未来操作序列下都无法区分”的等价关系。这是已有自动机理论思想在本项目里的连接，不包装为历史首创。

### 2. 区别必须穿过每一个完整的因果截面

“截面”包含当时通向未来答案的所有相关状态、在途信号、时钟和已声明的外部支持，不只是一组测到的神经元。

若后续没有另一个未计入的历史信息入口，两个需给不同答案的历史必须在截面上可区分。随机情形通过同一后续通道时，总变差不能增大；两个历史各自错误率不超过 ε，则截面状态分布的总变差至少为 1−2ε。

因此，为延迟能力保留的区别不能在完整支持中消失后再凭独立输入凭空恢复。但它可在部件间接力，不要求同一个存储元件一直承载，更不要求回路、自我模型或语言报告。这不是体验存在条件。

### 3. 外部支持与联合关系必须入账

完整回忆 m 类目标 X，内部载体 C，外部支持 B，实际平均错误率 ε，有：

I(X;C|B) ≥ H(X|B) − h₂(ε) − ε log₂(m−1)。

这是明确应用 Fano/数据处理，不是新信息不等式。精确回忆时，内部至少承担外部尚未提供的信息；外部已经存着 X，则不能从回答正确推断内部原先存着 X。

独立均匀 n 位的延迟任选位读取还有联合支持下界：I(X;C,B) ≥ n[1−h₂(平均位错误率)]，所需查询条件、每位错误≤1/2等均写明。

关系性反例：X、N 为独立随机位，C=X XOR N，B=N。单看 C 或 B，对 X 的信息都为零；联合却有一位。因此“每个部件单独解不出来”不能推出没有任务信息。这里比论文 C §7.2 多做的是把原先不可访问的 mask 明确变为可访问支持；原论文的 masked-memory 结果不重算新增发现。

这些比特数不是体验量、部件数或人类化程度。

### 4. 构成部分的正向路径已接回已发表本体论

本轮重新读 UCT I v1.2 §2.1–2.5、§3.1 和 C1。原文已经有有限实际过程判据。因此不应把“应用时尚未识别哪个实际过程”夸大成“UCT 缺少一套新体验准入条件”。

给定物理上确证的实际事件图，选非空、沿继承因果联系连续的事件子历史，保留诱导内部关系、重要跨界连接与可追踪历史，即满足既有有限过程判据。证明逐项对应原有要求，没有新增门槛。

实际输入—输出路径可提供候选支持，但不能把所有可能路径的集合冒充本次实际执行。截面也可能是断开的多点集合，它的信息充分性不会自动造出另一个过程。局部开放过程可以把外部记忆记录为边界端口；更大交互过程也可成立，不能强迫所有支持成为唯一大主体。

### 5. 在 C1 下可推出什么

实际支持被独立识别后，C1 的同构保持其真实关系与端口结构；这些关系因而在该实际过程的内在组织中有同构对应。选定载体若不对完整操作闭合，只能先说继承的关系结构，不能偷称封闭子代数。

这里比任意计算坐标更强的是“实际支持已有物理依据”。C1 本身仍是固定内部前提，不由本轮验证。任务等价类不是自动出现的构成槽位；同一任务商不代表完整体验相同；部件过程自己的体验与母过程里的某个现象学部分也不能只凭独立类型标签等同，需保留有关包含/边界映射。

## 严格区分的五个谓词

- 属于实际过程 P 的构成组织。
- 所声明任务族对所有实现的要求。
- 某次干预背景下对任务是否必要。
- 本次发生中是否实际使用。
- 连同所声明背景是否足以实现任务。

必要的外部供电不因此自动成为预定局部过程内部；冗余的内部贡献者不因单独移除无效而自动被排除。任务要求往往是“至少存在一条合适支持路线”，不能偷换成某一部件在所有实现中必要。
