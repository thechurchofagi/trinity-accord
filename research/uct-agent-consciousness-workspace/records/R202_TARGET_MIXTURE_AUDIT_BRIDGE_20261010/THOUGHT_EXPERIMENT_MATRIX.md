# R202 thought-experiment matrix

| Family | Fixed items | Varied item | What it tests / counterexample role |
|---|---|---|---|
| Equal-marginal twins | `m_T`, marker coding, source calibration, actual-use declaration | Swap target `q0,q1` | Refutes inference from target marginal to signed familiar-continuity direction. |
| Random vs volunteer audit | Population law, endpoint, marker | Inclusion probability as independent vs `H`-dependent | Shows why a test performed on reporters need not represent the target-style population. |
| Singular endpoint | `M` law and audit design | Set `a=c` | Demonstrates that more audited data cannot identify orientation through an uninformative endpoint. |
| Response-key mirror | Stimuli, organization, comparative content | Reverse report key | Separates endpoint semantics from motor/report convention. |
| Physical route bypass | Input/output/task score | Declared carrier-consumer path used vs bypassed | Separates actual use `U` from successful test evidence `E_U`. |
| Copy/switch/memory | Complete current visible state and reports | Numerical lineage, switch history, retained memory | Prevents current similarity from establishing actual continuity or target-domain transport. |
| Ancestor/formation | Present organization | Formation history and constitutive use | Tests whether formation is evidentially required without making ancestry a basal-experience gate. |
| Abacus/calculator/human agent | Correct computation and public report | Physical implementation and who/what carries steps | Blocks output equivalence from fixing bearer boundaries or experience structure. |

The experiments are constraint probes, not observations that any listed system is conscious or unconscious.
