# R202 preregistration skeleton — reporting audit before no-report transport

## Frozen domains and sequence

1. `C`: independent semantic calibration of endpoint direction/error.
2. `V`: target-style reporting population; randomly select audit membership before marker outcomes.
3. `T`: genuinely nonreporting population; no inference to `T` unless a separate bridge is predeclared.

Measure `M` before the audit prompt. Freeze bearer class, interval, application signature and the actual-use criterion. Record telemetry as `E_U`, not as `U`.

## Controls and estimands

- Randomize response-key direction and balance success/fluency.
- Include a physical-bypass control and retain evidence that the declared path was actually available and used.
- Estimate `m=P(M=1)`, `j=P(J=1)`, `r=P(M=1,J=1)` in `V`; calibrate `a,c` independently in `C`.
- Propagate a simultaneous confidence set through the constrained inversion; do not combine unrelated point estimates.
- Hold out marker-model choice and all thresholds from the confirmatory split.

## Falsifiers and stop rules

- Reject endpoint orientation if `a≤c`, if the confidence set includes an uninformative separation, or if response-key reversal changes semantic direction.
- Reject the marker bridge if residual `J–M` dependence within endpoint class exceeds its predeclared bound, or if the bypass condition preserves the putative marker effect.
- Reject population recovery if audit inclusion depends materially on marker, outcome, success, fluency or willingness to report.
- Do not attempt `V→T` transport unless class-conditional bounds or a justified same-domain missingness design are available.
- Otherwise report: **marker observed; `H` direction unidentified**.

This design tests a selected evidential bridge. It does not test C1 or add report/control requirements to basal experience.
