# R124 Next Research Program — Rescue or Retire, Then Human Content Bridge

## Decision rule

Do not return to generic theorem generation or repeated state decoding. R124 converts the main rat uncertainty into a falsifiable go/no-go question.

### Priority 1 — Raw-bin no-future-support C2 rescue test

Use the same Gupta sessions/trials and a frozen cohort. Construct the primary neural view from **raw 50 ms spike bins** whose support does not extend beyond the declared target endpoint. The R122 seven-tap filtered view becomes sensitivity analysis only.

Fit, on training trials only:
1. a state decoder (g(z_t)	o e_t);
2. a transition operator (F(g(z_t),u_{t+1})	o g(z_{t+1})) or an equivalent source-faithful state-space form;
3. a matched null/persistence model.

Evaluate on held-out whole trials:
- level-state R²;
- transition MSE and skill over persistence;
- increment correlation/sign accuracy;
- input-conditioned commutation residual;
- cross-rat stability;
- fixed lag sensitivity declared before evaluation.

**Go criterion:** a positive, reproducible held-out transition advantage that survives frozen nuisance/time controls and has a biologically defensible state/time mapping.

**No-go criterion:** if the raw/no-future-support candidate again fails C2, retire cumulative signed-click decoding as the T2 state map. Do not tune the view until it passes.

## Priority 2 — C3 intervention transport

Only after a defensible C2 state map exists, compare intervention ports. Preserve the distinction among:
- external evidence pulse;
- FOF region perturbation;
- ADS region perturbation;
- FOF→ADS projection perturbation;
- artificial accumulator state reset.

No pair is considered the “same intervention” merely because both change behavior. A transport map must be justified by preserved causal role and downstream transition law.

B3 remains open until genuine trial-level optogenetic behavior or equivalent source data are independently recomputed.

## Why this sequence

R124 shows that a static neural readout can look positive while the required transition law fails. Therefore cross-substrate work must move from “can I decode a state label?” to “does the mapped state transform under inputs/interventions in the same structured way?”

The human APStim line is valuable because it adds a finite phenomenal/psychophysical target to an actual intervention. It is not a substitute for the rat mechanism certificate. Keeping the two questions separate respects UCT I's physical-view/phenomenal-target firewall and UCT II's anti-oracle rules.
