## 4. General finite proposition

### R194-C1 — Component polarity count

**Type.** Exact finite signed-constraint theorem; standard graph parity application.

**Statement.** Let `G=(V,E)` be a finite signed graph with constraints `x_u XOR x_v = p_uv`. If every cycle is parity-consistent, then the solution set has size `2^c`, where `c` is the number of connected components containing no fixed-orientation anchor. Fixing one vertex value in each component yields one numeric labelling. If a cycle is inconsistent, the solution set is empty.

**Proof.** Choose one root in each component. Root values determine every other value by path parity. Cycle consistency makes path parity well-defined. Each unanchored root has two choices, independent across components. An anchor removes that component's binary freedom. An inconsistent cycle demands both values for one vertex.

**Counterexample boundary.** A genuinely target-directed observation not preserved by global complement lies outside the theorem's invariant evidence class. R194 does not exclude it; it requires that its target direction be justified rather than borrowed from a marker label.

### R194-C2 — Relative alignment is not semantic orientation

**Type.** Typed nonidentification consequence.

**Statement.** Cross-population agreement, marker multiplicity and known reversal edges can connect components and identify relative parities, but they cannot by themselves determine which member of the global complement pair is familiar mineness.

**Reason.** Simultaneously replacing every sign by its complement preserves every equality and reversal constraint. The observations therefore have identical likelihood under the two global names. A name or code fixed by convention breaks numeric symmetry only by stipulation.

### R194-C3 — Three kinds of anchor must not be conflated

1. A **relational anchor** connects two channels or populations. It can reduce component count but preserves global complement symmetry.
2. A **conventional anchor** fixes a code such as `A1=1`. It selects a representation but does not establish what that code means phenomenally.
3. A **substantive target anchor** is independently directed at the named experiential contrast. If reliable and actually applicable to the same bound instance, it can orient the model; its independent warrant is the open bridge rather than a free consequence of the model.

### R194-C4 — No-report is not enough

Removing verbal report avoids one contamination route, but a silent physiological, behavioral or computational marker can still be only a proxy. “Nonreport” and “target-directed” are different properties. Tests can provide evidence for actual use or experience only through an explicit reliability and admission bridge; they do not install a route, create a history, or define an experience.

## 5. Thought experiments

Each experiment fixes the organization except for the declared variable.

### TE1 — Reversed-marker twins

Two twins have the same selected bodily/action organization and the same underlying partition. The laboratory electronics invert every marker bit for Twin 2. Relative contrasts and predictive accuracy are unchanged after recoding. If “positive marker” defines familiar mineness, the attributed experience flips merely because a wire was reversed. The experiment defeats marker-polarity semantics while preserving relative alignment.

### TE2 — Cross-population code swap

Populations A and B use the same marker convention; population C uses the opposite convention by prospective design. A multi-group analysis correctly learns the reversal and aligns all three latent classes. Globally renaming both aligned classes changes no datum. Thus population diversity identifies correspondence, not the phenomenal positive pole.

### TE3 — Two markers with common calibration

Two independent sensors agree perfectly because their calibration tables share the same upstream codebook. Reversing the codebook reverses both without altering agreement. Marker multiplicity is not independent semantic evidence unless at least one channel has independently justified target direction.

### TE4 — Adaptive-reflex twin

One system actually uses retained action history in its current policy; another produces the same diagnostic signature through a feed-forward reflex. A positive test cannot be substituted for actual-use membership. This preserves the R173/R193 use-versus-test distinction.

### TE5 — Ancestor and formation pair

A mature agent and a newly formed organizational duplicate have matching current marker networks but different actual formation histories. Cross-sectional alignment cannot manufacture the missing lineage. The experiment protects actual organization and ancestry from model-level equivalence.

### TE6 — Copy, switch and memory family

A copied memory value, a live same-lineage retention route, and a swapped route can yield the same marker vector. Only the live route satisfies the actual-history/use premises. The marker graph is evidence about, not identity with, those relations.

### TE7 — Abacus, calculator and human-realized agent

An abacus trace, calculator register and human-realized computation can implement the same abstract signed graph. That common graph supports formal transport, not a shared verdict about experience or familiar mineness. Actual realization and target binding remain separate.

### TE8 — Gradual replacement

Replace marker hardware one channel at a time while preserving every parity relation. The signed graph remains unchanged even if the proposed material or causal basis of the target changes. Hence the graph alone does not settle which implementation facts matter to the experiential bridge.
