# A4D gap ledger

## A4D-G1 — writer completeness is a physical premise

- **Location:** AWC clauses 1–4.
- **Impact:** blocks promotion from logs/replay to actual target-writer use.
- **Counterexample:** a challenge-aware hidden writer reproduces all six actuator cells while the target is idle.
- **Corrected:** A4D-N1 records the exact twin; no log or source audit is called complete physical isolation.
- **Open premise:** physical enumeration, isolation and timely-information exclusion for every competing writer.

## A4D-G2 — actuator probe can still be misplaced

- **Location:** AWC clause 5.
- **Impact:** a pre-arbitration register may report the target command while a later writer controls the actuator.
- **Counterexample:** telemetry is sampled before a safety controller overwrites the power-stage command.
- **Corrected:** the protocol requires a post-arbitration, pre-plant probe and separately checked clock order.
- **Open premise:** actual hardware placement and integrity of that probe.

## A4D-G3 — rescue can create a bypass

- **Location:** AWC clause 6.
- **Impact:** rescue success can be caused by a direct actuator write rather than restoration of the target route.
- **Counterexample:** the rescue process writes motor current after bypassing the target arbiter.
- **Corrected:** same-interface rescue is explicit and direct actuator/endpoint rescue is a failure state.
- **Open premise:** physical interface identity and absence of rescue side effects.
