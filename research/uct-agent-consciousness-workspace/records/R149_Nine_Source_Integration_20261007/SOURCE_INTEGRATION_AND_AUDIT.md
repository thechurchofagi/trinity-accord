## Findings requiring explicit qualification

**F149-01 — Trajectory, germ and experiential target are three different maps.** TA18 Proposition 1's intended AND/XNOR witness requires the germ to retain joint interventions or distinguishing implementation data. The displayed per-variable response profiles alone do not ensure that. Even once different germs are established, a constant PRD bridge can make their targets equal. R149 imports enriched-germ nonfactorization, and permits phenomenal nonfactorization only with an explicit pair-separation premise. This repairs the inference without changing the published text.

**F149-02 — A function is not automatically isomorphism invariant.** TA18 Proposition 2 uses that extra property. The graph now lists it separately. The conclusion concerns the selected target region/interval, not every larger bearer containing idle hardware.

**F149-03 — Bridge relabeling can be gauge rather than a difference of type.** TA18 Proposition 3's automorphism sketch requires actual difference on the bridge image and compatibility with all cross-scale maps. An output automorphism alone may produce only an isomorphic relabeling. R149 uses an explicit two-class/two-output countermodel to a universal uniqueness claim; it does not claim that C1 admits arbitrary type reassignment or that raw-label nonuniqueness proves different qualia.

**F149-04 — A quotient needs an equivalence relation.** TA18 null transformations are treated as an equivalence relation or its generated closure. Invariance must hold on that relation. Declaring a difference null is not proving it null. The R149 compatibility theorem states when full C1 and that null quotient can coexist.

**F149-05 — Functional intervention information needs a clear joint law.** TA17's I(U;Y|do(U)) is read as MI under the randomized interventional joint distribution p(u)p(Y|do(U=u)), not ordinary conditioning on the already known U. Positive H(U), fixed distribution and transported intervention semantics remain explicit. The fission normalization claim includes the nonnegative and symmetric co-successor premises used in the source proof. Intervention-limited nonidentification additionally needs admissible observationally equivalent full-model completions; missing interventions alone do not prove every query unidentifiable.

**F149-06 — TA19 source coverage is not as broad as its abstract.** The exact 43,338-byte published Markdown, matching its release SHA-256, ends after the double-cover example in §5. The repository source-main also ends there. The main PDF was not inspected in this round, so no claim is made that it shares this issue. The 7,573-byte published supplement was recovered and hash checked; it contains S1–S6 and the reported IIT tables. R149 imports the available local/covering results plus explicitly proved supplement claims; it does not invent missing main sections, references or an analytic numerical crossing proof. Source formatting/coverage repair remains a separate publication-maintenance task.

**F149-07 — Historic hypotheses are not all simultaneous current axioms.** TA16 RRH-E and TA18 PRD retain their original target domains and conjecture/postulate status. If RRH-E is construed as necessary for all basal actual-token experience, a witness failing its gate conflicts with U1. If PRD uses a genuinely complete germ for the same bearer, the R149 compatibility condition can hold; no blanket inconsistency is asserted. A partial target or different bearer is an explicit change of question, not a hidden resolution.

## Integration result and current research increment

The new synthesis proves: under complete organizational/experiential type equivalence, a descriptor determines complete experiential type exactly when it preserves every complete organizational type distinction. For selected targets the weaker ordinary fiber criterion suffices. This relates the old papers and clarifies the precise problem raised by the calculator, human-computer and self-misbinding thought experiments. It does not certify historical novelty or original-paper submission readiness. The source ingredients are already published.
