# A4O 中文交接：行动框架一手范式筛查

## 本轮实质推进

按 A4N 的同实例合同筛查六项一手范式。Cordo 肌腱振动提供强姿态/本体锚干预；Iriki 与 Cardinali 提供工具纳入/形成相关证据；Takahashi 提供工具映射下的视觉—触觉整合；Zografos Themelis 2026 提供独立改变凝视/物体位置的工具触觉在线坐标变换。但没有一项在同一承载者/事件/路线中同时满足：固定外部目标与工具状态、独立扰动承载者姿态锚、在线重映射、同一已学习路线实际读取、肢体/已纳入/未纳入工具比较及同实例绑定。

关键修正是：这些互补证据不能跨论文拼成一个 `all_of` 实例。精确64世界反例还表明，即使固定外部状态、姿态扰动后端点与报告同样变化，真实框架路线和独立补偿器仍可观测等价。路线切断/同接口救援只在备用写入器/控制器清单完备时条件性分离，A4D–A4G限制继续有效。
