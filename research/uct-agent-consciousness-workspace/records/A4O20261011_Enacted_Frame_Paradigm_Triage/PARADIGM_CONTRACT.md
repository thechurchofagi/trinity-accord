# Same-instance enacted-frame paradigm contract

Version: A4O-EFP-v0.1.0  
Status: disabled empirical-screening contract.

## 1. Joint eligibility

A paradigm is eligible to ground the A4N organizational comparison only if one actual bearer/event/route package jointly supplies:

1. **`C_ext` — external-state fixation:** the relevant external target and tool geometry/state are fixed, measured, or exactly counterbalanced while the bearer anchor is varied;
2. **`C_anchor` — independently oriented anchor intervention:** a predeclared intervention changes or degrades the bearer's current pose/proprioceptive anchor without being defined by the behavioral endpoint;
3. **`C_remap` — online remapping evidence:** the event requires a coordinate update from that anchor, rather than only a post-use aftereffect, endpoint shift or verbal judgment;
4. **`C_route` — same-route consumption:** the learned route that mediates present fit is shown to consume the remap, with a route-specific block/rescue or an equally discriminating causal witness;
5. **`C_compare` — comparison coverage:** limb, frame-incorporated tool and non-incorporated tool conditions are independently grounded, or an explicitly bounded subset is reported without claiming the missing comparison;
6. **`C_bind` — same-instance binding:** bearer, event, anchor, route, intervention, target/tool state and readout are bound to the same actual token and declared time order.

All six entries are conjunctive. Evidence from distinct studies may motivate a new design but cannot be conjoined as one actual installation.

## 2. Evidence grades

- `YES`: the primary source directly supplies the criterion in the declared experiment.
- `PARTIAL`: a related variable or proxy is measured, but at least one binding/causal requirement is absent.
- `NO`: the source does not supply the criterion.
- `UNCLEAR`: the accessible source scope is insufficient; this never counts as `YES`.

Eligibility requires six `YES` values. This is deliberately stricter than evidence that tool use changes behavior or body representation.

## 3. Frame-cancellation counterexample

At fixed external target `x`, a pose perturbation `d` can yield the same endpoint signature in two declared mechanisms:

```text
frame route:        u = x - d        because the learned route reads the bearer anchor;
allocentric twin:   u = x - d        because a separate perturbation-sensitive compensator adds -d.
```

Endpoint change, success and report therefore do not identify `C_route`. In a declared closed writer/route model, blocking the learned route while leaving the compensator unchanged separates the pair; same-interface rescue restores the frame case. If an unlisted controller can observe the intervention or forge the rescue, the A4D–A4G completeness obligations reopen and the result is invalid, not positive evidence.

## 4. Stop rule

If no primary source has six `YES` values, report the nearest complementary components and the exact missing conjuncts. Do not infer `EnactedFrameBind`, do not compare `H_cf`, and do not promote a formal-map node/rule.
