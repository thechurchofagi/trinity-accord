## 1. Result

Six primary paradigms were evaluated against A4N's full same-instance contract. None jointly fixes external target/tool state, independently perturbs the bearer's pose/proprioceptive anchor, establishes online remapping, shows that A4M's same learned route consumes that remap, covers limb/incorporated/non-incorporated tool cases, and binds all witnesses to one bearer/event.

The evidence is complementary rather than useless. Cordo et al. provide a clean proprioceptive intervention during a coordinated movement sequence. Iriki and Cardinali provide neural or behavioral evidence associated with tool incorporation. Takahashi et al. show flexible use of tool-induced hand–world mappings. Zografos Themelis et al. independently vary gaze and object location and fit an explicit tool-touch remapping model. But these components occur in different tasks, bearers, events, route definitions and comparison domains. `all_of` does not license their cross-study conjunction.

The A4N stop rule therefore fires. The present record supports a prospective experiment specification, not an actual `EnactedFrameBind` token and not an `H_cf` comparison.

## 3. What each near-hit does and does not supply

### 3.1 A bearer-anchor intervention without tool incorporation

Cordo et al. vibrated the biceps tendon during a visually occluded, proprioceptively coordinated elbow–hand sequence. Frequency and timing changed when the hand opened relative to a prescribed elbow target. This independently manipulates a bodily input and supports its task relevance. Yet there is no tool, no incorporated/non-incorporated comparison and no A4M learned route-to-fit mediation. It is a component model for `C_anchor`, not a completed A4N application.

### 3.2 Tool-associated changes without a same-event anchor perturbation

Iriki et al. observed tool-use-dependent receptive-field changes in trained macaques. Cardinali et al. observed later free-hand kinematic and tactile-localization changes after grabber use, and their deafferented case supports a proprioceptive contribution to body-schema plasticity. These studies matter for tool incorporation and formation. They do not independently perturb the current bearer anchor at fixed tool/target state inside the same enacted tool event, and their output/aftereffect evidence does not identify that the A4M route consumes an online remap.

### 3.3 Online tool remapping without the A4N body-frame comparison

Takahashi et al. show that visual–haptic integration can respect articulated-tool mappings. Zografos Themelis et al. provide the strongest online coordinate-transform near-hit: independent gaze/object variation supports a hand-to-space-to-gaze computation for touch on a rod. But gaze-centred remapping is not by itself the bearer-pose anchor specified by A4N. Neither source causally isolates consumption by A4M's retained route or compares limb, incorporated-tool and non-incorporated-tool cases.

## 4. Endpoint-equivalent frame-cancellation twin

The 64-world checker separates a frame route from an allocentric compensator. With fixed external target and a pose perturbation, both can generate the same endpoint and report:

```text
frame-only world:       bearer remap=1, same-route use=1, compensator=0;
compensator-only world: bearer remap=0, same-route use=0, compensator=1.
```

All eight endpoint/report observation fibres in the declared binary model contain both `frame_route=0` and `frame_route=1`. Thus endpoint dependence on a pose intervention still does not prove that the selected learned route reads the online remap.

Within a closed declared writer/route model, route-specific blocking separates the displayed pair: the frame-only signature disappears, whereas the compensator remains; same-interface rescue restores the frame route. This discriminator is conditional on A4D–A4G completeness. An intervention-aware hidden controller can reopen the twin. A PASS therefore cannot be promoted from a route label, output trace or rescue command alone.

## 5. Positive bounded consequence

A feasible next experiment can be stated more sharply than A4N's broad search request:

1. pre-establish one learned tool route and an unincorporated control route at the same declared grain;
2. within the enacted event, perturb a proprioceptive/postural anchor while measuring and holding target and tool geometry/state fixed;
3. test a predeclared coordinate-transform signature rather than success or ownership report;
4. block the learned route's anchor input and rescue through the same interface;
5. include a limb condition and verify route equivalence or report the bounded comparison honestly;
6. audit alternate writers/controllers before treating block/rescue as route-specific.

The smallest unresolved core is now the joint `C_anchor ∧ C_route` installation in an incorporated-tool event. Another broad tool-embodiment endpoint study does not answer it.
