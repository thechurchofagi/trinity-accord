# Target-relational mineness family contract

Version A4Z-TRMF-v0.1.0. Disabled candidate interpretation; not a basal-experience condition.

## 1. Typed domain

Fix one admitted actual process token \(P\), interval \(I\), complete signature \(K\), event \(e\), and a predeclared target set \(T\). Let \(R\) be the set of actual same-event bearer-centred routes in that binding. The candidate relation

\[
\Pi_{P,I,K,e}\subseteq R\times T
\]

contains \((r,\tau)\) only if route \(r\) is independently grounded as a current BearerCentredRoute and actually participates in forming or sustaining target \(\tau\) at the named consumer boundary. Value equality, passive recording, output success, a body label, a conceptual self-description, and a report do not create an edge.

## 2. Disabled positive bridge

TargetRelationalMinenessFamily requires all of:

1. **BIND:** one fixed process/interval/signature/event/target-family binding;
2. **ROUTE:** every admitted route satisfies the applicable A4V bearer-centred contract;
3. **PARTICIPATION:** every edge is an actual same-event route-to-target participation relation, not merely a challenge response or log;
4. **COVER:** each selected target has at least one admitted route;
5. **INDEX:** targets remain typed and are not collapsed into one global label;
6. **COVARIANCE:** renaming route identifiers transports the relation without changing its structural orbit;
7. **NONEXCLUSIVITY:** multiple routes may serve one target and different targets may have different route sets;
8. **SEPARATION:** conceptual self and report are downstream or neighboring organization, not defining conjuncts.

Under C1 and R157, an actually installed complete relation may be transported as structure inside experience. The further phrase “practical from-here organization for these targets” is the disabled semantic bridge B_pc^family. It is not established as felt ownership, agency, familiar mineness, a unique subject, or a report meaning.

## 3. Three candidate bridges

| candidate | retained information | exact objection |
|---|---|---|
| unique-owner label | one route name for the whole target set | not invariant under route renaming; excludes overlapping routes and distributed target centres without argument |
| target coverage only | whether each target has some route | all nine two-route/two-target matrices have the same coverage, so participation structure is erased |
| target-indexed relational family | the nonempty route set for each target, modulo mere relabeling | preserves five structural orbits in the finite model; still needs actuality, C1 transport and an independent semantic/phenomenal bridge |

## 4. Inference firewall

The permitted direction is:

    complete actual target-indexed participation family
      --(C1 + R157, conditional)--> experience-internal relational structure
      --(B_pc^family, open)--> practical-mineness interpretation
      --(fallible measurement bridge, open)--> judgment/report

No arrow is reversed. Coverage does not entail a unique owner. Local uniqueness at each target does not entail one global owner. A route-label swap does not by itself change experiential structure under C1. A relation contrast does not by itself establish a named phenomenal contrast.

## 5. Failure conditions

The contract is not installed if routes, targets, consumers or events differ across alleged conjuncts; if participation is inferred only from output/logs; if a hidden compiler moves the relevant boundary; if the route family is an analyst-only abstraction absent from \(K\); or if the target meaning is selected after outcomes. B_pc^family remains false-or-open if an independently warranted target contrast lies inside a relation-family orbit claimed sufficient, or if the named target is invariant across a grounded relation contrast where sensitivity was predeclared.
