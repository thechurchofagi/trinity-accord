# R133：信息够不够，必须连同还能不能行动一起问

这一轮沿四篇统一形式地图继续理论推导，没有新增训练或生物实验。

## 1. 补上的共同策略条件

“每个候选机制各自存在成功方案”不推出“有一个只凭可观察历史就能选对的共同方案”。在有限模型和固定时限内，给出了概率一成功的充要条件：当前每个可能状态都能执行所选动作；每一种可能观察之后，又都存在可继续成功的共同方案。模型身份必须从头到尾一致。不能偷偷读取隐藏身份、免费读取可执行菜单，或逐时刻更换最坏模型。

## 2. 很值得写进下一篇的区分

完成任务所需信息可以远少于完整识别机制所需信息。一次决策的精确条件是：同一观察单元内，各机制的成功动作集合有共同元素。理想编码器可自由选择时，最少消息数等于用成功动作覆盖所有候选机制的最小覆盖数。

例：100 个候选机制，每个只禁用对应的一个动作。不观察时随机选择的最佳最坏成功率为 99%，但不能保证每次成功。只要一个可实现的 bit 告诉你“是不是机制 1”，就能选择一个必定成功的动作；无需识别全部 100 个机制。这里的传感器可实现性是前提，不能从数学编码器直接推出。

另外，最粗的任务充分观察划分可能不唯一。这补明了“完整接口的最粗稳定划分”与“只够完成某一任务的观察划分”之间的差别。

## 3. 信息正确仍不等于控制成功

同样是准确识别机制，保留后续行动机会的探针可以有用；来得太晚，或让目标再也不可达到的探针则无用。这不反驳 C 关于免费附加信息的结果，因为探针改变了时限或动作条件。

还有一个两步反例：固定机制的轨迹只能是 (1,0) 或 (0,1)，两者都至少成功一次。若每一步重新挑一个机制，便虚构出 (0,0)，误判所有共同策略都失败。

## 4. 论文价值和边界

下一篇可围绕“行为接口何时足以支撑实际可用的共同控制”组织：目标识别、完整转移律、资源共同实现、可观察策略、信息到达时间，形成一条完整的论证链。

支持集控制、集合覆盖等是已有数学，本轮价值在于把缺失条件、区别和反例接入四篇理论，而非宣称数学史首创。发表前仍需更完整查新及更明确的 UCT 特有贡献。上述结果不能推出体验更多、唯一主体、负效价或 T2 闭合，也不能把自我识别能力加为体验存在门槛。

验证：22 项具名检查，756 次直接策略树与支持递推比较，343 个成功集合族、1715 种观察划分核验。一般定理仍依赖正文的条件手工证明，非证明助手认证。

下一步：成功率允许低于 100% 后，如何把诊断精度、探针成本和剩余行动机会联成定量界？需保存候选机制各自的延续收益，不能把支持集当作后验概率，也不能每一步重新取一个无关的最坏机制。
