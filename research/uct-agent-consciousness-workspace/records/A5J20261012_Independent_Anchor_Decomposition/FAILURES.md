# Failures and Negative Results

1. **Two-channel convergence failed as an independent anchor.** It leaves all six target laws because both channels may read `P` directly.
2. **Factorial `P×C` calibration failed to establish target-source inclusion.** It excludes direct `C` reading but not direct `P` reading.
3. **Semantic source diversity alone failed to identify target polarity.** Four models survive, including `H=1-P`.
4. **Common orientation alone failed to establish a phenomenal source.** Ten models and all six target laws survive.
5. **Full `SD+CO` failed to identify which named/anatomical channel reads `H`.** Two selector-swapped models remain.
6. **No empirical installation was established.** Existing held-stick studies motivate routes and constraints but do not jointly install A5J's `F+SD+CO` package in one participant/process.
7. **Direct Git push from the local checkout failed at the initial checkpoint because no HTTPS credential was available.** The GitHub connector is used as the authorized fallback; no remote-save claim is made before connector verification.
