# Thought Experiments

## Fixed and varied roles

| Family | Held fixed | Varied | Role in A5J |
|---|---|---|---|
| Ancestor / formation | current four-cell output table | whether a target-sensitive route ever formed | prevents later successful calibration from retroactively determining earlier experience; non-retroactivity check |
| Abacus / calculator | correct `P` output | direct physical reading versus selected `H` reading | counterexample to equating calculation/decoding with phenomenal source identity |
| Human-implemented agent | outer participant and task table | which nested actual process supplies `Z` or `A` | scope check; blocks transfer of the implementer's bodily anchor to every represented agent |
| Copy / reconnection / memory | channel values and copied labels | source routing and polarity | countermodel generator for the 12-model baseline and selector-swap residual |

## Direct-position twin

Two independently manufactured sensors both receive the physical `P` line. Their noise, substrate and anatomical location differ. Both output `P` in every `P×C` cell while `H` is constant. This holds hardware independence fixed and varies semantic source identity. It shows why “independent channel” must not mean merely “different device.”

## Complement twin

One channel reads `P`; the other reads `H=1-P` and complements it. Outputs agree perfectly. This holds semantic source diversity fixed and varies orientation. It shows why target-source admission alone leaves a global complement.

## Selector swap

Under full `SD+CO`, exchange which named channel reads `H` and which reads `P`. The target law remains `H=P`, but anatomical source attribution changes. This is a boundary case: target identification does not entail mechanism identification.
