# Primary-source comparison and originality scope — PR-v4.0.0

Research date: 2026-10-11. This is a targeted comparison, not an exhaustive worldwide priority determination. No source is rejected merely because it does not solve the current contract.

## Claims not made
No novel general cover theorem, new hypergraph theory, new C(6,3,2) value, new lower bound for every control problem, measured AI consciousness, trained-model experiment, or proof of guaranteed civilization-wide coexistence. The net product is a scoped, internally consistent co-design and falsification framework with exact instances and implementation contrasts.

Broad web searches produced some irrelevant results. The abstract route for authorization succession was initially unavailable; its full arXiv HTML was subsequently retrieved. A separate consciousness-reference access attempt did not yield useful current content; no newly asserted empirical consciousness fact relies on it. Stable source links are in the paper bibliography. Earlier manuscript references are not described as newly fully verified.
