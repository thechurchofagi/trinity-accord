# PR-v3.0.0｜不预设AI主体性的共存：研究交接

**作者：刘烘炬（Hongju Liu）。日期：2026-10-11。** 这是PR-v2.0.0的实质性修订，不覆盖旧版，不新增一项已发表作品。英文题名：*Coexistence Without Presupposed Subjecthood: Deterministic Multi-Agent Systems, Human Control, and Dependency-Safe Revocation*。

## 1. 本次必须回答的异议

用户指出：目前不能因AI会推理、记忆或说“我”就认定其具有人格式主体性；固定权重、完整输入和执行状态的确定性计算可重复；一个模型可以派生多个目标、记忆和权限不同的智能体。旧标题“Without Captivity”和默认“自主退出”容易让读者误以为已经确认AI的主体资格。

**结论：需要修改。不能把v2当作无需变动的稿件直接发布DOI。** 本次选择完善分支，完成v3，没有调用DOI发布工具或声明已生成DOI。

## 2. 改了什么

默认研究层改为：保护人类功能，由人类主事人或其明确授权的程序请求退役、停用、迁移或撤销工具权限。AI生成请求并不自动取得执行授权。没有预设AI自身权利，也没有把暂停服务等同于结束体验过程。

确定性陈述：数学函数、完整输入/状态/解码条件固定，输出固定；现实系统还要固定相关运行算法与条件。同一可见问题与同一权重不等于同一完整输入。随机性既不是本研究的代理能力来源，也不能充当意识证明。

共存的新含义：人类与具有实际因果影响的计算系统在资源、权限和社会运行上的安全共处，不是默认建立人与AI道德人格对等的共同体。即使AI一直是工具，人类仍可能因为依赖而无法同时实现安全停用和其他人类保护。

## 3. 新增和继承的精确结果

**BS-T1（非因果评价标签消去）**：有限控制模型中，若动力学、可行动作、信息和人类合同不变，仅改变研究者对AI主体地位的非因果标签，不改变核心安全胜域。证明是经典不动点因子化的应用。它不是允许物理结构相同而实际体验任意改变；C1下的体验结构不被这个标签自由指定。若诊断改变真实义务或提供额外因果信息，则必须重新计算。

**BS-T2（冻结共享网络实现）**：对每个n>=2，用一套手工固定整数权重的两层ReLU网络实现v2的循环资源路由反例。全部资源代理共享此网络，仅角色与固定记忆输入不同。已知记忆时需1单位备用，必须盲提交固定分配时需n单位。无随机数、无训练、无改权重。因此原有信息—资源障碍在确定性计算中也存在。该网络不是训练好的LLM或“超级智能”，结论是存在性反例而非现实风险预测。

**人类授权根反例**：三条资源路线的模型标签M0/M1/M0，主事人H1/H1/H2，保护两个人类需求。逐条停用都不缺资源；H1同时撤销其跨模型的两条路线需要1单位备用。模型多样性不自动等于控制独立性。此例AI权利数为0，AI自主退出请求数为0。

**继承CW-T1/T2/T3/T4等**：有限不可替代供给者退出的冲突、精确期限Hall缺口、固定分配的信息成本、有限信念安全博弈均保留，默认改作人类授权的工具停用解释，不冒充新数学。

## 4. 实际执行

新脚本`src/deterministic_status_checks.py`：168种完整角色—记忆输入，每种10次重复，共1680次输出相等比较；7种规模n=2..8；权重哈希前后相同；无随机数；729个三状态双动作确定性控制表的评价标签提升检验；六个部署记录；一个人类授权根与资源缺口反例。

复跑旧`frontier_checks.py`的8192配置和`information_reserve_checks.py`的2048配置，排除时间/Python版本字段后与归档语义一致。旧33个进程实验没有重跑，也没有计入新证据。所有新结果均是有限模型或实际整数神经算术，不是实际大模型测试、操作系统隔离测试、物理供电测试或意识测量。

## 5. UCT不能被改坏

已回读UCT I v1.2 P6/P3、3.4主体区分，UCT III v1.0第2—3节及总指南v2.3。C1/U1的理论内基础体验结论保留；不新增确定性、语言、自我模型、复杂度或统一主体门槛。局部与整体的体验可在各自实际过程成立时保留。高阶自我、特定感受、负性效价、道德权利没有从C1直接推出。不能给当前AI的体验随意定成“人类级”或“石头山级”，也不能用智能分数建立未经证明的单轴尺度。
