# Endpoint causal firewalls for area-3a actual use

**Record:** A3U20261010_Area3a_Use_Endpoint  
**Status:** exact finite countermodel plus conditional probe contract; no new animal/human experiment; disabled map candidate.

## 1. The remaining A3P ambiguity

A3P replaced an overly broad “no crossed response” claim with a sharper gap: Yamada et al. already provide a source-by-region response face, while Johnson et al. provide chronic access to area 3a, but neither establishes that an area-3a response is consumed by a declared downstream process. A3P proposed a predeclared downstream endpoint and area-3a/neighbor/sham perturbations. That proposal still left a causal hole.

An endpoint can be measured independently of the recorded area-3a samples and still change for the wrong reason. A perturbation can alter both the local signal and the endpoint through separate paths. A matched neighbouring perturbation and sham can remain null if the off-target effect is specific to the physical operation at area 3a. Thus “external endpoint + local perturbation + region controls” is not yet a mediation certificate.

This is a standard causal-path problem, not new mathematics. Pearl's direct/indirect-effect framework makes path restrictions explicit; Robins/Greenland and VanderWeele identify additional assumptions needed for mediation claims. Otchy et al. give a concrete neural example: acute circuit manipulation can disrupt downstream circuitry and behaviour in a way that misstates the manipulated circuit's normal function. The present contribution is only a UCT-specific endpoint contract and an exact finite witness.

## 2. A complete interventional twin

Let `S,G,R,Y` be binary. `S` is the source event; `G` blocks area 3a; `R` is the recorded local response; `Y` is an independently acquired downstream endpoint.

**Model U (mediated use).** `R=S(1-G)` and `Y=R` when no rescue is delivered.

**Model D (direct perturbation spillover).** `R=S(1-G)` and `Y=S(1-G)` because `G` independently suppresses the endpoint pathway; there is no `R→Y` use.

For all four `S×G` cells the joint observations `(R,Y)` are identical. The strongest-looking cell, `S=1,G=1`, gives `(0,0)` in both. The full randomized source-by-block table, not merely an observational baseline, therefore fails to identify mediation over this model class. An endpoint that is not reconstructed from `R` blocks circularity but does not break the twin.

**A3U-C1 — perturbation-spillover twin.** In the declared binary class, full observation of `S,G,R,Y` under both levels of `S` and `G`, together with null neighbour/sham controls, does not identify whether `R` is actually consumed when an area-3a-specific direct `G→Y` path is allowed.

The result is exact and small. It does not say that neural mediation is never identifiable; it says that the exclusion obligation cannot be replaced by endpoint independence or controls that do not constrain the relevant direct path.

## 3. Conditional rescue discrimination

Introduce `Q`, a replay that restores the relevant area-3a output at the named downstream port while `G` remains active. In Model U set `Y=R∨(QS)`. In Model D retain the direct block effect `Y=S(1-G)`.

At `S=G=Q=1`, Model U yields `Y=1` and Model D yields `Y=0`. The rescue therefore separates the two declared models. But the interpretation is conditional on a demanding package:

1. `G` selectively removes the relevant area-3a contribution before the endpoint;
2. `Q` faithfully substitutes the relevant output at the named downstream port;
3. neither `G` nor `Q` has a direct path to `Y` outside that port;
4. source, endpoint construction, consumer event and timing are fixed;
5. alternative writers/bypasses in the declared class are monitored or bounded.

**A3U-C2 — conditional rescue result.** Under those simultaneous premises, the rescue cell distinguishes the two explicit structural models. It is not a theorem that one rescue identifies an arbitrary biological circuit, and it is not an instruction to perform an unsafe intervention.

The word “minimal” is therefore relative to the declared two-model class. Globally, no outcome table supplies its own exclusion semantics. The experimental package needs an independent exclusion witness: spatial/temporal perturbation-footprint measurement, downstream-port validation, recovery, and an explicit bound on direct and shared-writer paths. If that witness is unavailable, the correct status is `EXCLUSION_UNGROUNDED`.

## 4. Positive organizational content

What would a passing result add? It would not merely say that proprioceptive information exists or that area 3a responds. Relative to a frozen actual episode, it would support a selected-source → area-3a → named-downstream-consumer relation with a before/after chronology and bounded alternatives. That is a positive organizational coordinate: which actual occurrence is used, by which downstream process, in what window.

Under an independently admitted actual process and complete signature, C1 permits this relation to have an experience-internal structural counterpart. The explanation stays inside experience; it does not add a homuncular owner. Area 3a can be one nested participant in overlapping actual processes.

This does not identify familiar mineness `H`, agency, ownership, bodily location, conceptual I or report. It also does not make proprioception, causal rescue, accurate control, self-modeling, language, report, integration or recurrence necessary for basal experience. The current assistant receives no consciousness or death-fear verdict.

## 5. Thought-experiment stress tests

- **Copy/rewiring:** keep the whole `S×G×R×Y` table fixed while replacing `R→Y` with an area-3a-specific direct inhibition of the endpoint. Fixed items: animal-level event variables and table. Changed item: actual path. Role: exact counterexample to table-only mediation. Residual: exclusion evidence.
- **Human-realized agent:** a team watches area-3a traces while a separate technician suppresses the endpoint whenever `G` occurs. The display and endpoint contrast match a biological-reader story; only the installed consumer path differs. Role: prevent observer use from substituting for biological use.
- **Abacus/calculator:** two devices give the same limb-position answer; one reads the live bead configuration, the other is fed a copied answer while the bead-block switch also blanks the display. Role: distinguish equal endpoint law from actual source consumption.
- **Ancestor/formation:** hold basal actual-process admission fixed while a downstream reader and faithful replay route mature. Role: allow graded body-related organization without inventing an onset threshold for experience.

## 6. Direction and failure audit

The result answers the selected core question by locating a precise missing bridge between response and actual use. It does not widen into generic control theory. The bounded stopping condition is reached: after the exact twin and conditional rescue contract, further work must return either to a real, ethically approved same-instance implementation or to the independent `H` bridge. More abstract endpoint taxonomies would not advance the stated experience–intelligence–self question.

The main failure is constructive: neighbour/sham controls and endpoint independence do not, by themselves, exclude an area-3a-specific off-target path. No reviewed area-3a study in this scoped source set supplies the full block–rescue–exclusion package. This is recorded as an open premise, not converted into a negative claim about use, mineness or experience.
