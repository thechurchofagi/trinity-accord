These custom Matlab scripts are used in the computational analyses performed in the study "Parietal alpha frequency shapes own-body perception by modulating the temporal integration of bodily signals" by Dr D'Angelo et al.- Master_BCI.m" is the main script that delivers the best model parameters estimated values (minimized NLL) for the different models tested in the study and compares the goodness-of-fit of these models. - "modelprediction_log_BCI.m" is a function that generates predicitons about the participants' responses (yes or no) according to the Baysian causal inference model for a given set of parameters.- "NLL_BCI_EEG.m" is a function that calculate the negative log-likelihood of the model outcome (prediction) for the EEG study in the manuscript. - "NLL_BCI_tACS_Sigma.m" is a function that calculate the negative log-likelihood of the model outcome (prediction) that assumes a change in sensory uncertainty with the tACS stimulation. - "NLL_BCI_tACS_Psame.m" is a function that calculate the negative log-likelihood of the model outcome (prediction) that assumes a change in a priori probability for touch and vision to come from a common cause with the tACS stimulation. -
