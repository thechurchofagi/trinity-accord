# Selected bodily mineness: prediction, confidence and installed use

R156 v0.1, 7 October 2026. Unpublished conditional research note.

## 1. The selected question

The intended target F_O is the felt character of a represented body/body part as one's own, within an experiential episode. This verbal description selects a research target; it does not yet supply a formal phenomenal classification or a measurement procedure. It is distinct from a judgment about anatomical membership, a posterior probability, the capacity to report, or an extra owner producing experience. Ambiguous episodes remain unclassified; we do not force every token into a measured yes/no category.

The question is which organizational description could be sufficient for this selected target on a declared actual domain. R155 provided a finite mechanism for source and action-efficacy attribution. That result must not be promoted into a mineness law simply because its registers can be given suggestive names.

Read A v1.2 §§8.11–8.14 for the physical-witness and body-centered/self-model distinctions. C1 supplies an experiential interpretation of complete actual organization. U1 has no posterior-confidence or self-model gate. Neither statement by itself equates F_O with one of the descriptors below.

## 2. Three candidate descriptions, not three established consciousness theories

Fix an actual bearer/window domain Omega, a candidate-body convention, intervention ports, temporal grain and admissible operations before comparisons. Candidate descriptors are only defined where their stated protocols and realization bridges are available.

| Descriptor | Retained information | Candidate sufficient-target claim | Omitted information |
|---|---|---|---|
| J_P | Declared action-prediction law or score in its fixed task | F_O=psi_P(J_P) | Source attribution and its installation may differ. |
| J_Q | J_P and the source/action attribution readouts q_O,q_A | F_O=psi_Q(J_Q) | A readout can have different causal consumers despite the same present value. |
| J_U | J_Q and a declared finite intervention-response table for attribution use | F_O=psi_U(J_U) | Complete organization, omitted interoceptive/affective/temporal relations, and mineness interpretation are not automatically supplied. |

The functions psi are hypotheses fixed across the comparison domain, not licenses to fit a different meaning after each outcome. There is no presumption that the third is phenomenally sufficient just because it retains more information. These restricted proposals do not exhaust Bayesian or predictive-processing accounts.

R155 §4 P2 already separates a source consumer while holding action evidence fixed. It defeats a claim that the declared action evidence alone recovers that **functional consumer**. It does not independently defeat every prediction-based account of felt ownership. That would require a corresponding independently established F_O contrast.

## 3. Exact installation witness W

Consider two deterministic devices c in {0,1}, evaluated at the same instant, with typed binary attribution latch M, background latch D and body-related consumer port V. A separate prediction port has the same fixed law in both devices. Readouts q_O,q_A are also identical at this instant; M can be the already computed threshold latch of q_O, as in R155. Copying a q value does not predetermine all its downstream wiring.

Set the actual pre-intervention state M=D=1 in both devices, and define

    V_c := c M + (1-c) D.

Because c is binary, V is binary. Device c=1 uses M; c=0 uses D. The two admissible interventions do(M=0) and do(M=1) replace M's structural assignment, hold D=1 and c fixed, and leave the independent prediction/readout ports fixed. They are diagnostic latch interventions; the off-manifold q/M combination they may produce is not claimed to be a new calibrated Bayesian history. The current ordinary input/output observation includes M,D,V and the prediction/readout ports, but excludes the wiring bit c. Thus even that relatively rich snapshot agrees between the devices.

Define the functional use target

    R(c) = 1[V_c(do(M=0)) != V_c(do(M=1))].

This is sensitivity to the attribution latch at this consumer, not global agency, an intrinsic body boundary, or felt mineness.

### Proposition W1: a matched snapshot cannot recover this use relation

Both devices have the same J_Q snapshot and V=1. Yet R(1)=1 and R(0)=0. No deterministic fixed decoder of that common snapshot can return R correctly for both.

Proof. With c=1, the intervention pair of consumer outputs is (0,1). With c=0, it is (1,1). Before intervention M=D=1 gives V=1 in both. All other included coordinates were stipulated identical. A fixed decoder on equal inputs has equal outputs and cannot equal the different R values. QED.

The two-entry intervention table in J_U does recover R on W: compare its entries for equality. This is sufficient for the defined use target on these two devices, not complete structural recovery. The witness expresses a standard distinction between observed values and causal organization; no historical novelty is claimed for it.

### Boundaries and changed assumptions

- If J_Q already includes the wiring or intervention table, it is not the snapshot descriptor just defined and W1 does not apply to it.
- If interventions cannot physically be implemented while preserving the stipulated context, W is an abstract model counterexample only. A physical inference requires an actual realization satisfying the same operation contract.
- If D is allowed to change with M, the displayed intervention outputs need not hold. Holding it fixed is a substantive condition.
- Equal observations and unequal use do not yet establish unequal F_O. That extra step would assume the very mineness bridge under investigation.
- Even if both devices are actual and their constitutive role difference establishes different complete organizational types, C1-OI gives a conditional difference of complete experiential types, not identification of the differing coordinate as F_O.

## 4. What has actually been ruled out?

| Statement | Verdict | Reason |
|---|---|---|
| Fixed action evidence recovers every R155 source consumer | False in the stated R155 domain | P2 gives a consumer contrast at matched action evidence. |
| Current attribution/readout snapshot recovers every installed use relation | False in W | W1 gives equal snapshot and unequal R. |
| The declared two-entry table recovers R in W | True, by construction and direct proof | R is the inequality of its entries. |
| Equal attribution confidence implies equal felt ownership | Not established or refuted here | No independent F_O values were supplied for the pair. |
| Installed use is sufficient or necessary for any experience | Not inferred; incompatible with treating this mechanism as a new U1 gate | The target is a particular organization, not basal existence. |
| Installed use is sufficient for selected bodily mineness | Open candidate, with domain and interpretation obligations | Extra information does not prove phenomenal sufficiency. |

This distinction prevents a subtle error: an operational counterexample is not automatically a phenomenal counterexample. A conditional experiment could connect them, but its measurement and intervention assumptions must be stated independently.

## 5. Positive construction route

Retain the R155 acquisition mechanism and augment its descriptor with the installed source-consumer relation, instead of treating the posterior number as the complete relevant organization. This makes the proposed description discriminate an actively used attribution from a matched unused/copy-only value. It is a concrete improvement to a **candidate explanation**, not proof that mineness equals causal use.

The next finite comparison should keep candidate body, time and prediction/evidence history fixed while varying (i) causal incorporation into body-related processing, (ii) report-only access, and (iii) the proposed temporal persistence relation. Before assigning experiential conclusions, specify what exactly counts as a difference in F_O and which independent interpretation/measurement premise warrants that assignment. Report access must not silently become either the definition of F_O or a gate for any experience.

For any proposed J, apply the existing C:P2_COORD / R155:BRIDGE_CRITERION: a fixed decoder to independently specified F_O exists iff F_O is constant on the J-fibers. This is a formal obligation, not an empirical decision procedure when F_O is unavailable. If a genuine F_O contrast is established within a J-fiber, that descriptor's sufficiency fails on that domain. If no contrast is found in a finite set, unrestricted sufficiency does not follow.

## 6. Four thought-experiment checks

- **Formation:** installing the M-to-V connection changes a causal role even when the observed M,D,V values stay fixed. This identifies a physically relevant organizational acquisition that a snapshot would miss. It does not locate an onset of experience or reconstruct evolution.
- **Abacus/calculator:** an externally calculated confidence can equal an internally used one. Equality of the number does not settle the use relation; an actually coupled larger process may include either substrate.
- **Human implementation:** matching a transcript is insufficient for the intervention table. Participants' actual conditional responses and wiring must implement it; their individual experiences need not be excluded for the larger process to be considered.
- **Copying/rewiring/memory:** copying the latch value preserves the snapshot, whereas changing which latch controls V changes R. R147's report-isolated memory and R155's consumer-active memory are compatible under their different assumptions. No transfer of numerical identity is inferred.

Purpose verdict: this is on the selected-mineness research path because it identifies a precise omission in candidate organizational descriptions and prevents an invalid operational-to-phenomenal inference. It is a modest conceptual/formal advance, not a solution of mineness or a major new general theorem. The main open bridge remains F153-11 / R155-G1. Next research must address its independent target/interpretation, rather than repeatedly proving functional insufficiency.
