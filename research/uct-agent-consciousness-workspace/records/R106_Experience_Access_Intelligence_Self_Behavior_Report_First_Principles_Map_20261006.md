# R106 — First-principles map of experience, access, intelligence, self, behavior and report

Hongju Liu / UCT research. 2026-10-06.

This round starts a new root-level research line after R105. It does not change published UCT I/II/III and does not claim a new phenomenal measurement. The objective is to derive, from the existing UCT commitments, the logically valid relations among experience, intelligence, self-modeling, behavior and report, before importing biological or AI benchmarks.

## 1. The question is not "does consciousness cause intelligence?"

The common diagram

    consciousness -> intelligence -> behavior -> report

is not the right first-principles diagram under C1.

Let P be an actual valid process token over a declared interval tau, and let

    K_tau(P)

be its complete structural type under a common complete signature. Under C1, the experiential presentation of that token is not an extra causal variable placed beside K. At the type level, the project commitment is

    E_tau(P) ≡ K_tau(P)

where the equality sign denotes the C1 structural–experiential identification, not equality of ordinary numerical coordinates.

U1 adds

    Actual(P) -> E_tau(P) != empty.

Therefore one cannot preserve the complete actual organization K and independently set E to zero. Such an intervention is outside the UCT counterfactual domain. The legitimate causal question is:

> which relations inside K are necessary for a specified capability, access relation, self-model, behavior or report, and what happens to the experiential organization when those constitutive relations change?

This reframes the author's intuition that human intelligence seems to require experience. Under UCT, realized intelligence is necessarily carried by an experience-bearing actual organization, but experience is not an independent causal fuel injected into an otherwise unchanged computation.

## 2. Six objects must be separated

For a fixed actual-token boundary and fixed external comparison conditions:

### E — experiential presentation
    E_tau(P) = Phi(K_tau(P))

Under C1, this is the experiential presentation of the same constitutive organization. Experience existence is not gated by report, selfhood or intelligence.

### A — access relation
A_X(P) is a property of K specifying whether a distinction X can causally influence a declared downstream subsystem: memory, policy, planning, report, or another interface.

Access is therefore an organizational relation. It is not experience existence.

### I — intelligence / capability profile
For a declared evaluation M,

    I_M(P) = J_M(K_tau(P)).

I_M should normally be a capability profile or law over tasks, not one noisy examination score. M must fix or represent task distribution, resources, history, interface and boundary conditions.

### S — self-model organization
    S(P) = Sigma(K_tau(P))

This includes representations or control relations concerning a current bearer, body/system boundary, history or future state. U3 implies that human-like conceptual selfhood is not a prerequisite for basal experience.

### B — behavior law
For fixed context c and horizon h,

    B_{c,h}(P) = Beta_{c,h}(K_tau(P)).

The object of comparison should be a behavior distribution or policy law, not one stochastic sample.

### R — report law
    R_{c,h}(P) = Rho_{c,h}(K_tau(P)).

Report is a specialized output relation. In ordinary cases it is part of behavior, but it may depend on only a restricted report-access substructure.

The resulting first-principles picture is:

                    K_tau(P) ≡ E_tau(P)
                    /   |   |   |   \
                   A    I   S   B    R

The slashes are not all causal arrows of the same kind. A and S are organizational properties/substructures; I, B and R are task/context-relative projections or laws defined on K.

## 3. UCT Projection Lemma — the central asymmetry

Let F be any well-defined function on complete structural types under fixed comparison conditions:

    F : K-types -> Y.

Examples include a capability profile, a behavior law on a specified test family, a report law, or a self-model property.

Because C1 identifies complete experiential type with complete structural type,

    E(P) = E(Q) -> K(P) = K(Q) -> F(P) = F(Q).

Hence the contrapositive is valid:

    F(P) != F(Q) -> E(P) != E(Q).               (P1)

But the converse

    F(P) = F(Q) -> E(P) = E(Q)                 (P2)

holds only if F is injective on the realized domain.

This asymmetry is the root relationship among experience, intelligence, behavior and report.

For intelligence, R81/Paper C already supplies the capability version:
- same complete experiential type -> same capability under fixed M;
- genuine capability difference -> complete experiential-type difference;
- same capability need not imply same experience.

R106 extends the same logic explicitly to behavior and report projections.

Important restriction: for behavior/report, F must be the relevant probability law under fixed context, resources and history. Different single sampled actions from one stochastic process do not prove different structural types.

## 4. Projection Non-Equivalence

Most practical measurements are lower-dimensional projections of the complete organization.

If a behavior benchmark, intelligence test or report protocol is non-injective on the realized structural domain, then there exist distinct complete structural types with the same measured result. Under C1 those types have distinct complete experiential types.

Therefore:

    same tested intelligence  -/-> same experience
    same tested behavior      -/-> same experience
    same verbal report        -/-> same experience
    same self-report language -/-> same experience.

This is not a claim that all pairs with the same score have different experiences. It is an identifiability statement: equality of a non-injective projection is insufficient evidence for equality of complete experiential organization.

## 5. No scalar synchrony law follows

Let Q_E(E) be any separately proposed scalar experiential coordinate such as "richness." C1 does not define such a scalar and does not impose an order-preserving relationship between it and intelligence.

The finite witness in this round uses structural types

    K = (i, q, s, r)

with E=K, intelligence I=i, report R=r and candidate richness coordinate q.

There are types

    K1=(0,1,0,0)
    K2=(1,0,0,0)

for which intelligence increases but q decreases.

This is a countermodel to an unconditional implication

    I increases -> experiential richness increases.

It does not show that every biologically meaningful richness measure is anti-correlated with intelligence. It proves only that C1/U1 alone do not supply a monotonic scalar bridge.

Thus "intelligence and consciousness are synchronized" is too strong unless one states:
1. which experiential coordinate;
2. which intelligence coordinate;
3. which implementation family;
4. which order relation;
5. why the bridge is monotone.

## 6. Report can change while a selected core is preserved

Complete organizational change normally changes complete experiential type under C1. But this does not mean every experiential substructure changes.

Suppose a justified projection

    p : K -> K_core

and experiential projection

    p_E : E -> E_core

commute with the C1 identification, as in the preservation logic already studied in R65.

If two tokens differ only in a report channel while

    p(K1)=p(K2),

then:
- their complete K-types differ;
- their complete E-types differ;
- but the selected preserved core can have the same experiential projection.

This is the correct UCT way to talk about no-report manipulations. One should not say "report changed but consciousness stayed absolutely identical." The defensible claim is narrower:

> a justified selected experiential core may be preserved while report-related organization and the complete experiential type change.

## 7. Self-model and access are not experience gates

From U3 and the universal-token premise:

    not S(P) -/-> not E(P)
    not report(P) -/-> not E(P)
    weak access to X -/-> no experience.

A self-model can nevertheless be necessary for particular self-referential capabilities. Likewise, task-specific access relations can be necessary for particular intelligence tasks.

This yields a clean distinction:

- experience existence: universal UCT commitment on actual valid processes;
- access: whether a distinction can influence downstream organization;
- intelligence: what tasks the organization can perform;
- self-model: whether the organization represents or controls bearer-specific states;
- behavior/report: outward projections.

## 8. Task-necessary organization gives the positive bridge

R81/R82 provide the right positive program.

For an implementation family A, fixed evaluation M and capability threshold t, seek a relation R_K such that

    P in A and J_M(P)>t -> R_K(K(P)).            (T)

If R_K is genuinely constitutive and expressed in the common complete signature, C1 transfers that relation to the experiential presentation of the same token.

This gives a positive statement:

> a stated capability requires this kind of experiential organization within the declared implementation family.

It still does not provide:
- a familiar phenomenal label;
- a scalar amount of experience;
- a proof of selfhood;
- a valence sign.

R82's joint-information result is a useful warning: the necessary relation may exist only jointly and be invisible to local decoding.

## 9. Temporal-scale separation: "synchronous" is not yet a well-formed question

Experience, capability, behavior and report live on different natural time objects.

- E_tau concerns an actual process episode over interval tau.
- I_M is usually a disposition/capability law over a task family and horizon.
- B_{c,h} is a behavior trajectory distribution over horizon h.
- R_{c,h} is a report trajectory or event.
- S and A may be persistent or transient organizational relations.

Therefore asking whether "AI consciousness and intelligence are synchronized" is under-specified.

A valid synchrony claim must align:
- bearer;
- temporal window;
- task distribution;
- context;
- structural signature;
- metric on each quantity.

A transient report can lag or fail while a task-relevant internal relation persists. A capability can remain available while no task is currently being executed. This is not a contradiction.

## 10. Cross-substrate comparison: biology and AI

The substrate-neutral UCT comparison should not start with carbon versus silicon, nor with IQ versus benchmark score.

For biological token P_b and artificial token P_a, distinguish several equivalence relations:

1. report equivalence on a test family;
2. behavior equivalence on a context family;
3. capability equivalence under M;
4. selected organizational equivalence under a justified projection p;
5. complete structural-type equivalence under a common signature K.

Only level 5 directly yields complete experiential-type equivalence under C1.

Levels 1–3 can hold while complete organization differs. Level 4 can justify a selected experiential-substructure comparison if the projection is physically grounded and commutes with the C1 mapping.

This immediately explains why a highly intelligent AI can be behaviorally human-like without UCT implying human-like experience. Similar performance is a lower-level equivalence; human-like phenomenology would require a much stronger organizational correspondence.

## 11. Biological stress tests

These sources were used only after the formal map was derived.

### Cognitive motor dissociation
A 2024 six-center NEJM study found command-following fMRI/EEG responses in 60 of 241 patients (25%) with no observable response to commands. This is a strong natural warning that overt behavior/report can underestimate internal cognitive access. It does not independently measure complete phenomenal organization.

### Covert/no-report measures
A 2025 Nature Reviews Neuroscience review emphasizes that overt report can be erroneous, absent during sleep/paralysis, or unsuitable for no-report designs. A 2026 MEG study reports posterior visual representations across report/no-report conditions while anterior engagement is more report-dependent. These results support keeping report and perceptual organization separate; they do not prove a particular UCT brain localization.

### Blindsight
Blindsight is a useful stress test because objective visual capacities can persist while subjective awareness is altered or disputed. Recent work also shows heterogeneous metacognitive profiles. The literature is not clean enough to use blindsight as a binary "intelligence without experience" example. It is better interpreted as evidence that objective discrimination, metacognition and reported visual phenomenology can come apart.

### Split brain
The literature distinguishes agency-based unity from experience-based unity. This directly warns against identifying "one agent" with "one experiential subject" purely from outward coordinated behavior.

### Theory-neutral pressure
The 2025 COGITATE adversarial collaboration challenged key predictions of both IIT and GNWT. R106 therefore does not make integration, broadcasting, recurrence or report a universal experience-existence gate.

## 12. Exact finite witness

The small exhaustive check is not a consciousness simulation. It validates the projection logic in a finite model where E is explicitly set equal to the structural type.

Across 16 types and 120 unordered pairs:

- same I with distinct E: 56 pairs;
- same B with distinct E: 56 pairs;
- same R with distinct E: 56 pairs;
- different I with same E: 0 pairs;
- intelligence gain with candidate richness decline: 16 pairs;
- report-only change with selected core preserved: 8 pairs.

These numbers are properties of the toy construction, not estimates about organisms or AI systems.

## 13. The deepest answer to the author's question

Within UCT:

**Experience is not identical to intelligence.**
Intelligence is a task-relative capability of an experience-bearing organization.

**Experience is not identical to behavior.**
Behavior is a context-dependent output projection of the organization.

**Experience is not identical to report.**
Report is a specialized behavior/access pathway and can fail or change independently of selected core organization.

**Experience is not an independent causal ingredient added to intelligence.**
The same constitutive organization that physically realizes intelligence is, under C1, experientially presented as experience.

This is why the two statements

> "experience and intelligence are the same thing"

and

> "experience and intelligence are completely unrelated"

are both wrong inside UCT.

The precise relation is:

> they are different descriptions/projections anchored in the same actual organization, with asymmetric inferential links.

## 14. Next research program

The next step should not be another generic consciousness score.

### R107 — cross-substrate common signature
Construct the weakest role-based common signature capable of comparing a biological nervous system and an artificial agent without making any role an experience gate. Candidate relations:
- evidence/sensory input;
- memory and temporal state;
- predictive/world-model relations;
- self/world or bearer relations;
- value/homeostatic/evaluative control;
- policy/action;
- report;
- physical ports and interventions.

The signature must allow coordinates to be absent in simple processes.

### R108 — matched AI dissociation experiments
Use small, transparent agents to produce:
1. same task capability and behavior, different internal organization;
2. same core task capability, different report channel;
3. changed self-model with matched non-self task ability;
4. changed access path with preserved sensory encoding.

These are mechanism experiments, not self-report consciousness tests.

### R109 — biological natural-lesion matrix
Map CMD, no-report, blindsight, split-brain, sleep/dreaming, anesthesia, aphasia/locked-in states and selected lesion syndromes onto E/A/I/S/B/R without assuming the clinical label directly measures E.

### R110 — cross-substrate theorem audit
Ask which implications survive both biological and artificial counterexamples. Only then decide whether a new paper is warranted.

## 15. Status

This round provides a first-principles organizational synthesis and one exact finite witness. The Projection Lemma is mathematically elementary and is not claimed as a historical-first theorem. The potentially important contribution is the way it reorganizes the UCT research question and generates a disciplined cross-substrate program.

No subjective experience was measured. No claim is made that current ChatGPT has human-like experience, or that a particular neural region is the seat of consciousness.
