# A5L thought experiments

| Family | Fixed | Varied | Result / role |
|---|---|---|---|
| ancestor / formation | basal C1/U1 status, current physical contact `P` | whether a learned role intervention `Q` forms an actual `X=P xor Q` coordinate | formation can add self-related organization without becoming a threshold for basal experience |
| abacus / calculator | correct `E=X` table and direct `P` availability | endpoint reads actual `H` versus a direct relational register `X` | decisive `H`-free writer countermodel |
| human-realized agent | represented task, input table and report | whether `X` belongs to the represented agent, human implementer, or nested joint process | blocks transfer of organization across actual bearers and permits overlap without a unique owner |
| copy / swap / memory | copied weights, learned memories, reports and all eight observed cells | present writer is direct `X` versus target-sensitive `H`; orientation is preserved or inverted | separates stored equality from actual current source and selected phenomenal pole |

The thought experiments are countermodel devices, not evidence that any described system is or is not conscious.
