# A4E source and priority scope

This round is a direct correction/application of A4D's probe clause and the existing R172/R173 evidence/use distinction. The hold-versus-write observation is elementary state-transition reasoning; no claim of inventing latches, event logs, provenance, reset experiments or intervention logic is made.

Fixed sources used: UCT I v1.2 C1/U1 and §§8.11–8.14/14.7; effective R172 evidence/use amendments; R173 retentive-binding boundary; A4C and A4D records. No new external empirical source is used and no worldwide priority claim is made.
