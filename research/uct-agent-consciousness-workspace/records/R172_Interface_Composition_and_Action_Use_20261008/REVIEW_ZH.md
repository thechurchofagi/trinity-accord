# R172 中文审查：接口组合、在线行动使用与体验内行动坐标

## 本轮实际推进

R172 没有继续扩张一般证书链，而是完成审查要求的有界返回。

1. **接口组合。** 两个局部有效的组织证书不能直接推出组合系统有效。新增的 Compat_gamma 同时要求同一实际绑定、初始接口一致、连接器产生的输入仍在两个局部证书的允许族中、每个联合转移都投影/细化为两个局部转移，并保持接口一致。满足这些前提时，联合不变集按任意后继和有限路径归纳保持。
2. **失败连接反例。** 两个布尔部件各自在输入 0 下保持状态 0；把输入交叉连接成对方状态的补，从 (0,0) 一步到 (1,1)。这精确指出缺失的是允许输入/接口兼容前提，不是“组合永远不可能”。
3. **在线行动使用。** LiveUse_gamma 不以报告定义，而要求实际连接和消费发生，并在预先限定的中介/切断干预、保真度、局部性和补偿前窗口下，行动结果对该表征路径有差异。
4. **实时与回放。** 实时模型和回放/旁路模型可以在基线的身体状态、表征、行动和报告上完全相同；固定背景后只改变中介，前者行动改变、后者不变。因此输出或报告匹配不能识别在线使用。
5. **体验内解释。** theta_EBA = Anchor ∧ Bind ∧ Compat_gamma ∧ LiveUse_gamma。如果这些关系在同一实际 P/I/K/D/Phi/h 上独立落地且该实例满足 C1，其结构对应物在体验内部。这给出正面的“体验内行动坐标”，不需要额外主人。

## 严格边界

- 体验内行动坐标不等于熟悉的“我的行动”感；B_min/F_O/F_A 仍需独立、非循环的语义与证据桥。
- C1 保持意识特定解释性公设，没有被接口、干预、报告或代码检查推导。
- 在线使用不是基础体验门槛；回放或无报告不由此推出没有体验。
- 有限检查是反例和回归检查；一般组合结论依赖手工的任意后继证明，真实生物或 AI 实例尚未验证。
- 不把人类参与者、被实现的计算和更大的耦合过程视为同一对象；允许嵌套和重叠，不寻找排他的唯一主人。

## 漏洞与失败

八项漏洞保存在 GAP_LEDGER.json。最关键的是：同步接口条件可能过强，异步/随机/混合系统需要不同的时序细化定理；LiveUse_gamma 相对于声明的干预族和路线闭包；真实生物/AI 落地、完整组织及 B_min/F_O/F_A 均未完成。QC-01/03/04/05 仍待独立审查，QC-02 只获得本轮回应证据，研究者不自行关闭。

## 地图与初心

R172-v1.0 为 506 节点、244 规则、141 条非演绎背景联系；R171 前缀精确保持。24/24 地图检查和 9/9 精确检查通过，但这不等于理论全局证明。选题后、结果形成后和保存前方向检查均通过：本轮把辅助证书明确接回身体/行动组织如何在体验内部出现，而没有把报告、自我模型、语言、整合、预测或控制能力变成基础体验条件。
