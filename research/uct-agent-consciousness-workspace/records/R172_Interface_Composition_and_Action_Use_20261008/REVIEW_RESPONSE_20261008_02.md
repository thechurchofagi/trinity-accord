### One explicit actual-role predicate

For a fixed actual D on P,I with grounded relations, define

OnticUse_path(D,k,a;gamma) :=
  exists q,e1,e2 [
    TransferOccurrence(k,q,gamma,e1)
    AND OperandUseOccurrence(q,a,e2)
    AND SameEpisodeOrdered(e1,e2)
  ].

All witnesses are actual occurrences inside the declared carrier/sorts, at times in I. TransferOccurrence is a realized transfer along gamma; OperandUseOccurrence is an executed operand dependence in the production of a, not a dead read, a matching log, an analyst arrow or a variable named self. SameEpisodeOrdered fixes the relevant within-episode temporal order. Their physical interpretation and realization are explicit obligations, not proved by declaring predicate names.

This is a selected executed path, not a necessary definition of every causal use or a guarantee of nonzero net output effect. Redundant/cancelling paths can be executed without a simple cut changing final action. Dynamic selection can read only one of several installed paths. The deliberately narrow target avoids claiming that test availability or sensitivity is constitutive of the process.

Define the corrected internal formula

phi_path(b,k,a;gamma) :=
  Anchor(b) AND Bind(b,k) AND OnticUse_path(D,k,a;gamma).

This is an explicit correction of the application target, not a claim that phi_path is equivalent to the old certificate-laden theta_EBA. Compatibility and evidence remain side conditions of this sufficient research application, not new requirements for experience or for the existence of a path in every possible system.

### Evidence-to-role bridge and its limits

CertUse_path(t,W,E) records a successful fidelity/locality-controlled contrast, with W, E, validity assumptions and intervention intervals retained. R172's LiveUse clauses already contain baseline use; merely renaming that conjunction is NOT a new empirical identification result.

For an inferential route, keep a separate Bridge_path(t,W,E):
(a) a physically grounded realization map identifies the baseline k,gamma,q,a occurrences;
(b) the trials track that same baseline mechanism and declared path, rather than creating a new path during intervention;
(c) the intervention selectively addresses that path, with no off-path direct action or report route;
(d) a declared causal model validates that the contrast identifies the baseline executed operand path;
(e) baseline timing and any cross-trial transport assumptions are discharged.

Only CertUse_path AND Bridge_path supports the claimed role. These are substantive, potentially unproved premises. We do not claim that an action difference alone discharges (a)–(e). In the restricted faithful feedforward live/replay toy class the equations and stipulated execution graph discharge them; no biological or AI instance has done so here. A perturbation that installs a previously unused wire violates (b) and is a counterexample to the overbroad inference.
