## Concrete empirical question

Use the public Experiment 3 data of D'Angelo et al. (2026), DOI 10.1038/s41467-025-67657-w. The original authors already reported stimulation effects, cross-task individual covariation, and a Bayesian uncertainty-versus-prior model comparison. This project asks a stronger additional question: can positive participant-level temporal widths for two tasks and three stimulation conditions be represented as W[t,f] = c[t] * tau[f], with the task factor fixed across stimulation?

This is a deliberately specified bridge/model instance. It is not a necessary consequence of UCT C1, all common-clock theories, the original authors' Bayesian model, IIT, GNW, or HOT. The weaker common-clock model permits fixed task-specific increasing nonlinear links. Differences between these model classes are part of the research target.
