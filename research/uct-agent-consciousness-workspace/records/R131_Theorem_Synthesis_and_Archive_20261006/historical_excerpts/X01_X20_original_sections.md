### X01. The two-mode museum: collecting properties from different regimes

**Target.** High capacity somewhere plus high contextual return somewhere establishes a richly integrated organization now.

**Construction.** A five-bit payload is operated under a clamped, separately specified mode. In mode 0 it retains five independent bits. In mode 1 it computes the parity of all five bits and broadcasts that one bit to all positions. At a two-update horizon, mode 0 has capacity 5 bits and predecessor expressed-return value 0. Mode 1 has capacity 1 bit and expressed-return value 1.

**Result.** The coordinatewise best-looking vector, `(capacity=5, return=1)`, is not realized in either mode. Selecting a capacity threshold of 4 and a return threshold of 1/2 illustrates the logical failure: each threshold is met somewhere, but not together. These numbers illustrate a quantifier error; they are not consciousness thresholds.

**Revision.** All claims must have a common admissible witness. Different tests can be combined, but they must describe one compatible system/regime/protocol family. This does not require all counterfactual alternatives to occur in one trial.

**Status.** Executed finite construction; not an experiential verdict.

### X02. The warehouse attached to a feedback toy

**Target.** A small recurrent component can borrow the capacity of a large independent memory to become a rich global subject.

**Construction.** Combine two independent two-bit contextual loops. Each local loop has return organization; their union retains four bits. Yet the genuine cut between the loops changes no transition probability.

**Result.** Summed capacity does not supply an interaction joining the memories into an additional whole. Adding arbitrarily many independent registers has the same conceptual problem.

**Revision.** The distinctions invoked to explain an alleged whole must participate in that whole's claimed organization. A nearby reservoir of unused bits is not a free source of phenomenal richness.

**Status.** Product-channel and separating-cut checks executed. No claim that either local component experiences.

### X03. The switch opened by the measuring instrument

**Target.** A contextual reset echo plus a matching uninterrupted contextual effect proves that the returning carrier normally mediates the effect.

**Construction.** The source retains local seed `z` and a mode flag `p=1`; the complement retains context `c` and a carrier `m`. The outward operation writes `m=z XOR c`. The final rule is `y=z XOR c` when `p=1`, and `y=m` when `p=0`. Resetting the source to `(z,p)=(0,0)` opens the carrier route. Without a reset the same value is computed from local `z` and context `c`, ignoring `m`.

**Result.** Reset and uninterrupted contextual norms are both 1. Nevertheless, changing `m` while holding the natural mode fixed has no effect. The reset created the very route it was supposed to diagnose. A reset preserving `p=1` gives no seed-dependent echo.

**Revision.** Matched endpoint positivity is not route identity. Use controlled mediator replacement while retaining the actual regime. This construction attacks the interpretation of an individual witness; it is not advertised as proving that every all-cut condition of the full v0.2 system has been met.

**Status.** All binary combinations and the matched true-return control checked.

### X04. Two independent loops behind a cryptographic coordinate screen

**Target.** A dense, strongly connected state-update graph and large cut defect necessarily reveal a new internally integrated physical whole.

**Construction.** Let two physically independent two-bit loops be described by `F(x)=(x1,x0 XOR x1,x3,x2 XOR x3)`. A reversible linear encoding changes coordinates to `y0=x0`, `y1=x2`, `y2=x1 XOR x2`, `y3=x0 XOR x3`.

**Result.** The new coordinate update graph is strongly connected. Under newly imposed coordinate-local cuts its minimum two-step total-variation defect is 3/4, compared with 0 for the real original separating cut. Transporting that original physical intervention through the encoding restores defect 0. Capacity stays 4 bits. The older all-cut contextual score remains 0 in this example; the claim is not that every diagnostic is fooled.

**Revision.** Coordinates cannot supply a new intervention algebra for free. A physical rebuild that really implements the encoded factors with new independent controls is a different experiment, not merely a redescription.

**Status.** Explicit example and complete four-bit invertible-linear-encoding enumeration executed.

### X05. The enormous catalogue with a one-bit inspection window

**Target.** A large number of distinct response laws establishes equally large jointly expressed content in one use.

**Construction.** Store an `n`-bit string `Z`. A uniformly selected index `Q` is revealed together with the bit `Z_Q`. The rows of the query-response channel are different for all `2^n` strings.

**Result.** The one-query capacity is nevertheless only 1 bit. With a uniform message prior, exact recovery of the entire string succeeds with probability `2^{-(n-1)}`. At `n=8`, there are 256 distinct rows but one-query success is 1/128. Reading all eight coordinates on eight occasions can recover eight bits; that is a larger temporal protocol, not one-use integration.

**Revision.** Distinguish stored information, counterfactual response variety, reliable joint decoding, and internal use. This does not bound the whole memory to one bit: the memory contains `n` bits. It bounds this particular inspection channel.

**Status.** Exact kernels checked for `n=1,...,8`.

### X06. Two unreadable shares that become readable together

**Target.** If each component carries no information about a distinction, the joint system carries none.

**Construction.** For a seed bit `Z`, choose an independent fair mask `R`, and output `(R,Z XOR R)`.

**Result.** Each marginal is independent of `Z`; the joint pair determines `Z` exactly. A real internal recombination operation is different from an analyst collecting both records afterward.

**Revision.** Marginal nulls cannot eliminate higher-order organization. Equally, an analyst's joint readout is not proof that the original system uses that joint information, much less that it experiences it.

**Status.** Exact distributions and information calculations executed.

### X07. The mind that disappears every third camera frame

**Target.** A null final-time contextual contrast proves absence of contextual organization throughout the interval.

**Construction.** Use `F(a,b)=(b,a XOR b)`. Its third iterate is the identity. The first coordinate's uninterrupted contextual norm across successive lags is `0,1,0,0,1,0,...`.

**Result.** Sampling only every third update suppresses the intermediate contextual relation. Capacity remains 2 bits. The identity stroboscopic map does not carry the intervention semantics of the intervening steps.

**Revision.** Preserve a temporal response family or actual process trace. A chosen final snapshot is not automatically an adequate description of a temporally extended candidate experience.

**Status.** Twelve lags checked. No phenomenality is inferred from an intermediate positive.

### X09. A continually renewed world with no memory of the opening instant

**Target.** Loss of information about an old seed means the ongoing system has lost all differentiated organization.

**Construction.** At each step a fresh independent bit `u` drives `(a,b)` to `(u,a XOR u)`. Initial-state information falls from 1 bit after one step to 0 after two, while the first internal coordinate continually expresses the fresh input stream.

**Result.** Six successive input bits can be read from the six-step internal transcript, despite complete loss of the original seed. The example is a simple driven mechanism, not a conscious observer.

**Revision.** Separate old-seed retention from current input-sensitive organization. A relay can have a high information rate; that rate is not a sufficient consciousness condition either.

**Status.** Kernel checks and 256 six-step input/preparation transcripts executed.

### X10. Two large systems connected by an arbitrarily rare update

**Target.** Any positive cross-system causal influence creates a comparably substantial new whole.

**Construction.** Start with an independent update kernel `P0`, and at each step independently substitute a cross-coupled update with probability `epsilon`. Over a finite horizon, the probability of at least one substitution bounds the difference from the uncoupled kernel.

**Result.** The bound is `1-(1-epsilon)^H <= H epsilon`. Thus finite-time causal effects can be arbitrarily small. Over a longer horizon they may accumulate, so an instantaneous classification cannot discard the horizon.

**Revision.** Preserve scale, reliability, and time. The bound does not identify an integer subject-fusion point or prove continuity of phenomenal presence.

**Status.** Sixty exact parameter/horizon checks.
