# R199 Thought-Experiment Matrix

| Experiment | Fixed | Varied | Target | Result / falsifier role |
|---|---|---|---|---|
| Complete retained-state clone | current state, transition/readout law, interventions | numerical lineage | lineage from future behavior | All traces match; behavioral continuation cannot recover lineage. |
| Trace erasure | external biography | every current carrier reset | biography versus current retention | Biography alone has no continuation effect. |
| Dormant memory | genuine stored trace | consumer use versus bypass | storage versus same-episode use | Storage does not entail current use; telemetry is required. |
| Fresh mimic | observed savings trace | installed mechanism/history | diagnostic uniqueness | Same trace can arise from a new mimic; mechanism and `H` remain unidentified. |
| Habitual versus copied prosthetic route | task, present functional state as far as measurable | personal formation versus transfer/copy | formation contribution | A difference reveals incomplete matching; equality does not prove no `H`. |
| Human-realized agent | abstract transition table | bearer/implementation | level-of-process error | Equal table does not identify participant, implemented process and whole formation. |
| Abacus/calculator log | stored numeric history | inert storage versus current input | actual use | Data equality does not fix causal role. |
| Ancestor/formation | basal C1 commitment | current retained structure | historical contribution | Only causally carried history matters to current organization. |
| Copy/switch/memory | reports and memory content | active carrier/consumer route | report versus actuality | Report continuity does not establish route continuity or `H`. |

Each thought experiment fixes bearer, interval and signature before comparison. None is an empirical claim about a current assistant or a proof of C1.
