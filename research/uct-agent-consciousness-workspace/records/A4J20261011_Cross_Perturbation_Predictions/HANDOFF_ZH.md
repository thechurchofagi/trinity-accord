# A4J 中文交接

## 本轮实质推进

把 A4I 的“关系扰动 vs 适配/努力扰动”问题写成允许交叉效应的带符号预测合同。只要在看 `J_cont` 前独立确认：关系臂确实降低 `R`、适配臂确实降低 `F`，并把两种候选限定为严格正向的纯桥，那么无需假定操纵选择性：

- `(-,-)`：两者都兼容，不能区分；
- `(-,0/+)`：只兼容 `B_relation+`；
- `(0/+,-)`：只兼容 `B_fit+`；
- 其余四种：两种纯桥都不兼容。

若目标一阶方向没有独立依据，两套预测都扩成全部九种签名，干预名称本身不识别机制。弱敏感性把重叠扩大到四种。本轮因此同时得到一个正面设计条件和一个严格停止条件。

## 关键失败与边界

交叉效应没有被“控制掉”；它们是总效应签名的一部分。不得回归掉形成后努力、成功、记忆、`R` 或 `F` 来制造纯效应。`(-,-)` 必须报告为未决；落在两者之外只反驳声明的纯桥，不推出无熟悉感、无体验或 C1 错误。`J_cont` 的正向体验校准、实际 `RetBind` 使用、完整物理承载者和真人可行性仍不存在。

## 初心与形式化地图

本轮直接比较体验内部的身体接续关系与当下适配，没有增加报告、语言、自我模型、整合、递归、预测或控制的基础体验门槛，也没有寻找唯一主人。完成图仍为 913/424/261，A4J 正式增量 0/0/0；727 个待定对象保持停用、10 条历史规则保持暂停。逐 ID 结构遍历通过不等于全历史语义重证。

审查状态不自闭合：QC-20261008-10 保持 ACKNOWLEDGED/OPEN；IA-QC11、QC-20261008-12/13、SCU-OPEN-R191-NORMALIZATION 保持 OPEN；SCU-AUDIT-DEPTH 保持 AUDIT_INCOMPLETE。
