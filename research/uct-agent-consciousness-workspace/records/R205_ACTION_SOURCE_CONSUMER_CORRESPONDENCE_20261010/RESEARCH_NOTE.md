# Action sources, actual consumers, and the limits of matched prediction

R205 / ASC-RESULT-v0.1.0. Conditional UCT application and finite countermodels; unpublished, with no phenomenal calibration.

## 1. Contribution and antecedents

The question concerns organization of body/action-related self within experience: how can an outcome agree with a prediction while the prediction consumes a different source occurrence from the one driving action? TA25 §6 already establishes that exact prediction does not settle physical attachment and that synchronized commands conceal swaps. R182 already distinguishes shared carriers from equal-valued copies. R204 distinguishes task success, alignment and feedback use. None of those general observations is claimed anew.

The bounded increment is an explicit driver/consumer source square with a recovery contract, followed by a cancellation implementation that defeats extension of that recovery contract to arbitrary consumer architectures. This extends the diagnostic discipline, not the core consciousness axiom. The mathematics is elementary structural-equation reasoning over finite alphabets, with known causal identification and efference-copy antecedents. The exact computation checks the declared equations; it supplies no human data.

## 2. Freeze the episode before interpreting it

Let B denote an admitted bearer candidate over one interval I. Two distinct physical source registers q_B and q_R are fixed: q_B belongs to B, q_R is outside B. Membership is a premise about support and induced relations, not chosen from a feeling report. The model alone does not discharge this premise for a person. Their values b,r lie in X, |X|≥2. Value equality does not identify these register occurrences.

At time t0 the registers are set. At t1 fixed selector s supplies the actuator branch, and fixed selector c supplies the predictor branch. At t2 the plant yields y and the predictor yields z; at t3 the comparator can receive them. There is no learning during this interval. The outcome recipient may be a biological effector, prosthesis or remote effector, but endpoint relocation is a separate variable from source-register membership. Resetting between probes starts a new trial and is not numerical continuation of the earlier token.

The model equations are y=P(q_s) and z=F(q_c), with s,c in {B,R}. P and F are injective; matched-prediction comparisons below fix F=P. The selected signature K_episode includes register occurrences, source/branch/consumer relations, temporal order, transformations, local intervention ports and boundary membership. K_down includes only y,z at t2. These are different views: the larger signature is still not claimed to be a complete human organization. The same-instance binding is (B,I,K_episode,P,F,s,c,reset contract).

Define L iff the actuator's selected source is q_B, and Q iff actuator and predictor read the same source occurrence. L is a bearer-relative action-source location; Q is source correspondence. Neither is a definition of ownership, voluntary action, introspective judgment or H (a selected familiar self-related feeling). Q does not require the same numerical code at both consumers: invertible compensated encoding retains the same physical source relation.

## 3. Scoped claims and proofs

### R205-C1 — Location and correspondence form an independent square

**Type/domain:** finite construction for the two-source single-read class. **All premises:** the fixed episode, |X|≥2, F=P, and synchronized sources b=r=a. **Statement:** all four (L,Q) profiles occur while y=z=P(a) for every a. **Proof:** substitute (s,c)=(B,B),(B,R),(R,B),(R,R). They respectively give (1,1),(1,0),(0,0),(0,1), while synchronization erases selector dependence at K_down. **Counter-scope:** equality for synchronized trials is not equality for all independently varied commands, and not complete-type identity. **Status:** proved within the class. **Experiment role:** a remote source can correspond to both branches; a local source can fail correspondence. This stops correspondence becoming a synonym for endogenous action.

### R205-C2 — Two isolated source probes identify the two selectors under a single-read contract

**Type/domain:** conditional identification theorem in the same class. **All premises:** fixed s,c,P,F; injectivity; access to both y and z; valid independent source interventions; exact reset; no alternative source paths, hidden coupling, writer or branch gate. **Statement:** choose a distinct a' and compare the baseline (a,a) to (a',a) and (a,a'). Which outputs change uniquely recovers (s,c). **Proof:** injectivity makes an output change iff its selected source changed. The four signatures in EXACT_RESULTS are pairwise distinct. This identifies model selectors, not body ownership or actual installation from a generic behavioral correlation. **Counter-scope:** constant F, synchronized-only interventions, invalid reset or additional paths destroy the proof. **Status:** conditional proof. **Experiment role:** an intervention identifies an already specified route; it does not establish a human process boundary.

### R205-C3 — Even all source interventions cannot identify every internally consumed branch

**Type/domain:** counterexample over Z_n, n≥2, with two actual copies/edges of q_B. **All premises:** actuator y=r; direct predictor z=r; comparison predictor z=(r+e1−e2) mod n; physical fan-out gives e1=e2=b absent edge interventions. **Statement:** both installations produce (y,z)=(r,r) for every joint source assignment, yet the latter has two locally effective B-input branches and the former has none. **Proof:** cancellation gives b−b=0 for every source intervention. Independently perturbing e1 by δ≠0 changes z by δ; perturbing e2 changes it by −δ. These edges are functional inputs to the implemented modular computation, even though total B-source influence cancels. The model explicitly includes their intervenable consumption events; a graph drawing alone would not establish execution. **Counter-scope:** if only net output influence defines the target, both have the same net B influence. C3 distinguishes route-level consumption from net source effect; it does not dispute C2 within its no-alternative-path class. **Status:** exact countermodel. **Experiment role:** a null source effect cannot universally prove absence of internal consumption; branch-specific intervention/instrumentation is a separate obligation.

### R205-C4 — Compensated recoding preserves the relation

**Type/domain:** inherited covariance principle applied to this construction. **All premises:** transport input coordinates by a bijection h and replace P,F with P∘h⁻¹,F∘h⁻¹; preserve source occurrences, paths, time and membership. **Statement/proof:** substitution leaves y,z,L,Q unchanged. Code changes are not physical rewiring. **Counter-scope:** transporting values but failing to transport transformations or membership is a different installation. **Status:** conditional application; no new symmetry theorem. **Experiment role:** calculator, human and silicon encodings cannot be sorted by token spelling.

### R205-C5 — The UCT interpretation requires two additional interfaces

**Type:** conditional interpretation, not a new axiom or empirical theorem. **All premises:** an actual admitted token and interval; a complete constitutive signature rather than K_down or this toy subset; faithful occurrence-level carrier/consumer realization; C1. **Statement:** a constitutive source/consumer relation has its corresponding relation inside the experiential organization of that token. A proven complete-type difference has the corresponding complete experiential-type difference. No particular coordinate is thereby named felt agency or ownership. **Proof/source:** tokenwise sort-preserving C1 and its pairwise type equivalence; TA25 D5. **Open additional interface:** an independently identified selected phenomenal target and a fixed, non-oracular bridge relating it to these coordinates. **Counter-scope:** selected graph differences may be omitted by a separately justified macroprocess signature. No unconditional type difference is inferred from extra microscopic gates. **Status:** conditional/open actual and H premises. **Experiment role:** self-related organization is explained within experience, with no additional owner or existence gate.

## 4. Compare three bridge candidates

| Candidate | Organizational consequence | Outstanding explanatory obligation |
|---|---|---|
| Correct prediction identifies endogenous source | Fails C1's matched square; correctness can be supplied by a different synchronized source | Do not treat a proxy match as source membership |
| L and Q identify familiar agency/ownership | Positively specifies an endogenous correspondence in this class, but reflex/clone cases can retain it; passive ownership is a separate target | Independently fix the target, its polarity and scope; no unmeasured H differences are asserted |
| Actual carrier/consumer relations have intra-experience counterparts under C1 | Supplies a structural explanation conditional on actual completeness, and admits passive, remote, overlapping processes | Map which selected experiential character these counterparts explain; compare alternatives without using H to choose boundaries |

The third is the permitted UCT explanatory direction; it is not a completed empirical bridge. The result contributes to UCT by separating task intelligence and predictive accuracy from organization relevant to an admitted bearer, and by identifying the evidence needed to interpret that organization as particular self-related experience.

## 5. Four retained thought-experiment families

| Family | Fixed and changed items | Counterexample role and limit |
|---|---|---|
| Formation/ancestors | Keep actual-process admission; vary whether source branching/consumer coupling forms | New self-related organization can form without a first basal-experience threshold. No real phylogenetic history is reconstructed |
| Abacus/calculator | Fix input/output law; change implemented carriers, manual branches and predictor consumption | Equal arithmetic or prediction does not settle occurrence-level paths. No consciousness ranking follows |
| Humans implementing an agent | Fix algorithm and task; specify people, cards, ports, timing and cancellations | A B-source may be read internally while aggregate influence cancels. Algorithm equality does not certify complete organizational equality |
| Copies/rewiring/memory | Copy register values/reports while changing s,c or branch duplication; alternatively copy complete admitted type | Partial copies conceal routing; complete same-type copies preserve type under C1 but remain distinct occurrences. Memory strings do not select the current source |

Remote/prosthetic control additionally holds q_B and its predictor branch fixed while relocating the effector. Endogenous correspondence need not be defined by anatomical endpoint. Passive source correspondence can coexist with external action initiation. These cases require body-location, agency and ownership to remain distinct targets.

## 6. Exact results and failure boundary

Fresh execution checked 608 single-read installations, 2,872 synchronized episodes, 5,744 isolated-source probe episodes and 38,224 compensated recodings. All 608 selectors were recovered within C2's class. Six cancellation alphabets (n=2…7) matched on all 139 joint source assignments; 1,288 separate branch probes distinguished locally consumed paths. Zero violations of the declared equations occurred. This is reproducibility evidence for a narrow mechanism model, not consciousness evidence.

The extension of C2 to arbitrary consumer installations fails at C3. Complete human carrier identity, actual boundary admission, phenomenal target calibration, and a bridge-sensitive prospective contrast remain missing. Known shared-carrier and permutation reasoning is credited to prior UCT work; a standalone paper is held.
