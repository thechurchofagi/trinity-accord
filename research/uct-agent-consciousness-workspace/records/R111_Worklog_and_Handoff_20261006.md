# R111 工作记录与交接 — intelligence capability-support hypergraph

日期：2026-10-06。

本轮把“智能”从一个scalar重写为任务族的组织支撑结构。

定义关系宇宙R；每个能力T对应一族minimal support sets M_T。多个M_T成员=同能力的degenerate/multiple realization。真实智能比较应该保留capability profile、必要/使用关系、替代路径、共享关系、资源与时间条件，而不是只留一个benchmark数字。

精确5关系/3任务toy枚举32个relation sets、496对：
- same capability profile但different support：100对；
- same scalar J但different capability profile：38对；
- 同完整profile111 witness：
  {g,v,m,s} 与 {g,m,s,x}；
- scalar都1但profile不同：
  {g,v}->100；{g,m}->010；
- capability从100提升到110的同时relation sets不可比较：
  {g,v} -> {g,m,x}，说明能力增加不意味着组织是旧组织的superset。

shared relation g lesion使111->000；专门关系v/m/s lesion各只掉对应一项。说明general deficit可来自多能力共享一个必要关系，不必假设脑里有一个scalar intelligence substance。

这给experience-intelligence关系更精确的答案：每种能力T应找task-necessary relation R_T；若该relation被实际K验证，C1下它属于该token体验组织。但另一个系统完成同一T可走alternative support，因此same capability不能推出same experience organization。

神经科学degeneracy是强先例，不称multiple realizability新发现。R111增量是把它和UCT R79/R81/R82接成capability-support hypergraph，并明确scalar intelligence是两次压缩：K->capability profile->score。
