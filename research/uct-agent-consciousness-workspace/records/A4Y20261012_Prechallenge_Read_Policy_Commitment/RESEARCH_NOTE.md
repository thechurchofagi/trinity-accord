# Challenge-blind read-policy commitment at a bodily/action consumer boundary

Version `A4Y-PBRW-v0.1.0`. Disabled research application; no physical or phenomenal installation.

## 1. Result in one sentence

A4X's full finite port suite can be reproduced exactly by a one-port consumer whose hidden mode receives the challenge identity; the bounded repair is not a larger test suite or a bare state snapshot, but a state-to-read-policy witness that is fixed before an independently drawn challenge, blind to pre-read challenge cues and bound to the actual named consumer.

## 2. Exact negative result

For each finite labelled challenge `j=(u_j,v_j)` and target bit `b(j)`, a hidden controller can select one port and identity/negation so that its one-port output equals `b(j)`. Therefore every finite public Boolean challenge family admits an exact challenge-aware one-port mimic. In A4X's four-row AND/OR case, 16 of 256 row-indexed policies mimic each target; both port lineages may remain present and a separate monitor may log both values.

This sharpens A4X-G03. More public rows cannot solve test awareness in the declared class. Output agreement, port presence, logs and an internal state value are all insufficient unless the state is temporally and causally tied to the actual read policy.

## 3. Positive bounded repair

The `PBRW` contract contains three simultaneous relations:

- **BEFORE:** read policy is witnessed before the independently generated challenge;
- **BLIND:** no challenge label, schedule, shared RNG or equivalent cue can reach the dispatcher before the relevant reads/output, except the named data values;
- **BOUND:** the witnessed state determines the actual read set/order of this occurrence of `m` and is not a sidecar or self-authored log.

Within the declared one-port polarity family, this reduces the rival to four fixed modes. None reproduces AND or OR on the full factorial. Drop-one countermodels show why each clause matters. The claim is deliberately local: it does not certify that the cue/control inventory is complete, that the witness is physically independent, or that an arbitrary controller has been ruled out.

## 4. Why this matters for bodily/action mineness

A4V and A4W seek a positive organization in which multiple bearer-centred routes may jointly shape one target without an exclusive master. A4X placed the missing obligation at actual port participation. A4Y shows how test-aware mode selection can counterfeit the functional part of that obligation, and what kind of actual mechanism evidence would block one precise counterfeit family.

The order remains:

```text
actual consumer-bound dual read relation
  -> conditional C1/R157 experiential structural counterpart
  -> open B_pc^family/H_cf interpretation
  -> separate fallible judgment/report route.
```

Nothing flows backward from output, attestation text, report or body label. A token lacking PBRW is not denied experience or mineness; only this proposed participation inference remains unresolved.

## 5. Failure and stop conditions

PBRW fails if the challenge is predictable before commitment, if trial order or shared random state leaks the challenge, if the state record is generated by the consumer under test, if the recorded state does not bind the actual read event, if the consumer/boundary changes across rows, or if alternate writers/readers remain unbounded. A cryptographic hash can bind bytes without proving that the bytes are the operative policy; a fresh nonce can support freshness without proving consumer binding.

The round stops at this bounded family. It does not enumerate arbitrary controllers. The next empirical/organizational step is to find one actual interface where `z -> rho -> read_m` and the cue cut are independently inspectable. If none is available, return to the independently specified `B_pc^family/H_cf` target rather than extend the certificate chain.

## 6. Originality boundary

The finite construction is elementary. Adaptive-test leakage, commitment and challenge-response freshness have established literatures. The project-level contribution is the exact placement of their relevant distinction at A4X's named consumer boundary, the proof that a state snapshot alone does not close `SEPP`, and the three-clause typed witness with explicit UCT firewalls. No general priority claim is made.
