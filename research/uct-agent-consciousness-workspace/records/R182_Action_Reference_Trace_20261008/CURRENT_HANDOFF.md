# R182 当前交接：行动参照轨迹与受阻尝试

本轮针对R181和QC13留下的核心漏洞继续推进，没有重复SB20261008已经完成的“外显动作/想象目标绑定”玩具修复。

新增结构：在两个行动情境之间，区分“同一个实际参照载体分支供给两处”与“两个数值相同的复制寄存器”。定义行动参照轨迹ART，以及受阻行动坐标：

`EAC_tau = PC_tau AND E_tau AND Block_tau AND ART_tau`。

64个配置、12项检查通过。共享轨迹和复制轨迹在基线D/C/E、运动、命令值和报告上可以完全相同；预先声明的A侧校准扰动只在共享轨迹中改变B侧命令，给出一个未由感受报告拟合的跨情境后果。生物/义肢、故意/反射、肯定/否定报告标签都不决定ART/EAC。

关键边界：故意与反射双胞胎仍可共享全部选定ART/EAC结构。因此本轮只得到体验内部的一个正面组织坐标，没有证明它就是“尝试感”。在C1和实际完整P/I/K独立成立时，该关系是体验结构的一部分，不需要额外主人；命名为人类具体感受仍需独立桥接。

思想实验包括：共享载体与等值复制、瘫痪/机械受阻、反射双胞胎、义肢整合、主动想象。义肢可以获得ART，生物组织不是门槛；单纯接入装置也不自动获得ART。

证据只作约束：Evans等2015的BMI研究排除“外显生物运动必需”；Bertoni等2025区分动作前状态、反馈和报告；Imaizumi等2017的小样本义肢/姿势研究限制固定生物—装置边界。没有原始数据复算或实际人类ART实例。
