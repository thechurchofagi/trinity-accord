# R181 当前交接：体验内部的“实践中心化”候选

本轮提出正面但有限的组织候选：对固定行动目标，区分实际指令使用 D、行动—结果闭环 C、失配被同一策略用于坚持/修正/取消 E，以及后来作者归因 A。实践中心化 PC=D且C。它不是意识开关、所有者、主观感受或报告。

128个配置和12项检查显示：内部来源+实际运动+肯定报告仍不能识别PC；外来建议也可进入PC，内部内容可绕过；受阻尝试可有PC和失配使用但无运动；被动/外加运动可有运动而无PC；主动想象可对“想象这一活动”有PC而没有外显运动。初次误写256配置，已保留失败并修正。

UCT正面解释是：若同一P/I/K上的D/C/E/A实际关系独立成立，C1使其在体验内部有结构对应，不需要额外主人。候选地图把顺畅做、费力尝试、被动发生、主动想象和事后认领分开。但PC是否就是行动感、E是否就是“努力感”仍未证明；自动技能和后见归因是主要反例。QC10/IA-QC11/QC12实际应用继续OPEN。
