# Thought experiments

| Family | Held fixed | Varied | Role in A5K |
|---|---|---|---|
| ancestor / formation | basal C1/U1 status and present contact | whether route `R` forms and is actually used | route acquisition changes organization, not the threshold for experience |
| abacus / calculator | correct `P` output and preserved `A` | `R` consumption versus a direct gate on `Z` | direct-gate countermodel |
| human-realized agent | represented task and output table | which nested actual process owns the route and cut | blocks transfer from implementer organization to represented agent |
| copy / swap / memory | stored values, reports, and `P×C` table | current source route, gate, and semantic pole | separates copied equality from actual use and selected meaning |

## Direct-gate twin

Leave `R` unused and let `Z` read direct `P`. The intervention gates `Z` during the cut phase and ungates it during rescue. `A=P` remains continuously usable. This reproduces the full table without making `R` the source of `Z`.

## Semantic-free route twin

Let `Z` genuinely read `R`, and faithfully cut and restore `R`. Hold that physical history fixed while assigning `H=C`, `H=notC`, `H=0`, or `H=1`. The output table is unchanged, showing that actual route use is not yet selected phenomenal meaning.

## Complement twin

Let `Z` read the genuine cut/rescued `R`, but set `H=notP`. This preserves physical source attribution while reversing the proposed experience target pole.
