# Selective-source cut–rescue contract

Version: A5K-SSCR-v0.1.0  
Status: disabled finite application; no human, artificial, or phenomenal token is installed.

## 1. Frozen objects

Fix one bearer, held tool, interval, actual contact coordinate `P`, crossed nuisance cue `C`, selected experiential-location target `H`, candidate physical route `R`, candidate channel `Z`, and independent direct-position reference `A`. `R` is a physically typed route that carries the contact coordinate in the declared finite model. It is not named `H` by definition. `A=P` remains available throughout baseline, cut, and rescue.

The target signature is:

```text
Z_baseline=P, Z_cut=unavailable, Z_rescue=P; A=P in all phases.
```

“Unavailable” is a typed failure symbol rather than the valid location value zero.

## 2. Simultaneous obligations

| ID | Obligation | Exact role | Failure condition |
|---|---|---|---|
| `BIND` | same-instance binding | bearer, tool, event, route, source port, readout and reference belong to one frozen package | cross-study or cross-token assembly is needed |
| `F` | factorial cue exclusion | all four `P×C` cells; `Z` and `A` follow `P`, not `C` | either channel follows `C` in a discordant cell |
| `RE` | route efficacy | the declared intervention actually cuts `R` before `Z` consumes it and rescue restores `R` at the same interface | source/event/chronology or cut/rescue fidelity fails |
| `NDR` | no direct readout intervention | cut/rescue has no direct write, gate, criterion shift, label change, or mode-aware bypass at `Z` | the direct-gate twin remains possible |
| `CLOSE` | alternate failure-route closure | no other cut-sensitive route can suppress and restore `Z` while `R` is unused | an admitted compensator or hidden controller reproduces the signature |
| `SB` | semantic bridge | independently fixes why the transported `R`-coordinate realizes the selected `H` source, allowing explicit failure/undefinedness | `R` dependence is used as its own phenomenal definition |
| `CO` | common orientation | prospectively fixes the positive pole from `R/P` to `H` | `H=P` and `H=notP` are both compatible |

The physical route inference uses `BIND AND F AND RE AND NDR AND CLOSE`. The selected-target inference additionally requires `SB AND CO`. These are not alternative proof routes.

## 3. Exact bounded result

In the declared 216-model family, the observed signature leaves 36 models, both physical source classes, and all six `H` laws. Declaring route cut/rescue efficacy alone leaves 18 models, both physical sources, and all six `H` laws because a direct gate at `Z` can reproduce the pattern. Excluding direct readout intervention leaves six models: all read `R`, but all six `H` laws remain. Adding `SB` reduces the target to the complement pair `{P,notP}`; adding `CO` leaves `H=P`.

Thus the cut–rescue package can ground **organizational source diversity**. It does not manufacture **phenomenal source diversity**. `SB` is the remaining A5J semantic obligation in more explicit form.

## 4. Noncircularity rule

`SB` must be fixed independently of the same `Z/A` failure table. A physical `K`-definable `R` relation can be transported conditionally by C1/R157 once actual complete organization is established. That licenses an experience-internal structural coordinate, not the external name `H_tip`. Using “the route whose cut removes Z” as the definition of `H_tip` would collapse the evidence into the target and violate R157's semantic residual.

## 5. Stop rule

If `NDR/CLOSE` cannot be supported, stop at “the intervention controls Z.” If they can be supported but `SB` cannot, stop at “Z depends on the actual route R.” If `SB` is supplied without `CO`, retain the global complement. None of these failures changes C1/U1 or licenses “no experience.”
