# Endpoint and installation contract

## Same-instance fields

| Field | Required declaration | Failure condition |
|---|---|---|
| Bearer / interval / target | one participant, trial interval and body/action target | population label or delayed summary substitutes for the token |
| Complete application signature | sensors, actuator, perturbation/guidance, route carrier/consumer, timing and response interface | an unrecorded path can generate the same output |
| `R` actual use | present ordered carrier-to-consumer consumption of the retained target route | training history, decoder fit or memory report alone |
| `L_sel` | predeclared selection latency/conflict/automaticity criterion | inferred from smooth motion or success |
| `L_kin` | predeclared kinematic error/smoothness criterion | inferred from subjective ease |
| `Q` | separate cue familiarity test | inferred from route history |
| `J_H` | positively oriented comparative bodily-establishedness judgment | defined by `R`, fluency, success or marker outcome |
| `R_J` | recorded response key/code and reversal provenance | report action identified with target experience |

## Required four-cell attempt

| `R` | `L_kin` | candidate realization | principal threat |
|---:|---:|---|---|
| 0 | 0 | novel unsupported target action | reused general route may set fine-grained retention |
| 0 | 1 | novel guided target action | guidance substitutes causal work and directly changes sensation |
| 1 | 0 | retained route under unexpected perturbation | compensation may switch the actual route |
| 1 | 1 | retained unperturbed action | ceiling and demand differences |

This table targets external fluency only. It does not certify the corresponding `L_sel` values.

## Endpoint firewall

Primary item: “In which interval did acting feel more like an already-established way of acting through this body?”

Record separately: cue recognition; selection ease/automaticity; physical effort; kinematic fluency; success; agency; ownership; liking; confidence; response key; demand expectation. Do not form the primary target by averaging these scores.

## Replication and stop rules

1. Use at least two physically different realization families for each critical off-diagonal or state a quantitative direct-effect bound.
2. Reject the pure route bridge if the endpoint follows intervention family within a fixed verified cell, response-key reversal, or either fluency measure rather than `R` on held-out trials.
3. Mark the route assignment unresolved if carrier/consumer use is inferred only from behavior or telemetry correlation.
4. Do not transport to nonreporting populations without a separately defended class-conditional bridge.
5. A failed bridge leaves basal experience and C1's general status untouched.
