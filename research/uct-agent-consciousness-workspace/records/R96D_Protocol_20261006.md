Question: does accurate separate prediction of current virtual bearer's and successor's future availability suffice for an installed task-only continuation decision?

1. Derive expected binary payoff f(Q,O) as a function of marginals q,o and joint probability j=P(Q=1,O=1). Check all sixteen Boolean payoff tables using rational arithmetic.
2. Construct two four-world causal tables with fixed exogenous O and pointwise Q1>=Q0. Both have q0=1/4, q1=3/4, o=1/2 and action-1 cost 1/4. Match every action-conditional Q/O marginal. Test whether task payoff Q OR O gives opposite optimal actions.
3. Enumerate all four endpoint combinations of the feasible joint probabilities; compute the exact decision interval. Audit all 16 deterministic Q0/Q1 bit-vector pairs satisfying the specified counts and monotonicity, with O fixed to (1,1,0,0). Retain every case, including ties if any. Count is to be computed, not assumed correct from this document.
4. Verify the best achievable decision value when the controller sees only the matched marginal interface, with balanced context prior. Compare with a controller receiving the joint law. Treat utilities as installed design specifications, not inferred feelings.
5. Show that a trusted substitute suppresses instrumental continuation value only for substitutable tasks (OR); a complementary task (AND) reverses that comparative static. Do not call the comparison a universal behavioral prediction.
6. Test the bounded-payoff total-variation substitution inequality on the declared rational examples. It is a mathematical check, not evidence for a phenomenal bridge.
