# R109 工作记录与交接 — 生物natural-experiment六轴矩阵

日期：2026-10-06。

承接R108，系统审计生物天然解离案例，用E/A/I/S/B/R六轴记录，不把诊断标签当体验读数。

最强结果：
- CMD：241个无床旁command response者中60人（25%）有fMRI/EEG command following；B/R弱不等于A/I无。
- Locked-in：严重B/R输出损失可与意识及相当认知保存并存。
- no-report：report demand与部分感知表征可分离，支持R不是E同义词。
- anesthesia：外部同样unresponsive可对应connected consciousness、disconnected/dreaming或unconsciousness；这是现实的behavior non-injectivity。
- blindsight：视觉task ability可部分保留而主观visual content/metacognition改变，但体验状态异质，不能当“智能无体验”二元证明。
- split-brain：agency unity与experience unity必须分开。
- dreaming：E可在在线external B/R很低时存在；self/metacognition还能在梦内变化。
- aphasia/language impairment：verbal R失败可与非语言认知和体验保存并存。
- cortex/cerebellum/subcortex文献反对简单neuron-count或单一region等同体验量。

本轮提出“dissociation topology”作为下一跨底物比较对象：不比较一个consciousness score，而比较E/A/I/S/B/R哪些边在什么intervention下断开或保留。
