# UCT-GD v0.2.0 — From preserved distinctions to effective regulation

Start with RESEARCH_NOTE.md; HANDOFF_ZH.md is the Chinese continuity record.
Run `python code/verify_endogenous_regulation.py` (without -O) after installing requirements.txt. The generated JSON and CSV are model verification, not empirical data. Read the review before applying the results.

This continues GD v0.1.0; it is not a new DOI paper or a replacement for the published UCT-RC manuscript. Proofs, limitations, failure history and actual persistence receipts are separate. No official UCT map version is changed.
