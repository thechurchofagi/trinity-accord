# R185 中文交接：跨尺度关系发生与成员资格

## 本轮实际完成

R185 把 R184 的“保留目标路线”接到局部保持过程、执行器环和整体组织的重叠问题上。核心区分是：

1. **实际关系发生** `rho` 是带有发生身份、端点、机制/端口和时间的具体事件；
2. **成员资格** `Mem(rho; P_i, K_i)` 是这个发生是否构成某个实际过程 token 的完整、token 相对组织；
3. 一个发生可以同时有多个成员资格，但多个数值相等或同步的副本仍是多个发生；
4. 同步器只会新增一条组织关系，不会把两个副本变成同一个发生。

有限模型遍历 16 个配置，15 组断言全部通过。它区分了 `(一次发生, 多个成员资格)` 与 `(多个复制发生, 各自成员资格)`，并保持输出、局部值和报告可以相同的反例。该模型没有体验变量，也没有人体或现有 AI 的实例数据。

## 对初心和形式化地图的检查
