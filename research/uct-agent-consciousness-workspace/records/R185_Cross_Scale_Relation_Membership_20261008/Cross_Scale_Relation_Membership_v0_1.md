# Cross-scale membership of one actual relation

**UCT research note R185, v0.1 — 2026-10-08.**  This is a conditional organization-level result and a finite countermodel.  It is not a proof of C1, a measurement of experience, an exclusive subject selector, or a paper-release decision.

## 1. Question and inherited boundary

R184 strengthened the positive action-organization account through target-correct resumption after obstruction, but a reflex twin retained the whole selected `TBI/ART/EAC/RTR` profile.  The promised next question is therefore not another proposed feeling label.  It is:

> When can one actual retained-target-to-use relation be a member of a local retention process, an effector loop and a whole-organism process at once, and when do matched local values instead belong to numerically distinct copied relation occurrences?

UCT I v1.2 already permits overlapping and nested actual process tokens and explicitly denies that an exclusive maximal boundary is required.  Its §6.1 also says that the independent product argument does not establish a general gluing construction for overlapping processes.  `CG20261008` subsequently gives coherent overlap transport and interaction-coverage conditions.  R185 does not claim those standard gluing results again.  Its narrower target is **occurrence-sensitive membership after the actual tokens and one common episode have been declared**.

Keep four levels separate:

1. the common actual episode and its physical event/relation occurrences;
2. an actual process token and its token-relative complete organization;
3. a local scientific representation or estimate of that token;
4. the experiential organization supplied tokenwise by C1, plus any still-open named interpretation.

## 2. Occurrences, values and membership

Fix one actual episode structure

\[
\Omega=(E,\mathcal R,\preceq,\ldots)
\]

in a declared typed signature.  A primitive relation **occurrence** is

\[
\rho=(\iota_\rho, R, e_1,\ldots,e_k),
\]

where the occurrence identifier `iota_rho`, relation type `R`, ordered physical event endpoints, mechanism/port facts and time are grounded in the episode.  A value carried by the relation is a property of this occurrence; it is not its numerical identity.  Two occurrences may have equal type and value while remaining distinct.

For an independently admitted actual process token `P_i`, let `j_i:C_i -> E` be its physically grounded carrier inclusion and let `K_i` be its complete token-relative constitutive signature.  Define

\[
\mathrm{Mem}(\rho;P_i,K_i)
\]

only when all of the following hold simultaneously:

1. `P_i` is an actual process token on the declared interval;
2. every endpoint/support event of `rho` lies in `j_i(C_i)`;
3. the occurrence and its relevant mechanism, ports, time and boundary dependencies are constitutive facts represented in `D^ontic_{K_i}(P_i)`;
4. the attribution is inherited from `Omega`, rather than reconstructed from equal values, a report or a successful test.

This is a membership definition, not a consciousness gate.  A relation that crosses an analyst's preferred boundary may require enlarging or correcting that token description; an arbitrary larger set of variables does not thereby become an actual token.

Define physical same-occurrence equivalence for two local representatives by

\[
\rho_i\sim_\Omega\rho_j
\quad\Longleftrightarrow\quad
j_i(\rho_i)=j_j(\rho_j)=\rho
\]

including occurrence identity, endpoints, type, port/mechanism role and time.  Equal decoded target values, isomorphic relation types or equal outputs do not imply `~_Omega`.

The cross-scale incidence profile of an occurrence class is

\[
M_{i,[\rho]}=1\;\Longleftrightarrow\;\mathrm{Mem}(\rho;P_i,K_i).
\]

The number of memberships is the column sum of `M`.  The number of actual relation occurrences is the number of grounded occurrence classes.  These counts answer different questions.

## 3. Shared-occurrence membership lemma

**R185-C1 — scoped shared-occurrence membership.**  Let `P_1,...,P_n` be independently admitted actual tokens in one episode `Omega`.  Suppose each token organization is a faithful token-relative restriction/completion of `Omega`, with materially relevant boundary facts retained.  If one grounded occurrence `rho` has its full constitutive support and signature facts in every selected token, then

\[
\forall i\in S,\quad \mathrm{Mem}(\rho;P_i,K_i).
\]

There is one occurrence class `[rho]` with membership profile `1_S`; it is not `|S|` copies.

**Proof.**  The same episode occurrence is included by every `j_i`, and each faithful token organization contains that occurrence as a constitutive relation by premise.  Membership follows by definition.  Equality of the local representatives follows through their common image `rho`, not through value equality.  Counting the one equivalence class gives one occurrence, while summing incidences gives `|S|` memberships.  No subject or phenomenal identity claim is used.  `square`

The lemma is deliberately conditional.  If one alleged local object is merely a view, omits a constitutive endpoint, or fails the actual-token criterion, the corresponding membership conclusion is unavailable.  If an omitted boundary mechanism makes the relation nonlocal to the declared token, the token description must be repaired rather than the relation silently imported.

## 4. Target-retention instantiation

Use three candidate tokens within one action episode:

- `P_L`: a local target-retention process;
- `P_E`: an effector-control loop;
- `P_W`: the larger organism/tool episode.

In the shared architecture, the same target carrier event `m` and consumer event `u` occur in the overlap of all three carriers, and one installed occurrence

\[
\rho=(\iota_\rho,\mathrm{consumes\_target},m,u)
\]

is constitutive in all three complete token-relative signatures.  Its incidence column is

\[
(M_{L,[\rho]},M_{E,[\rho]},M_{W,[\rho]})=(1,1,1).
\]

If the three process candidates satisfy the actual-token criterion, UCT does not require selecting only one.  `P_L` and `P_E` may overlap rather than nest; `P_W` may contain their shared occurrence and additional relations.  P3 prevents mere embedding from being treated as cessation.

This model does not assume that every local carrier supporting the same value is part of every token.  Membership follows the physically grounded occurrence and constitutive signature.

## 5. Equal-valued-copy countermodel

Construct a copied architecture with two distinct occurrences:

\[
\rho_L=(\iota_L,R,m_L,u_L),\qquad
\rho_E=(\iota_E,R,m_E,u_E),\qquad \iota_L\ne\iota_E.
\]

Let both carry target `tau`, let local readouts both return `tau`, and let the whole output resume the same target.  Give the incidence columns

\[
M_{\bullet,[\rho_L]}=(1,0,1),\qquad
M_{\bullet,[\rho_E]}=(0,1,1).
\]

The local retention view, local effector view, whole output and any fixed report bit can match the shared architecture exactly.  Yet the shared architecture has one relation occurrence with three memberships, while the copied architecture has two relation occurrences with four total memberships.  Therefore:

**R185-C2 — value/output nonidentification.**  Equal relation type, target value, local readout, whole output and report do not identify same-occurrence equivalence or the incidence profile.

The construction is a finite witness.  It does not claim that every biological copy is functionally invisible or that the complete organizations are equal.

## 6. Occurrence intervention and the synchronizer dilemma

Predeclare an occurrence-specific content intervention after establishing physical identity.  In the shared architecture, changing the one target occurrence changes both local projections because they are views of the same occurrence.  In the copied architecture with the cross-copy synchronizer disabled or clamped, changing `rho_L` need not change `rho_E`.

This supplies evidence about the declared occurrence structure only under intervention fidelity.  A copied architecture can mimic shared propagation by adding a synchronizing mechanism `sigma` from the changed copy to the other.  But then `sigma` is an additional actual occurrence/relation in the whole organization.  One must either:

- include `sigma`, in which case the complete organization differs from the one-occurrence shared architecture; or
- omit it, in which case propagated equality is unexplained and cannot serve as membership evidence.

**R185-C3 — synchronizer boundary.**  Propagated equality among distinct copies does not convert them into one occurrence; it adds a relation whose membership and boundary must itself be represented.

This is the cross-scale version of the established copy/rewire discipline.  It is not a new general theorem about causal identity.

## 7. Tokenwise C1 transport and its exact limit

Assume now that each selected `P_i` is independently actual and that its declared `K_i` is complete for that token.  C1 supplies a tokenwise isomorphism

\[
h_i:D^{ontic}_{K_i}(P_i)\cong\Phi_{K_i}(P_i).
\]

If `Mem(rho;P_i,K_i)`, then `h_i(rho)` is a relation occurrence in the experiential organization of that token.  For a shared physical overlap, the `CG20261008` comparison maps

\[
g_{ij}=h_j\circ\mathrm{id}_{\rho}\circ h_i^{-1}
\]

coherently relate the token-relative images on the physically identified overlap, when all required signatures and overlap maps are admitted.

**R185-H1 — conditional cross-scale experiential counterpart.**  One grounded physical occurrence shared by several actual tokens has a token-relative structural counterpart in each token's experiential organization, and the grounded overlap diagram transports coherently under the tokenwise isomorphisms.

This does **not** establish:

- that `h_i(rho)` and `h_j(rho)` are one numerically identical phenomenal event outside the declared comparison quotient;
- one exclusive owner or privileged scale;
- that the token experiences are independent, summed or fused substances;
- felt trying, familiar mineness or any report content;
- the truth of C1 from physical observations.

The positive result is therefore a structural answer to a limited question: actual overlap need not duplicate a relation or erase a local experience.  A further theory of a particular unified feeling or subject individuation remains a separate bridge.

## 8. Thought experiments

### TE1 — shared actuator trace

Fix the same physical target carrier `m`, consumer event `u`, action, output and no-report condition.  Let local retention and effector-loop tokens both contain the same grounded `(m,u)` consumption occurrence, while the whole contains it plus body/environment relations.  Changing scale changes the token-relative complete organization but not the occurrence identity.  Role: positive witness for multiple membership without an extra owner.

### TE2 — synchronized mirror register

Replace the one carrier by two physically distinct registers initialized to the same target and coupled by `sigma`.  Fix all baseline outputs.  The values match, but there are two target-consumption occurrences plus a synchronizer.  Clamp `sigma` and perturb one register.  Role: counterexample to value-based identity; if the clamp is impossible, actual membership remains underidentified rather than proved shared.

### TE3 — prosthetic reroute

Hold the target, report and gross movement fixed.  Initially one neural target occurrence is consumed by both the local controller and whole body-tool loop.  Reroute the effector to a prosthetic controller that consumes a copied register.  If the original local process persists, it is not erased; the incidence profile changes.  Role: shows that bodily material is not the membership criterion and that rewiring can change cross-scale participation without creating or destroying basal experience by fiat.

### TE4 — human-realized agent

Fix a human formation implementing an agent.  A symbol copied across participants can have equal content while being many physical occurrences.  A single shouted or wired event may instead participate in several overlapping coordination subhistories.  Role: prevents the represented program or shared value from deciding the physical occurrence count.

### TE5 — ancestral embedding

Fix a continuing cellular relation while embedding it in increasingly large actual organizations.  P3 permits the local token and relation membership to persist; new whole relations can add memberships without making the cell's relation three numerical copies.  Role: connects cross-scale membership to UCT's no-first-conscious-ancestor and non-erasure commitments without claiming unchanged content.
