## 必须保持的理论边界

- 在 UCT 内，C1 是固定的意识特定公设；U1 从 C1 与非空实际承载者推出。不能循环地宣称从纯物理证明了 C1。
- 不新增自省、内部访问、报告、self-model、recurrence、integration 等体验存在门槛。实际过程可以简单、稀疏、嵌套、重叠；连接不自动给出一个排他的主体。
- 实际过程、完整组织、科学投影、因果摘要、统计估计、主体是不同对象。有限机制成功不能自动升级为实际完整组织。
- 体验、智能、行为和报告不能直接等同；报告通常属于行为。固定且定义良好的能力 J 差异约束完整体验类型，不推出体验数量、丰富度、valence 或 fear 的标量排序。
- R127 的 cut-TV 界须固定共同且有支持的外部信息 b 和查询 q，或对完整联合 cut (C,B) 比较。不能把它套到丢弃外部变量的内部边际 C 上。
- 各摘要随机闭合不推出联合闭合；分别有能力不推出同一资源/时间/端口下可同时执行。
- D 的延续控制证据不直接推出主观恐惧；D 的 L0–L9 不是 U1 存在条件。不要对当前助手有无意识或死亡恐惧作定论。
