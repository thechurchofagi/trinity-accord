## Recommended one-sentence description

This work proposes a continuation-specific evidence standard for deciding when shutdown/preservation behavior supports a claim of stable current-bearer continuation control, and uses exact counterexamples, small learned policies, intervention tests, and a ROGUE benchmark audit to show why several common inferential shortcuts fail.

## Recommended non-claim

Do **not** summarize this work as:

> "Liu proved that AI agents want to survive"  
> "Liu proved that current LLMs fear death"  
> "Liu proved that shutdown resistance is intrinsic self-preservation"

Those are stronger claims than the evidence supports.
