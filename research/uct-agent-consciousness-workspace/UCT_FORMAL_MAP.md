## 2. How to read an implication

The [machine-readable graph](UCT_FORMAL_GRAPH.json) contains **328 nodes and 157 rules**. It is a source-anchored dependency index, not a proof-assistant encoding. The [complete proof ledger](records/R137_Executable_Feedback_Interfaces_20261007/PROOF_LEDGER.md) gives each rule's premises, conclusion, proof sketch and source, followed by every node.

- All premises inside one rule's **all_of** must hold together.
- Separate rules concluding the same node are alternative sufficient routes.
- Definitions and ontology specify the admitted domain. An empirical premise is not discharged by assigning it a node.
- A source reference or contextual connection is not an implication.
- “Manual conditional pass” means the argument was checked given the premises. It does not mean those premises were measured or independently established.
- Global typing is mandatory: an actual token, a complete type, a finite view, an estimator, a dynamical state, a capability law, a behavior law and a subject selector are different objects.

For every comparison fix the bearer, interval, boundary, common signature, state domain, operation ports, time grain, outputs and task/resources as applicable. An operation must have the same meaning on both sides. For partial operations, enabledness must also be preserved; R126/R128's deterministic theorem uses total maps.

## 5. C: experience, capability and identification

Under C1 let e=Φ(k), with Φ bijective at complete types. Let J_M be a well-defined isomorphism-invariant capability profile under fixed tasks, resources and context M. Then

\[
J_M(k_1)\ne J_M(k_2)
\Longrightarrow k_1\ne k_2
\Longrightarrow \Phi(k_1)\ne\Phi(k_2).
\]

This is **C:P1**. The converse fails when J_M is noninjective. An ability difference therefore constrains complete experiential type, without imposing a “more intelligent = more experience” scalar order. Behavior and report laws are context-relative; a sampled action is not a law, and report is generally a kind of behavior.

For a selected coordinate C(k), **C:P2_COORD** gives the exact identification condition:

\[
C=g\circ J_M
\quad\Longleftrightarrow\quad
J_M(k)=J_M(k')\Rightarrow C(k)=C(k').
\]

C1 is not needed for this factorization fact. Full experiential identification additionally requires J_M to be injective on the admitted complete types. Increasing observations intersects fibers (**C:OBS_REFINEMENT**); it does not automatically create autonomous state dynamics.

**R128**, proved [in full here](records/R128_Unified_Formal_Map_Audit_20261006/R128_Joint_State_Derivation.md), adds:

\[
\text{common deterministic dynamics + each summary closed}
\Rightarrow \text{joint summary closed on its image}.
\]

For stochastic dynamics that implication is false without an additional condition. With independent fresh fair U, set

\[
X^+=U,\qquad Y^+=U\oplus Z,\qquad Z^+=Z.
\]

Each individual next-coordinate law is fair and closed. Yet current states (0,0,0) and (0,0,1) share the same observed pair while predicting, respectively, equal and unequal next pairs. Their joint next-state laws disagree. This counterexample concerns all eight states/all initial distributions; its four-state reachable restriction is a retained counterlimit.

The exact repair is

\[
p(s)=p(t)\Rightarrow p_*K_a(s,\cdot)=p_*K_a(t,\cdot)
\quad\text{for every declared operation }a.
\]

Conditional independence plus marginal closure is sufficient, not necessary. These are standard closure principles used to block an unsafe cross-paper inference. No historical novelty for lumpability is claimed.
