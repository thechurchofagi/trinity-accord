# UCT I and II v1.1 scientific audit package

Run from this directory with Python 3.10 or later:

    python verification/check_rc4.py
    python verification/check_transformations.py
    python verification/reproduce_shared_models.py

The first script is preserved historical code. The other two are new v1.1 implementations.
Archived CSVs remain under baselines/B_v1.0_audit; regenerated results are separate.
Main manuscripts and supplement explain the premises, source domains, and limitations.
Checks do not establish experience, A1/A5, human-data validation, or peer review.
The historical v0.54 source ledger retains old terminology; use the current ledger for v1.1.
All paper text and project-authored audit material: CC BY 4.0, Hongju Liu, 2026.
External literature is cited, not reproduced in full. No font files are distributed.
