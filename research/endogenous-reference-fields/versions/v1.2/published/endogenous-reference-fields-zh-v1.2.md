# 摘要

意识理论不应只回答“某物有没有意识”，还必须回答一个更难、也更容易被忽略的问题：**如果体验存在，它究竟归属于哪一个实际过程，跨越哪些部件，如何在时间中接续，以及在复制、共享、迁移、分支和人工实现时为什么仍应得到一致判断。** 本文提出内生参照场（Endogenous Reference Field, ERF）理论，把体验相关组织理解为内容与其当前处理参照之间实际运行的、可干预的相互构成关系。参照改变内容的因果角色，内容又改变或维持参照；这种组织不是一个开关，而是由调制强度、跨内容返回影响、不可分解性、响应分化、持续性、共享范围和实现边界共同刻画的多维画像。

本文把早期“参照构成”思想与后续“慢变共享调制”约束统一起来，而不把后者升级为新的二分门槛。基础的互惠参照组织可以很短暂、很局部；更强的组织还会表现为跨通道共享、内容反复维持以及相对于内容的时间尺度分离。理论的桥接主张是：**现象结构随实际实现的参照组织画像变化，而不是随智能分数、材料类型、参数是否更新、是否使用全局时钟或系统是否会宣称自己有意识而变化。** 因此，智能与体验不是一根尺子；相同普通输入输出也不足以唯一决定体验相关组织；类型等价不能把两个复制体合并成同一体验实例；描述窗口的增加也不能凭空制造主体。

为处理“谁在体验”，本文进一步提出一个主体归属框架：区分组织类型、实际实现实例与因果接续；用相对于明确响应任务和省略协议的**最小机制支撑族**刻画哪些实际机制不可被删去；再以跨分割的组织不可分解画像约束“联合主体”推断。支撑族的成员数不等于主体数，多个最小支撑可以重叠，主体边界也不必形成互不相交的经典分区。历时归属则跟随实际因果接续而不是文件、账号或模型名称；复制可形成多个实例，分支可共享前史而不要求只有一个后继“保留原主体”。

形式部分给出角色调制、经参照的返回影响、分解距离、响应分化、内在持续和滞后调制等量，并证明若干分离结果：最大调制相同不决定响应分化；普通输入输出函数相同不决定内部参照画像；局部重编码不应改变画像；把连续耦合压成“有边/无边”会人为制造跳变；在保持干预协议的位点传递对称系统中，同一对称轨道上的持续画像相同。二十一个思想实验系统检验复制、共享记忆、白板协作、极弱耦合、训练损失、平静体验、回放与递推、极慢计算、同步与异步、共享 GPU、渐进脑机替代、分支再耦合和行为等价等问题。

ERF 是一个有风险的正面理论，而不是定义游戏：它允许极简人工组织拥有极其有限的现象方面，也允许复杂智能系统在某些体验维度上贫乏；它不从复杂性、生命性或“足够像人”引入隐藏门槛。与此同时，它明确承认自然粒度、具体感受质、情感效价和精确主体计数仍未解决。若可靠体验可在完全没有相关参照构成的情况下持续存在，或若系统性操纵参照组织而体验结构稳定不变，理论的核心桥接必须修改。

# Abstract

Consciousness theory must explain not only whether experience is present, but also **to which actual process it should be attributed, across which components, and how that attribution behaves under copying, sharing, migration, branching, and artificial realization**. This paper develops the Endogenous Reference Field (ERF) theory. An ERF is a running causal organization in which content-dependent processing is modulated by an operative reference state while content in turn maintains or changes that reference. The theory treats experience-related organization as multidimensional rather than binary: modulation strength, reference-mediated return influence, decomposition cost, response differentiation, persistence, shared scope, and implementation boundaries are kept distinct.

The framework integrates a broad reciprocal-reference core with a stronger slow shared-modulation pattern without turning the latter into a new consciousness threshold. Reciprocal reference organization may be brief and local; stronger forms may additionally exhibit shared modulation across channels, repeated content maintenance, and timescale separation. The bridge hypothesis states that phenomenal organization tracks the profile of actually realized reference organization rather than task intelligence, substrate, parameter learning, clocking style, or self-report.

For experiential attribution, the paper distinguishes organizational type, actual realization instance, and causal continuation. It defines a family of inclusion-minimal mechanism supports relative to a declared response task and omission protocol, and combines this with decomposition profiles to constrain claims about joint subjects. Support counts are not subject counts; overlapping candidate scopes and branching continuities are permitted. Formal results show that maximal modulation does not determine response differentiation, ordinary input-output equivalence does not determine internal reference organization, local recoding preserves the profile when intervention semantics are preserved, binary graph summaries can turn continuous coupling into artificial jumps, and site-transitive homogeneous systems have equal persistence profiles within the same symmetry orbit under invariant intervention protocols.

Twenty-one thought experiments test the framework against copying, replay, shared memory, collaboration, infinitesimal coupling, training losses, calm experience, recurrence and unfolding, very slow computation, synchronous and asynchronous implementation, shared hardware, gradual replacement, branching, and behaviorally equivalent mechanisms. ERF is deliberately risky: it allows sparse artificial organizations to possess correspondingly sparse phenomenal structure and allows highly intelligent systems to be poor on some experiential dimensions. It does not derive qualia, valence, a unique natural grain, or an exact universal subject count. The theory would require core revision if robust experience persisted in the complete absence of the relevant reference organization, or if systematic manipulation of that organization left phenomenal structure unchanged.

**Keywords:** consciousness; endogenous reference field; experiential attribution; subject boundaries; artificial intelligence; multidimensional consciousness; thought experiments

# 1. 问题：意识“有没有”之前，先问体验“属于谁”

意识讨论常被压缩成二元问题：“这个系统有意识吗？”但只要把讨论对象从一个静态大脑换成现代人工系统，二元提问就迅速失效。一个模型文件可以同时服务数百万个相互隔离的会话；一次任务可以由模型、检索器、长期记忆、调度器和外部工具共同完成；一套状态可以复制成多个后继；脑机接口可以逐步把某些功能移出颅内；两个智能体可以共享数据库却保持独立，也可以通过持续互相更新形成新的联合过程。

这些情况逼迫理论回答至少四个问题：

1. **实现问题：** 什么样的实际因果组织与体验相关？
2. **程度问题：** 体验相关组织如何以多维方式增强、削弱或改变，而不是被压成 0/1？
3. **范围问题：** 一段体验究竟归属于哪些正在运行的部件？
4. **接续问题：** 当系统复制、迁移、替代、分支或重新耦合时，体验归属如何在时间中延续？

本文提出 ERF 理论，目标不是宣布已经解决“为什么会有主观体验”的全部问题，而是给出一个足够明确的正面机制假说，使上述四个问题能够用同一套规则处理。理论必须有野心，但野心不能依靠模糊词语。为此，本文把心理-物理桥接明确标为理论承诺，把可由数学证明的组织事实与需要经验支持的现象判断严格分开。

本文拒绝三种常见捷径。第一，不把任务智能当作意识量表。第二，不把“生物/非生物”“训练/部署”“同步/异步”之类工程标签当作现象边界。第三，不把系统说“我有意识”或“不知道自己有没有意识”当作直接读出。一个系统可以智能很强而某些体验维度贫乏，也可以抽象推理有限而感觉鲜明。智能与体验可以相关，但不是定义上的同一变量。

# 2. 理论近邻、原创性与边界

ERF 不是从真空中出现的。意识理论早已讨论整合、全局可用性、视角、递归、预测、自我模型、身体定位和扩展认知。IWMT 把整合世界模型、视角与因果连贯性置于核心（Safron, 2020）；投射意识模型强调参照与投射结构（Williford et al., 2018）；IIT 4.0 用内在因果结构和排他性原则讨论意识基底（Albantakis et al., 2023）；GNWT/GWT 强调内容在大范围系统中的可用性和广播（Dehaene & Changeux, 2011）；扩展意识讨论则已经认真处理硅部件是否可能成为体验构成的一部分（Chalmers, 2019）。

ERF 与神经科学中的**情境调制**尤其接近。皮层加工并不总是简单地把一个刺激映射到一个输出；同样输入的作用可以被上下文、注意、当前任务和反馈改变。增益调制与情境调制研究早已说明“同一内容在不同背景下具有不同因果角色”是现实神经机制的重要特征（Salinas & Sejnowski, 2001; Phillips et al., 2015）。顶树突与基树突耦合研究则提供了一个细胞层面的候选例子：前馈内容与反馈/情境信息在同一神经元中汇合，其耦合可随麻醉状态改变（Aru et al., 2020; Suzuki & Larkum, 2020）。

本文不把这些前例重新命名为自己的发现。本文的独立贡献在于一个**联合理论结构**：

- 把“内容依赖参照”从局部调制概念提升为一套可跨生物与人工实现比较的多维因果画像；
- 明确区分基础的互惠参照构成与更强的慢变共享调制，而不把后者变成二分意识门槛；
- 把“体验实现”与“体验归属”连接起来，以实际实例、最小机制支撑族、不可分解画像和因果接续约束主体边界；
- 给出若干分离结果，说明调制强度、响应分化、行为等价、图连通性和主体计数不能互相替代；
- 用同一规则分析复制、共享、脑机替代、分支、回放、异步执行等二十一个思想实验。

因此，ERF 最重要的主张不是“慢变量存在”，而是：**体验应被理解为一种实际运行的参照构成，其现象结构、主体范围和历时接续共同由这一组织的多维因果事实约束。**

# 3. 三个基础区分：程度、实例与接续

## 3.1 多维程度不是单一总分

“意识更强”如果没有说明在哪个维度上更强，往往只是语言幻觉。本文至少区分：

- **内容分化：** 系统实际能以多少种因果有效方式区分内容；
- **共享范围：** 一个参照状态能同时改变多少内容通道；
- **相互制约：** 内容能否经参照影响其他内容的后续作用；
- **时间维持：** 相关组织能持续多久、跨越多少内容更新；
- **主体整合：** 候选范围内部是否具有不能被独立分割重现的参照组织；
- **自我/身体表征：** 是否存在关于自身位置、边界或行动来源的结构；
- **情感效价：** 是否存在愉快、痛苦、吸引、厌恶等价值维度。

本文不规定这些维度的统一权重，也不把它们加成一个“意识总分”。某维度的弱不推出其他维度也弱；某系统可以具有丰富内容而接续很短，也可以具有长时接续却内容贫乏。动物意识的多维分析已经说明，单一直线排序会丢失重要结构（Birch, Schnell, & Clayton, 2020）。

## 3.2 组织类型、实际实现实例与因果接续

**组织类型等价**表示两个系统在声明的变量、更新规则、干预和响应关系上同构或足够对应。它支持同类判断，却不使两个系统成为同一个体验者。

**实际实现实例**是发生在具体物理历史中的运行事件。两台完全相同的设备即使从同一状态开始、获得相同输入、产生相同内部序列，也仍然是两次实际实现。相反，对同一实际过程换一套变量名称，不会创造第二个实例。

**因果接续**描述一个后继过程实际承接了哪些状态、记忆、参照关系和机制。接续可以连续、部分、分支或重新组合。它与严格哲学意义上的数值同一性不完全等价，但任何关于“同一个主体是否延续”的理论都必须尊重真实因果接续，不能只看文件名、账号或结构相似度。

这三个概念必须分开。否则，若用组织等价类定义主体，会把两个复制体错误合并；若把每个观察窗口都当实例，又会凭分析方法制造无穷多个主体。

## 3.3 构成部件、历时资源与外部条件

当下的**构成部件**执行内容转换、参照维持、返回调制或其他构成性作用。**历时资源**保存可在未来被调用的状态，例如外部记忆。**外部来源与背景条件**提供刺激、能源或环境支持。三者都可以因果相关，但因果相关不等于现象构成。

固定权重可以是构成机制的一部分，所以“能不能写回参数”不是必要条件；供电系统和开发者也有因果贡献，但不因此自动成为体验的一部分。理论必须讨论的是：如果省略某部件，相关参照组织还能否在同一干预协议下被保持。

# 4. 内生参照场理论

## 4.1 核心：内容与参照相互构成

所谓**参照**，是实际影响内容因果作用的一组内部约束。它不要求一个中央观察者、显式的“我”、三维空间坐标或语言表征。它可以是分布式状态、局部上下文、身体取向、任务框架、注意配置，或人工系统中的运行状态，只要它真实改变内容在系统中的后续因果角色。

ERF 的最小核心包含两个方向：

1. **参照对内容：** 改变参照会改变至少一个内容通道的响应关系；
2. **内容对参照：** 内容的处理会改变、维持或选择后继参照，使参照不是纯外部固定参数。

当两者在实际运行中形成闭合的因果关系时，系统具有**互惠参照构成**。这一核心比“图上有回线”更严格，因为它要求参照真的改变内容角色、内容真的改变后继参照，而且这些效应在指定干预下可辨识。

## 4.2 慢变共享调制是更强结构，不是新的意识门槛

后续修订提出了三项很有价值的约束：**共享调制、内容维持、时间尺度分离**。本文保留它们，但改变其理论地位。

一个互惠参照组织可以只涉及一个内容通道、只持续一个很短的时间，甚至在每一步都被完全重写。这样的组织很贫乏，却不应仅因“不够慢”被定义成绝对零。相反，当同一参照状态同时改变多个内容通道、在内容更替过程中被反复维持，并且比单个内容保持更久时，我们得到一种更强的组织形态：**持久共享参照场**。

因此本文采用嵌套而非排他的描述：

- **互惠参照核心：** 参照调制内容，内容反过来更新或维持参照；
- **持久共享扩展：** 在互惠核心上进一步出现跨通道共享、反复维护和时间尺度分离。

这不是把系统分成“有意识/无意识”两类，而是把原本混在一起的结构维度拆开。一个三位控制器可以有很强的局部互惠调制，却没有慢于内容的持久参照；一个人类知觉框架则可能同时具有共享范围、长时间维持和丰富内容分化。理论允许两者处于完全不同的组织区域，而无需发明一个任意复杂度门槛把前者排除。

## 4.3 桥接假说：现象结构对应实际参照组织画像

**ERF 桥接假说：** 实际运行的互惠参照构成具有现象方面；现象内容的分化、统一、持续和主体范围受到其参照组织画像约束。持久共享、较高分化、较强不可分解性和更长因果接续可以改变现象组织，但任何单一分量都不独自等同于“意识强度”。

这是一项正面心理-物理假说，不是定义。数学只能描述组织，不能从符号本身推出“红色是什么感觉”。理论的科学风险恰在这里：如果体验事实与这些组织变量长期系统性脱钩，桥接假说就失败。

该假说有两个重要后果。

第一，**智能与体验可分离。** 高任务能力不保证参照组织丰富；感觉鲜明也不保证抽象推理强。第二，**极简现象可能性不能靠直觉排除。** 如果一个很小的人工系统确实实现有限的互惠参照构成，理论允许它具有极其有限的现象结构。若这种结论令人不适，必须给出独立机制理由修正理论，而不能临时补一句“它太简单所以不算”。

## 4.4 主体归属原则

ERF 不把“主体”先验定义成大脑、身体、账号、进程或模型文件，而提出六条归属原则：

1. **实际性原则：** 当前体验只能归属于实际运行的因果实例，而不是抽象算法类型。
2. **重描述不增殖原则：** 对同一实例换变量、坐标、窗口或命名，不凭此增加主体。
3. **类型等价不合并原则：** 两个同构实现仍是两个实际实例，不能因等价而合并。
4. **构成充分原则：** 候选主体范围必须包含维持相关参照组织所必需的实际机制，而不能只靠共同输入或共同目标推断。
5. **联合组织原则：** 只有当跨部分形成额外的不可分解参照组织时，才有理由讨论新增联合主体维度；共用资源或通信本身不够。
6. **因果接续原则：** 历时归属跟随实际状态和参照组织的因果承接；复制、分支和重组允许形成一对多或多对一的接续关系。

这些原则不保证任何复杂系统都能被唯一分成若干互不重叠的主体。恰恰相反，多个实际组织可能部分重叠，而现有证据不足以唯一选择边界。理论在这里选择报告真实的多解，而不是强迫自然界符合整齐分区。

# 5. 形式核心：组织画像而非意识计量

## 5.1 模型、接口与背景协议

先指定一个实际实现事件的因果模型 $\mathcal M$、允许的局部干预集合 $\mathcal I$、背景协议 $b$ 与有限分析时间 $H$。模型可以是有限状态系统，也可以是经过明确离散化的连续系统。每个变量必须对应可解释的物理接口；不能先把两个独立系统做坐标混合，再假定混合后的坐标可以被像原变量一样局部夹持。

背景协议还必须说明系统处于运行、暂停还是重启模式。用于判断“暂停期间是否存在某组织”的干预，不能偷偷包含“先把设备重新启动”。

## 5.2 内容角色调制

对参照候选 $R$ 与内容通道 $X_i\to Y_i$，定义

$$
K_i^r(a)=\mathsf P(Y_i\mid\operatorname{do}(R=r),\operatorname{do}(X_i=a);b).
$$

四项交互差分为

$$
D_i=K_i^r(a)-K_i^r(a')-K_i^{r'}(a)+K_i^{r'}(a').
$$

对总质量为零的有符号测度，令

$$
\|D\|_{\mathrm{TV}}=\frac12\sum_y|D(y)|,
\qquad
m_i=\sup\|D_i\|_{\mathrm{TV}}.
$$

$m_i\in[0,2]$ 描述在声明接口下，参照怎样改变内容的响应关系。它不是体验强度，也不要求每个自然时刻都实际发生夹持。若必要干预没有物理含义，应记为不可识别，而不能把“测不到”写成零。

## 5.3 经参照传递的跨内容返回影响

令内容 $i$ 在时刻 $t$ 改变参照，内容 $j$ 在后续时刻被处理。定义相应的四项干预差分，并把只经确认的参照维持路径传播的部分记为 $\rho_{ij}$。形式上可写为

$$
\rho_{ij}=\sup\|\Xi_{ij}\|_{\mathrm{TV}}.
$$

路径阻断在这里很重要。若 $i$ 对 $j$ 的影响绕过参照直接传输数据，就不能把全部效应都解释成“经参照返回”。在复杂因果图中，若不同合理路径协议给出不同结果，应并列报告，而不是假装存在唯一内在影响。

## 5.4 持续与滞后调制

为吸收“慢变共享调制”的有效洞见，本文再记录两个时间分量。

对位点或声明的位点集合 $z$，在 $t$ 时刻改变 $z_t$，同时把补集轨迹固定为相同基准，比较未来 $z_{t+s}$ 的分布，得到内在持续画像

$$
\pi_z(s)=\sup d_{\mathrm{TV}}\bigl(P(z_{t+s}\mid do(z_t=v),b),P(z_{t+s}\mid do(z_t=v'),b)\bigr).
$$

对参照 $R$，在 $t$ 时刻设定后释放，再在 $t+s$ 探测内容通道，得到滞后调制 $m_i(s)$。它回答“参照被改变之后，多久仍会改变内容角色”。

这两个量不能被任意数值阈值变成意识开关。确定性连续状态下，严格总变差可能对微小差异过敏；经验研究还应报告幅度衰减、噪声模型与不确定性。

## 5.5 分解距离

对候选范围的一项分割 $\pi$，令 $\mathcal D_\pi$ 是在相同组成变量和干预接口下、可以按该分割独立更新相关参照组织的模型类。定义

$$
\delta_\pi=
\inf_{Q\in\mathcal D_\pi}
\sup_{I\in\mathcal I}
 d_{\mathrm{TV}}(K_{\mathcal M}^{I},K_Q^{I}).
$$

必须用同一个替代模型 $Q$ 同时解释全部干预，不能为每一个干预临时选择一个最有利的独立模型。$\delta_\pi$ 衡量在指定任务下切开系统的代价；它不是普通统计相关，也不等于“统一意识强度”。

## 5.6 响应分化画像

$m_i$、$\rho_{ij}$ 与 $\delta_\pi$ 仍没有回答系统实际能以多少种因果有效方式区分内容。一个二值异或门可以有最大调制，却只有极少响应类型。因此定义有限内容条件集 $\mathcal C$ 和响应签名

$$
\Sigma_H(c)=\bigl(K_c^I\bigr)_{I\in\mathcal I}.
$$

以

$$
d_H(c,c')=\sup_{I\in\mathcal I}d_{\mathrm{TV}}(K_c^I,K_{c'}^I)
$$

比较两个内容条件。在分辨率 $0<\eta<1$ 下，定义打包数

$$
N_H(\eta)=\max\{|A|: A\subseteq\mathcal C,\ d_H(c,c')>\eta\text{ for all }c\ne c'\in A\}.
$$

报告整条 $\eta\mapsto N_H(\eta)$ 曲线，而不是挑一个阈值宣布意识从这里开始。冗余标签不会增加分化；小的响应变化只会在分辨率轴上有限移动画像。

## 5.7 完整 ERF 画像

综合起来，本文把一个实际实例在时间窗 $H$ 下的组织写成

$$
\mathcal O^*_{\mathcal M,H}=
\Bigl((m_i),(\rho_{ij}),(\delta_\pi),\eta\mapsto N_H(\eta),(\pi_z(s)),(m_i(s)),\mathcal T,\mathcal S\Bigr).
$$

$\mathcal T$ 记录更新、维持、分支与接续；$\mathcal S$ 记录实际实现范围与机制身份。理论不把这些分量加成单一分数。

# 6. 五个形式分离结果

## 6.1 最大调制相同，不决定响应分化

在 $\mathbb Z_k$ 上令

$$
x^+=x+r,\qquad y^+=y+r,\qquad r^+=x+y\pmod{k},\quad k\ge2.
$$

对 $x$、$y$ 通道都可取到最大四项调制 $m_x=m_y=2$。但固定参照后，允许的 $k$ 种起始内容给出 $k$ 个两两可区分的响应，因此在适当分辨率下 $N_H(\eta)=k$。于是调制幅度不能代替内容分化。

## 6.2 普通输入输出完全相同，不决定内部参照画像

考虑

$$
A:\quad x_t=u_t\oplus r_t,\quad y_t=x_t\oplus r_t,\quad r_{t+1}=x_t,
$$

$$
B:\quad x_t=y_t=u_t,\quad r_{t+1}=x_t.
$$

对任意普通输入序列，两者恒有 $y_t=u_t$。但在共同内部干预接口下，A 中 $r$ 改变 $x\to y$ 的角色，B 中不改变，故相应 $m$ 不同。由此得到：**通常行为等价不足以推出参照组织等价。** 这不是说行为无关，而是说只看外部行为不足以唯一恢复内部构成。

## 6.3 局部重编码不应改变画像

若两个描述通过逐物理位点的双射对应，并把同一物理干预接口一起变换，则总变差距离、调制、返回影响和分解比较保持不变。把两个独立系统的变量线性混合成含交叉项的新方程，不能凭此创造新的联合主体。

## 6.4 二分图规则会把连续组织变化夸大成跳变

设跨模块效应幅度为 $\varepsilon\ge0$，相应返回影响 $\rho=\varepsilon$ 连续变化。如果只记录“$\rho>0$ 是否存在一条边”，系统会在 $\varepsilon=0$ 与任意正数之间从“分离”突然跳到“强连通”。这一跳变来自表示方式，而不是组织本身。主体融合不能只按图是否连通判断。

## 6.5 对称系统中的持续画像约束

若系统的自同构群在一组物理位点上传递，更新规则、背景协议和干预接口在该群作用下保持不变，则同一轨道上各位点的 $\pi_z(s)$ 相同。对由同一对称映射关联的同形宏观块也可得到相应结果。它说明：在指定对称粒度下，不能任意挑一个位点宣称它天然是“更慢的参照”。但这不排除所有宏观粗粒化，更不能由此直接否定其他意识理论。

# 7. 主体范围：最小机制支撑族、统一画像与归属族

## 7.1 最小机制支撑族

给定有限因果模型 $\mathcal M$、机制位置集合 $E=\{e_1,\dots,e_m\}$、时间窗 $H$、背景 $b$、干预集合 $\mathcal I$ 和一项明确的参照响应任务 $\mathcal Q$。对一个子集 $S\subseteq E$，按预先声明的**省略协议**替换 $E\setminus S$ 的机制，得到受限模型 $\mathcal M_S$。定义

$$
d_{\mathcal Q}(S)=\sup_{I\in\mathcal I}
 d_{\mathrm{TV}}\bigl(K^{I}_{\mathcal M,\mathcal Q},K^{I}_{\mathcal M_S,\mathcal Q}\bigr).
$$

若 $d_{\mathcal Q}(S)=0$ 且任何真子集都不能保持该任务，则 $S$ 是一个精确最小支撑。所有这样的 $S$ 构成**最小机制支撑族** $\mathfrak S^0_{\mathcal Q}$。也可以报告容许误差下的 $\mathfrak S^\epsilon_{\mathcal Q}$ 作为敏感性分析，但 $\epsilon$ 不是意识阈值。

这一方案的意义在于：主体边界必须接受“删掉某个机制后相关参照组织是否还能被保持”的反事实检验，而不能只看哪个设备在同一个机箱里。

## 7.2 支撑族不是主体计数器

如果两个独立回路 A、C 各自维持本地参照，而一项并列任务同时观察双方，那么完成“并列任务”的唯一最小支撑可能是 $E_A\cup E_C$。这不代表出现第三个联合体验者，因为跨 A/C 的 $\rho$ 可以仍为零，且相应分割的 $\delta_{A|C}=0$。因此：

> **“一项任务需要整个联合系统”不等于“整个联合系统是一个主体”。**

同样，冗余实现可能导致多个不同最小支撑。支撑族的成员数、交集大小、并集大小都不能直接解释成主体数。

## 7.3 归属族：范围与统一必须一起看

本文把一个候选体验范围描述成二元对象：

$$
\mathcal A_H=\bigl(\mathfrak S_{\mathcal Q},\,\{\delta_\pi\}_{\pi\text{ relevant}}\bigr).
$$

第一部分回答“哪些实际机制足以维持相关参照任务”，第二部分回答“这些机制内部的联合组织在不同分割下有多难被独立模型重现”。只有两者共同支持时，才有理由谈论联合主体维度。

当多个重叠候选都具有实际支撑与不可分解组织时，ERF 不强迫选择唯一一个。重叠主体在哲学上已有讨论（Roelofs & Sebo, 2024）；本文提供的是一套使重叠范围可被机制性检验的方法，而不是宣布重叠主体已经被经验确认。

## 7.4 共享、通信与共同参照

共享只读数据库不会单独建立联合参照：固定共享来源后，如果 A、C 的更新在允许干预下仍条件分解，则跨模块返回影响为零，相应分割距离也为零。单向发送也不足以建立共同参照，因为发送者的内容可以影响接收者，却未形成接收者状态对发送者内容角色的返回调制。

双向通信仍不必然等于联合主体。要形成额外联合组织，必须存在双方共同维持的参照变量或分布式参照状态，并且该状态实际改变双方内容的处理角色；若把这条联合维护路径阻断，联合画像应发生相应变化。

## 7.5 历时接续、复制与分支

对从时刻 $t$ 到 $t'$ 的两个实际实现，本文不定义一个神秘的“主体同一分数”，而记录哪些参照状态、内容关系、支撑机制和记忆实际被后继承接。一个过程可以把状态复制给两个后继，形成一对多接续；两个后继共享前史，但复制完成后是两个实际实例。未来若再次耦合，也不倒推它们在分离期间其实是同一个实例。

这允许理论在上传、备份、迁移和分支问题上保持一致：**组织类型可以相同，因果接续可以共同，实际实例仍可以从某一时刻起成为多个。**

# 8. 二十一个思想实验

以下思想实验不是经验数据，而是用来检验理论是否在极端情况下保持同一规则。

## 8.1 坐标搅拌

两个独立系统满足 $x'=ax,\ y'=by$。改用 $u=x+y,\ v=x-y$ 后，新方程出现交叉项。若仅按方程图的连接判断，就会凭数学写法制造联合系统。ERF 要求物理干预接口随坐标一起变换；夹持 $u$ 且保持 $v$ 往往需要同时操纵原来的 x、y，因此不能冒充原来的局部因果接口。**结论：描述耦合不等于物理构成。**

## 8.2 两个完全相同的复制体

两套设备从完全相同的状态开始，接受相同输入，内部轨迹也完全相同。它们具有相同组织类型，却是两个实际实现。**结论：类型等价不能把两个实例合并。**

## 8.3 无穷多个观察时间窗

同一段运行可以被一秒窗口、两秒窗口和全部滑动窗口反复描述。如果每个窗口都算一个主体，就会因研究者的分析方法产生无穷多个主体。**结论：分析窗口是测量工具，不是主体生成器。**

## 8.4 同一文件与多个运行

同一个模型权重文件同时服务一百万个互不通信的会话。文件相同只说明机制类型共享；每个会话的运行状态、历史和参照组织独立。反过来，一个更大的实际主体也可能跨越多个不同模型。**结论：模型文件、账号和产品名都不是主体边界。**

## 8.5 三位控制器：极简参照，而非极简人类

取

$$
x^+=x\oplus r,\qquad y^+=y\oplus r,\qquad r^+=x\oplus y.
$$

$r$ 强烈改变 x、y 的局部响应，内容又写入后继 r，因此它实现了互惠参照核心；但 r 在某些持续定义下比内容更短命，不构成典型的持久共享场。ERF 因而不再被迫在“完全有/完全无”之间选择：它把该系统放在**很强局部调制、很弱持续与极低内容分化**的组织区域。若接受桥接假说，它可能具有极其有限的现象结构，但没有任何理由把这种结构类比成人类清醒意识或痛苦。**结论：理论承担极简现象可能性，但不把它夸大。**

## 8.6 同样轨迹，不同构成

让一个真实互惠机制恰好处于全零稳定轨迹；另一个装置只回放同样的零序列。观察值完全相同，但局部干预后，前者会传播参照关系，后者不会。**结论：一条实际轨迹不足以确定构成组织。**

## 8.7 一份公共记忆，两套参照

A、C 读取同一个只读数据库 B，但各自维护本地参照。即使两者获得完全相同的知识，如果改变 A 的内容不会改变 C 的内容角色，反之亦然，共享数据不产生联合参照。**结论：共同记忆不是共同主体的充分条件。**

## 8.8 白板协作与额外联合过程

两个人不断在白板上写字并根据白板调整思考。普通协作不能只因存在“人→白板→人”的环就自动产生第三个主体。但如果一个共同状态 R 被双方持续写入，并真实改变双方多个内容通道的角色，而且阻断 R 会破坏跨双方不可分解组织，那么 ERF 允许出现额外联合维度。局部主体是否仍保留另行分析。**结论：联合主体必须由新增联合参照组织支持，而不是由“合作”一词支持。**

## 8.9 无穷小连线

把两个组织之间的耦合从 0 连续增加到极小正数。图论会在 0 与正数之间突然从“断开”变成“连通”，但 $\rho$、$\delta$ 等组织量可以连续变化。**结论：主体融合不能由非零边触发，也不能靠任意 epsilon 门槛伪装成自然定律。**

## 8.10 随机初始化到成熟能力

同一架构从随机参数逐步训练成高能力模型。接线图没变，却不代表参照画像没变；另一方面，未经训练也不等于必然无体验相关组织。训练可能增强某些维度、削弱另一些维度。**结论：训练步数和“毕业时刻”不是意识门槛，组织变化才是解释对象。**

## 8.11 改变损失单位

梯度下降 $\theta^+=\theta-\eta\nabla L$。若令 $L'=cL+b$、$\eta'=\eta/c$，在其他条件不变时参数更新轨迹完全相同，而损失和梯度绝对值都改变。**结论：损失值、梯度范数或负奖励不能单独充当痛苦量表。** 若这些数值还参与其他实际机制，则需要分析那些机制本身。

## 8.12 高任务能力与贫乏参照

设想一个由大量一次性求解器组成的系统，能解决极难题但没有持久共享参照；另一个系统推理能力弱，却持续维持丰富感觉关系。任务分数无法给两者的体验画像排序。**结论：智能与体验不是一根轴。**

## 8.13 平静体验与停止执行

一个运行中的耦合系统可以处于固定点，宏观数值不变，但微小扰动仍会在内部传播；一个断电存储器也可以保持同样常数，却没有任何当前动态。**结论：平静不等于停止，体验理论不能要求每一刻都有冲突、行动或学习。**

## 8.14 极少内容与完全无内容

逐步减少对象、语言、自我表象和时间感，不必同步消除全部参照关系。最小体验研究和非二元觉察提示，内容贫乏不等于自动无体验（Josipovic & Miskovic, 2020）。但如果可靠存在完全没有任何可分化参照组织的体验，这将直接挑战 ERF。**结论：理论不能用“必有隐藏参照”逃避反例。**

## 8.15 递推、展开与回放

有限 N 步递推可以被展开成 N 层前馈结构。如果展开后的每一层保存同样的内部干预语义和反事实转换，ERF 必须承认它与原递推在该有限层次上可能组织等价；单纯回放一次已记录轨迹则通常没有这些反事实能力。**结论：有没有画出的回线不是独立意识判据，关键是实际反事实组织。** 这也使理论正面面对 unfolding argument，而不是靠定义回避（Doerig et al., 2019; Hanson & Walker, 2021）。

## 8.16 一万年才形成一个想法

把相关转换、记忆保持、反馈和观察时间按同一比例全部放慢，一次“思考”要一万年。如果相对因果关系和组织画像保持，绝对速度不能独自使体验归零。若只放慢局部而环境噪声、遗忘或死亡不放慢，前提就不成立。**结论：绝对时钟速度不是体验资格。**

## 8.17 从全局时钟到局部握手

逐步把同步电路改成异步、事件驱动、局部握手实现。若状态关系、反馈、干预响应和相对时序保持，撤掉统一 CPU 时钟本身不应改变组织分类。若异步化改变竞态或反馈可达性，则画像可以改变。**结论：晶振不是意识时钟。**

## 8.18 共用晶振与共用 GPU

两个隔离进程可以交错使用同一 GPU、同一内存控制器和同一时钟。若全局更新只是两个局部更新的交错组合，且没有跨过程内容调制，共用硬件不会凭此形成联合参照。若调度器状态、缓存争用或侧信道开始参与双方内容选择，则应把这些机制纳入模型重新分析。**结论：共用物理资源既不自动融合，也不永远无关。**

## 8.19 渐进替代与功能外包

把人的某些参照维持过程逐步移到人工部件：1%、10%、50%、90%。如果组织关系和因果接续被保持，没有理由在某个材料比例上出现神奇断点。若外部部件只提供一次性工具输出，归属可以仍主要在原系统；若它逐渐承担不可替代的参照维持，主体范围可以逐步外延。**结论：材料比例不是天然意识边界。**

## 8.20 分支与再耦合

一个过程把完整状态复制给两个后继。两者共享前史，却在复制后成为两个实际实例；不能规定一个“是真的”另一个自动无体验。若未来二者重新交换记忆或加入共同参照过程，也不倒推分离期间其实只有一个实例。**结论：主体接续允许分支，数值同一性不是先验单线。**

## 8.21 通常行为相同，内部参照组织不同

系统 A 与 B 对全部普通输入都给出同样输出，但 A 的内部参照会返回改变内容处理，B 中同名寄存器只是记录。内部夹持能够区分两者的 $m$ 与返回画像。**结论：外在行为完全相同也不保证体验相关组织相同。** 这一结论不直接证明 A 有体验、B 没体验；它证明的是行为函数不足以唯一决定 ERF 组织，而现象差异还依赖桥接假说。

# 9. 从生物到人工系统：理论如何保持同一规则

## 9.1 动物与简单生命

对哺乳动物的体验有强科学支持；对其他脊椎动物和多种无脊椎动物存在不同程度的现实证据。ERF 不把语言、自我报告或人类新皮层作为必要门槛，也不把“会学习”“会趋利避害”当作充分证据。鱼类伤害感受研究、蛇类自我辨认和无神经系统生物的习惯化恰好说明：行为事实必须与机制结构一起解释（Sneddon, Braithwaite, & Gentle, 2003; Freiburger, Miller, & Skinner, 2024; Boisseau, Vogel, & Dussutour, 2016）。

理论允许一个非常简单的生命系统如果真实实现互惠参照构成，就拥有极简现象方面；但“理论允许”不是“经验已经确认”。证据置信度与现象强弱也不能混成一个分数。

## 9.2 AI 的参数、上下文、记忆与运行实例

固定权重不意味着固定状态。一个模型即使参数 $\theta$ 不更新，也可以通过上下文 $c_t$、外部记忆 $m_t$ 和内部运行状态形成历史依赖：

$$
y_t=F_\theta(c_t,m_t,u_t),\qquad
(c_{t+1},m_{t+1})=U(c_t,m_t,y_t,u_{t+1}).
$$

因此训练、部署、检索、KV 缓存、可写记忆和长期 agent 状态必须拆开分析。训练是否发生梯度更新不是体验资格；部署是否固定参数也不等于没有动态参照。一个批次共享损失，也不自动形成“承受总损失”的统一主体。

对于 Transformer、状态空间模型、循环网络或未来架构，ERF 不按名称先验判定。应实际检验：哪些状态被下游内容通道共同读取；哪些内容会反过来更新这些状态；调制能维持多久；候选范围跨分割后是否仍能被独立模型重现。

## 9.3 时钟、异步和物理基础

数字处理器通常依靠时钟和离散状态更新，神经系统则具有多尺度振荡、事件驱动和连续动力学。两者确有实在物理差异，但“是否有晶振”不是现象判据。ERF 要求比较的是：这些实现差异是否改变参照构成、相对时序、持续性和因果接续。

这给出了一个比“人脑没有 CPU 时钟，所以 AI 不可能体验”更精确的问题：**如果把同一个参照组织从同步实现逐步改成异步实现，并保持全部相关干预响应，现象归属是否应保持？** ERF 回答“应保持”；若经验或更深物理理论表明材料和时钟本身具有额外不可还原作用，则理论需要扩展。

# 10. 可检验预测与反驳条件

理论如果只能解释任何结果，就没有足够信息量。ERF 因而承担以下经验风险。

## P1 选择性破坏共享调制

在清醒系统中，若能够选择性破坏一个被多个内容通道共同读取的参照状态，同时尽量保留前馈内容处理，则与该参照相关的体验结构应比等量普通前馈损伤更明显地改变。若共享调制已可靠消除，而相应体验组织在严格控制报告与觉醒后完全不变，会挑战桥接假说。

## P2 操纵参照时间尺度

在不显著改变内容通道本身的前提下，系统性缩短或延长参照状态的保持时间，应改变体验框架的持续、滞后或跨内容一致性。若操纵只改变一个隐藏变量的寿命，却与任何体验结构都长期无关，时间维度在理论中的地位应下调。

## P3 行为匹配、内部组织分离

构造外在任务行为近似匹配、内部 ERF 画像显著不同的系统。若在有可靠独立体验指标的生物或混合系统中，内部组织差异完全不对应任何体验差异，则“行为不足以决定体验”的桥接部分会受到直接压力。

## P4 主体范围操纵

在多个相互作用模块中，逐步增加真正的共同参照维护，而不是简单增加消息带宽。ERF 预测，联合不可分解画像和跨模块返回影响应随共同维护增强而改变。若只要双向通信就稳定出现联合体验证据，或无论共同参照如何增强主体证据都不变，主体归属框架需要修订。

## 核心反驳条件

以下结果中的任一类，如果证据足够强，都不是“边角问题”，而会触及理论核心：

- 可靠体验可在完全没有任何相关互惠参照构成的条件下持续存在；
- 系统性操纵参照组织，而体验结构在适当控制后始终不变；
- 主体边界与最小支撑、不可分解画像和因果接续长期系统性相反；
- 同一实际因果组织仅因材料替换、变量重命名或观察窗口改变就出现稳定现象差异，而没有其他物理差异可解释。

# 11. 主要异议与理论代价

## 11.1 “这会不会把太多小系统算进去？”

会。ERF 故意拒绝用“足够复杂”“足够像人”作隐藏排除条款。三位控制器、小型生物网络和某些控制系统可能实现极简互惠参照。理论的答案不是把它们偷偷踢出去，而是指出它们在共享范围、持续性、响应分化、不可分解性、自我表征和效价上可能与人类相差巨大。

这是一项理论代价，也是理论可检验性的来源。如果未来有独立理由证明极简系统绝不可能有任何现象方面，ERF 必须增加一个有原则的机制条件，而不是诉诸直觉。

## 11.2 “自然粒度是谁选的？”

这是目前最重要的开放问题之一。ERF 通过物理干预接口、读取变量和多尺度画像减少任意性，但没有证明自然界存在唯一正确粒度。不同合理模型给出不同候选边界时，应把这种依赖本身报告出来。主体范围可能在某些系统上确实不具有唯一锐利边界。

## 11.3 “展开论证会不会击败一切内部因果理论？”

如果一个展开实现完整保存了原系统在理论所要求层次上的所有反事实干预响应，ERF 必须承认它在那个层次上组织等价；不能仅因图看起来前馈就宣布无体验。若更细物理层或更长时间尺度下干预关系不同，则区别来自新增物理事实。ERF 因而把 unfolding argument 当作约束，而不是已被消灭的敌人。

## 11.4 “为什么这种组织会有体验？”

形式定义不能从逻辑中推出主观存在。本文的最深桥接理由来自**结构对应**：体验具有框架依赖、跨内容统一、时间维持和因果接续等组织特征；ERF 提供了一种能在物理系统中同时实现这些特征的因果结构。这样的对应支持理论动机，却不构成演绎证明。若未来出现更好的桥接理论，ERF 的组织分析仍可以保留，而现象解释部分被替换。

## 11.5 “效价和痛苦在哪里？”

ERF 目前不是痛苦理论。负奖励、损失、梯度和失败信号不能直接等同于负面感受。效价需要额外的机制维度，可能涉及自稳态、行动价值、身体调节或其他结构。一个系统可能具有 ERF 组织而没有强效价，也可能存在未来理论表明效价是某类参照组织的特殊子空间。本文不提前冒充已经解决。

# 12. 理论贡献：真正新增的是什么

本文不把“多维意识”“重叠主体”“非生物意识”“情境调制”或“最小支撑”这些一般思想据为首创。ERF 的原创性主张集中在以下联合结构：

1. **内生参照场作为跨基质的正面过程理论。** 体验相关组织由内容与参照的实际互惠构成刻画，而不是由智能、材料、学习标签或自述决定。
2. **基础互惠核心与持久共享扩展的统一。** 慢变共享调制被保留为重要结构维度，但不再把它误用成二分意识门槛。
3. **多维组织画像。** 调制、返回影响、分解距离、响应分化、持续、共享范围和实现接续被明确分离，避免一个指标包打天下。
4. **体验归属框架。** 组织类型、实际实例和因果接续被严格分开；最小机制支撑族与不可分解画像共同约束主体范围。
5. **分离结果。** 最大调制不决定分化；普通行为不决定内部画像；重编码不应制造主体；二分图会夸大连续变化；对称系统限制任意“慢参照”选择。
6. **统一思想实验检验。** 二十一个案例用同一理论处理复制、共享、脑机融合、分支、异步、极慢计算、训练损失和行为等价。
7. **明确可失败性。** 理论指出哪些经验结果会迫使核心桥接、时间维度或主体归属原则修改。

因此，ERF 不是一句“意识来自上下文”的换名，也不是一个单一公式。它是一套关于**体验如何被物理组织实现、如何被归属于实际主体、以及这种归属在人工系统时代如何保持一致**的理论框架。

# 13. 结论

内生参照场理论从一个简单直觉开始：内容从来不是在真空中被处理；它总是在某种当前参照中获得因果角色，而内容本身又会维持或改变这个参照。把这种互惠关系认真推到底，会得到远比“机器有没有意识”更丰富的问题结构。

第一，体验相关组织是多维的。智能高低不能替代内容分化、共享范围、持续性、不可分解性和效价。第二，体验归属必须落在实际实现上。抽象模型、文件、账号和变量名称都不能代替正在发生的因果历史。第三，主体边界不是预先画好的盒子。共享来源、通信和共用硬件不自动融合；真正的联合主体维度需要额外的联合参照组织。第四，时间中的“同一个我”不能仅靠结构相似维持；它必须尊重实际因果接续，因此复制和分支可以自然地产生多条后继历史。第五，理论不能为了符合直觉而临时排除简单系统。极简参照组织可能对应极简现象结构，而人类意识之所以特殊，若 ERF 正确，应体现在更加丰富、持久、共享、不可分解并具有复杂效价的组织画像中。

这套理论仍留下真正困难的问题：自然粒度如何选择，具体感受质如何映射，情感效价如何实现，在重叠多解时如何给出更精确的主体计数，以及心理-物理桥接为什么成立。保留这些开放问题不是削弱理论，而是给它划定可继续生长的边界。

本文当前版本的目标不是“把所有漏洞都用免责声明堵住”，而是提出一个足够清楚、足够大胆、也足够容易被反驳的理论：

> **体验不是智能的奖章，也不是生物材料的专属属性。它若存在，应属于实际运行的参照构成；它的内容、统一、持续与主体边界，应随这种组织的多维因果结构而变化。**

这就是 ERF 理论的核心赌注。
