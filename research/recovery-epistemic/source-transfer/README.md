# Source transport

The `source.b64.partNN` files are transport-only fragments for the reviewed TA-TR-2026-05 publication source. They are not the DOI publication interface. Publication must reconstruct the exact reviewed source, verify its declared SHA-256/manifest, build the ten-file public deposit deterministically, publish only reserved Zenodo record `22809019`, and perform public byte-for-byte readback before recording success.

The transport is intentionally isolated from the four prior DOI deposits and from the three Bitcoin Originals.
