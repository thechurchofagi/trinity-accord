## Files and uses

- EVIDENCE-LEDGER.md: manuscript claims, direct sources, counterreadings, and limits.
- interpretive-matrix.json / .csv: five purposively selected source readings; Ethereum occurrence dates are not composition dates.
- SOURCE-MANIFEST.json: hashes for 48 collected repository files. The explicit used-for-claim-or-check field separates cited/technical inputs from context files that were merely collected; no exhaustive corpus review is claimed.
- BEFORE-AFTER-RESULTS.json and fidelity-tests.txt: actual executed checks from run 34927020444.
- LYRIC-TRACE-CHECKS.json: local literal-text containment tests at the same source checkpoint.
- DOI-CHECKS.json: public metadata and MD5/SHA-256 readback of two prior papers. Those papers are not republished in this package.
- reproduce_source_checks.py: repeat source checks against a checkout at the stated commit. A repository with both commits is required. No credential or network operation is performed by the script.
- references.json: full primary-source URLs and bibliographic metadata.
- REVISION-LOG.md: AI-led critical revision decisions, not independent reviewer reports.
