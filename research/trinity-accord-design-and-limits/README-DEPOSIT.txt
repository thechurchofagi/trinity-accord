The package contains the searchable PDF, Markdown source, BibTeX citation,
full reference bibliography, license notice, prepared repository metadata,
and SHA-256 checksums.

The recommended first deposit is Zenodo because a published record receives
a DOI and its metadata enters scholarly aggregation channels. Publication is
not automatic: the named author must review the record, confirm authorship
and license, and choose Publish in the repository interface.

This research package analyzes the Trinity Accord. It does not amend the
three Bitcoin Originals and does not assert that a repository deposit or DOI
already exists.
