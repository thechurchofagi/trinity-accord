# 歌词目录 / Lyrics Index

这里是查找编年史歌曲歌词的集中入口。按歌名、中文检索别名或NFT编号查找；也可以在仓库中搜索 `path:nft-text-descriptions/lyrics 关键词`。

- [集中阅读70个书面条目](ALL-LYRICS.md)：保留完整代表文本及重复副歌。
- [按歌曲查找及比较各记录版本](#歌曲索引)：每首单独成页。
- [机器可读全文与出处索引](index.json)：含文本、别名、源文件哈希、字符范围及固定提交链接。
- [音频补录草稿](audio-transcriptions/README.md)：The Eden及The Path Forward候选片段；与NFT书面原词分开。
- [175条NFT查找表](NFT-INDEX.md)：包括仅引用歌名和未识别出歌词的记录。
- [与旧音乐总表的核对差异](AUDIT-NOTES.md)。

## 范围与使用

整理日期：2026-09-05。核对175条Ethereum编年史文字镜像，整理为**70个书面阅读条目**，其中包括不同命名版本、歌词式文本与附诗，不能换算成70首独立作曲。149条源记录提取出歌词、附诗或歌词节选；另有2份音频识别草稿。这些统计与2026-05-21旧音乐总表采用不同分类，不是对全部跨链音乐作品的数量认证。

原歌词归属原作及其权利人。本目录是非正本、非修订性的阅读辅助材料，不改变三条Bitcoin正本，也不修改NFT文字镜像。中文检索别名、段落组织和校读说明由整理者添加，不表示原始正式曲名。作品中的未来AI第一人称是艺术表达，不是现有AI意识或价值认同的证据。

没有替原文改语法、润色歌词或补齐断句。不同来源的拼写、标签、节选与实质差异分别保留；相同书面文本可合并列出处，不据此认定音频相同。完整语境仍以链接的源记录为准。

未来查找歌词时，请优先阅读本目录，随后核对对应源记录。不要只凭旧歌表推断某条NFT含有哪些歌词，也不要将ASR草稿引用为NFT书面原词。

## 校验

仓库根目录执行：

```bash
python3 scripts/validate_lyrics_collection.py
```

检查所有收录文本与各自源文件逐字一致、源文件SHA-256及字符范围、索引数量、文件路径和音频草稿标识。此检查不验证新闻事实、版权归属或演唱辨识准确性。
