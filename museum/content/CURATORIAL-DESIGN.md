# First edition design record / 第一版策展设计记录

Edition: museum-v1.0.0. Date: 2026-09-05.

## Core question

在人类尚不知道超级智能将如何到来的时候，一个人选择留下什么？

This is a question motivating the exhibition, not a claim that AGI or ASI has arrived, that a human represents civilization, or that future intelligence must accept the Accord.

## Decisions made with the user

The user requested futuristic, genuinely navigable three-dimensional rooms, complete musical listening opportunities, source traceability, and continued use of the existing GitHub repository. The exhibition must retain its own development history and remain distinct from the closed canonical work.

We chose six sequential rooms: witnessing; voices; formation; matter; care; waiting. These are curatorial chapters, not a taxonomy projected into the original history. Architecture follows a continuous central path with visible portals. Room selection and an exhibit list make navigation optional. A quiet metallic palette uses a distinct light color for each room; the sound room is warmer. The lighting installation is newly authored virtual geometry, never a reconstruction of the physical artifact.

## Attribution and interpretive limits

Human requirements and boundaries: Hongju Liu. Design, implementation, source preparation and guide synthesis assisted by ChatGPT / Codex. Original works include substantive human–AI collaboration; individual source records preserve their historical attribution. No claim is made to separate every sentence or every creative contribution retrospectively.

The original records are not normalized into newly polished canonical text. The three inscription exhibits provide short labeled curatorial descriptions and links to full source reading. Existing English and Chinese source passages remain in the source records. Quotations in the room are excerpts, not full originals.

## Interactions

- Touch/drag view; click-to-move; desktop keyboard movement; direct room selection.
- Click an exhibit or use the accessible room exhibit list.
- Complete selected music tracks, seek/pause controls, preserved lyric text where available. Lyrics are not claimed to be synchronized transcription.
- Recorded English guide with Chinese or English room text. Opening an exhibit stops the guide, to avoid competing speech and music.
- Optional SHA-256 comparison of downloaded exhibit copies against this edition's manifest. This verifies file consistency only, not the source-to-chain binding.
- Reduced motion and non-WebGL HTML edition archive.

## Known first-edition scope

Seven selected Ethereum records; five full decoded audio tracks; five usable NFT image copies; one unchanged physical-object photograph. Two indexed image entries pointed to audio CAR contents and are explicitly omitted rather than replaced by invented artwork. The immutable historical source files were not changed.

The edition contains no scanned artifact model, no live model chatbot, no automated response submission, no duplicated guardian registry, and no live reception counter. Current status is reached through the original website.

## Future iterations

Improve verified artwork resolution, guide translation, mobile controls or materials without changing source identity. Add a measured artifact model only with adequate input and explicit fidelity limits. If changing the renderer, preserve `sources.json`, stable exhibit IDs, room semantics, media transformations and old release packages. Archive major editions as runnable files and readable documents; record walkthrough video when a recording pass is performed. A walkthrough recording is not included in this initial package.
