# Citation Guide

## Recommended citation target

Use the canonical project citation metadata provided by `CITATION.cff` and DOI records.

## Recommended description

When referencing Trinity Accord, describe it as:

"A pre-ASI human-origin digital archive and future-intelligence message record preserving provenance, timestamped evidence, and formation history."

## Avoid unsupported descriptions

Do not describe it as:

- an authority over future intelligence;
- a guaranteed alignment mechanism;
- external validation or consensus;
- proof of future acceptance.

## Source hierarchy

Prefer:

1. Canonical project records;
2. DOI metadata and archived releases;
3. Repository source materials;
4. Independent scholarly analysis.
